# 项目级人物功能更新日志 📋

## 更新时间
2025-10-12

## 更新内容

### 🎯 核心改进：从全局管理改为项目级管理

#### 变更前（旧方案）
- 所有人物照片保存到全局 `characters/` 文件夹
- 所有项目共享同一个人物库
- 切换项目时人物列表不变化
- 同名人物会相互覆盖

#### 变更后（新方案）
- 人物照片保存到 `projects/项目名/characters/` 文件夹
- 每个项目有独立的人物库
- 切换项目时自动加载对应人物
- 同名人物可在不同项目中独立存在

## 🔧 具体修改

### 1. image_mixin.py

#### 修改：`_auto_save_character_photo()`
```python
# 旧代码
workspace_root = Path(os.getcwd())
self.character_photos_dir = workspace_root / "characters"

# 新代码
if not self.current_project:
    messagebox.showwarning("提示", "请先创建或打开一个项目")
    return ""
project_path = self.proj_manager.get_project_path(self.current_project)
self.character_photos_dir = project_path / "characters"
```

#### 新增：`_load_project_characters()`
- 切换项目时自动调用
- 清空旧人物列表
- 扫描当前项目的 `characters/` 文件夹
- 加载所有人物照片
- 更新参考人物列表

#### 修改：`_update_reference_character_list()`
- 验证照片文件是否存在
- 添加项目名称日志输出
- 只显示当前项目的人物

#### 修改：UI提示文字
- "照片自动保存到 characters/ 文件夹" 
  → "照片自动保存到 当前项目/characters/ 文件夹"
- 状态消息包含项目名称

### 2. project_mixin.py

#### 修改：`_on_new_project()`
```python
# 新增代码
if hasattr(self, 'proj_manager'):
    from pathlib import Path
    project_path = self.proj_manager.get_project_path(self.current_project)
    characters_dir = project_path / "characters"
    characters_dir.mkdir(parents=True, exist_ok=True)
    print(f"📁 已创建人物照片文件夹：{characters_dir}")
```

#### 修改：`_on_load_project()`
```python
# 新增代码
if hasattr(self, '_load_project_characters'):
    self._load_project_characters()
```

## 📁 目录结构变化

```
创作知乎故事/
  ├── characters/              # ❌ 全局共享
  │   ├── 人物A.png
  │   └── 人物B.png

      │   │   ├── 人物A.png
      │   │   └── 人物B.png
      │   ├── images/
      │   └── story.txt
      └── 项目2/
          ├── characters/      # ✅ 项目独立
          │   ├── 人物C.png
          │   └── 人物D.png
          ├── images/
          └── story.txt
```

## ⚠️ 注意事项

### 兼容性
- **旧项目**：如果有旧项目，首次打开时 `characters/` 文件夹不存在，系统会自动创建
- **全局 characters/**：如果之前有全局的 `characters/` 文件夹，需要手动迁移到对应项目中

### 迁移步骤（可选）
如果需要将旧的全局人物照片迁移到项目中：

1. 找到全局 `characters/` 文件夹
2. 识别每个照片属于哪个项目
3. 手动复制到对应的 `projects/项目名/characters/` 文件夹
4. 重新打开项目，照片会自动加载
