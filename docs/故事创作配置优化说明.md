# 故事创作配置优化说明

## 更新日期
2025-10-11

## 概述
本次更新将故事创作的配置页面改造得与图片生成配置页面一致，提供了更好的用户体验和更灵活的API管理方式。

## 主要改进

### 1. 测试日志区域
- **位置**：故事生成 → 配置标签页底部
- **功能**：专门的测试日志输出区域，显示API测试的详细信息
- **优势**：
  - 测试日志不再污染创作页面的输出区域
  - 提供详细的测试过程和错误信息
  - 支持清空日志功能
  - 使用等宽字体，便于查看技术信息

### 2. 故事创作功能API配置
新增了独立的API选择器，可以为不同的功能选择不同的API：

#### 目录生成API
- 用于"生成目录"功能
- 可以选择任何已配置的API预设
- 独立于故事生成API

#### 故事生成API
- 用于"生成故事"功能
- 可以选择任何已配置的API预设
- 独立于目录生成API

### 3. 灵活的API选择
**使用场景示例：**
- 可以用便宜的API生成目录，用高质量的API生成故事正文
- 可以为不同的任务选择最合适的模型
- 所有API使用上方"基础API配置"中配置的密钥

### 4. 配置保存与加载
- 所有配置自动保存到 `.env` 文件
- 启动时自动加载上次的配置
- 配置项包括：
  - `STORY_OUTLINE_GEN_API`: 目录生成API
  - `STORY_STORY_GEN_API`: 故事生成API

## 使用指南

### 配置API
1. 切换到【故事生成 → 配置】标签页
2. 在"基础API配置"区域配置所需的API（API Key、Base URL、Model）
3. 点击"保存配置"保存到 .env 文件

### 选择功能API
1. 在"故事创作功能 API 配置"区域：
   - 目录生成API：选择用于生成目录的API预设
   - 故事生成API：选择用于生成故事的API预设
2. 点击"💾 保存故事创作API配置"保存设置

### 测试API
1. 配置好API后，点击"API测试"按钮
2. 在底部的"测试日志"区域查看详细的测试结果
3. 如果测试成功，会自动更新Base URL
4. 如果测试失败，日志会显示详细的错误信息和建议操作

### 使用创作功能
1. 切换到【故事生成 → 创作】标签页
2. 输入创作需求
3. 点击"📋 生成目录"：使用"目录生成API"配置的API
4. 点击"🚀 生成故事"：使用"故事生成API"配置的API

## 技术细节

### 修改的文件
1. `src/gui/mixins/story_mixin.py`
   - 添加测试日志区域
   - 添加故事创作功能API配置界面
   - 新增 `on_test_story_api()` 方法
   - 新增 `_save_story_assist_api_config()` 方法
   - 修改所有生成方法以使用选中的API

2. `src/gui/mixins/config_mixin.py`
   - 添加自动加载故事创作API配置
   - 删除旧的 `on_test_api()` 方法（已被新方法替代）

### 配置文件
所有配置保存在项目根目录的 `.env` 文件中：
```env
# 故事创作功能API配置
STORY_OUTLINE_GEN_API=DeepSeek
STORY_STORY_GEN_API=DeepSeek
```

## 优势对比

### 修改前
- API测试日志输出到创作页面，污染输出区域
- 生成目录和故事只能使用当前配置的API
- 无法灵活选择不同的API用于不同的功能
- 测试日志与创作内容混在一起

### 修改后
✅ 测试日志有专门的区域，不污染创作页面
✅ 可以为目录生成和故事生成选择不同的API
✅ 更灵活的API管理，适应不同的使用场景
✅ 界面布局更清晰，功能分区更明确
✅ 与图片生成配置页面风格统一

## 兼容性
- 完全向后兼容，不影响现有配置
- 如果没有保存故事创作API配置，默认使用"DeepSeek"预设
- 所有旧的API配置会自动迁移到新的配置方式
