# 腾讯混元提示词优化技巧

## 核心原则

**在256字符限制下，关键是"精准关键词"而非"冗长描述"**

### ✅ 好的提示词特点
1. **关键词密集**：每个词都有意义
2. **信息完整**：涵盖人物、场景、光线、构图
3. **精准表达**：用最少的字表达最多的信息
4. **结构清晰**：逗号分隔，层次分明

## 提示词公式

### 标准结构（推荐）
```
[主体] + [动作/表情] + [服饰特征] + [场景] + [光线] + [镜头] + [风格]
```

### 示例对比

#### ❌ 冗长版（效果差）
```
一个穿着白色大褂的年轻女医生坐在医院走廊的长椅上，
她看起来非常疲惫，眼神中透露出深深的疲倦，
走廊里的灯光很暗，墙壁是白色的...
（150字，但信息密度低）
```

#### ✅ 精简版（效果好）
```
深夜医院走廊，女医生白大褂坐长椅，疲惫神情，
昏暗灯光，空旷氛围，特写镜头，电影感
（42字，信息密度高）
```

## 优化技巧

### 1. 关键词替代完整句子

| 冗长表达 | 精简关键词 |
|---------|----------|
| 一个穿着白色大褂的医生 | 医生白大褂 |
| 看起来非常疲惫的样子 | 疲惫神情 |
| 走廊里的灯光很暗淡 | 昏暗灯光 |
| 空无一人的走廊 | 空旷走廊 |
| 从远处拍摄的镜头 | 远景镜头 |

### 2. 信息分层表达

#### 第一层：主体（必须）
- 人物：年龄、性别、职业、关键特征
- 示例：`25岁女医生`、`中年男子西装`

#### 第二层：动作/表情（必须）
- 动作：具体姿态
- 表情：情绪状态
- 示例：`疲惫坐姿`、`焦虑神情`

#### 第三层：场景（必须）
- 地点：具体场所
- 氛围：环境特点
- 示例：`深夜医院走廊`、`雨后街道`

#### 第四层：视觉（重要）
- 光线：时间、质感
- 镜头：角度、距离
- 示例：`昏暗灯光`、`特写镜头`

#### 第五层：风格（自动添加）
- 系统会自动根据图片类型添加
- 示例：`动漫风`、`高清摄影`

### 3. 高效关键词列表

#### 人物特征（10-15字）
```
- 外貌：25岁、中年、老年、年轻女性、帅气男子
- 服饰：白大褂、西装、便装、校服、古装
- 发型：长发、短发、马尾、寸头、披肩发
- 表情：疲惫、焦虑、微笑、严肃、惊讶
```

#### 场景环境（10-15字）
```
- 室内：医院走廊、办公室、咖啡店、教室、书房
- 室外：街道、公园、海边、山顶、广场
- 时间：深夜、黎明、正午、黄昏、傍晚
- 天气：雨天、晴天、阴天、雪天、雾天
```

#### 光线氛围（5-10字）
```
- 自然光：阳光、月光、晨光、晚霞
- 人造光：灯光、霓虹、烛光、荧光
- 质感：柔和、强烈、昏暗、明亮、对比
```

#### 构图镜头（5-8字）
```
- 距离：特写、中景、远景、全景
- 角度：俯视、仰视、平视、侧面
- 效果：景深、虚化、聚焦、广角
```

## 快速优化方法

### 步骤1：列出核心要素
```
✓ 谁（人物）
✓ 做什么（动作）
✓ 在哪里（场景）
✓ 什么时候（时间/光线）
✓ 什么感觉（氛围）
✓ 怎么拍（镜头）
```

### 步骤2：关键词提取
```
完整句子 → 关键词
"一个穿着校服的高中女生正在教室里专注地写作业"
↓
"高中女生校服，教室专注写作业"
```

### 步骤3：添加视觉细节
```
基础版："高中女生校服，教室专注写作业"
↓
增强版："午后教室，高中女生校服，专注写作业，
       阳光斜射，安静氛围，侧面中景"
```

### 步骤4：风格确认
```
选择图片类型 → 系统自动添加风格关键词
"日系动漫" → 自动添加"动漫风"
```

## 常见问题解决

### Q1: 如何在短文本中体现细节？

**A: 使用具象化关键词**
```
❌ 笼统：美丽的风景
✅ 具体：雪山湖泊晚霞倒影

❌ 笼统：很疲惫
✅ 具体：眼神疲惫额头汗珠

❌ 笼统：很有氛围
✅ 具体：昏暗灯光烟雾弥漫
```

### Q2: 多个人物怎么描述？

**A: 主次分明，突出重点**
```
✅ 单人：医生白大褂疲惫神情
✅ 双人：医生护士病房讨论，严肃表情
✅ 群体：医疗团队手术室，紧张氛围，主刀医生特写
```

### Q3: 复杂场景怎么表达？

**A: 分层描述，先主后次**
```
主体 → 行为 → 近景 → 远景 → 氛围

示例：
"咖啡店，女孩窗边读书，阳光洒进，
 街景模糊背景，温暖安静，特写镜头"
```

## 不同风格的关键词策略

### 写实照片
- 重点：光线、质感、细节
- 关键词：`高清`、`真实`、`自然光`、`景深`
- 示例：`晨光咖啡店，女孩窗边，自然光线，景深虚化，高清摄影`

### 日系动漫
- 重点：色彩、情感、氛围
- 关键词：`樱花`、`校服`、`温柔`、`清新`
- 示例：`樱花季校园，少女校服，温柔微笑，清新色调，动漫风`

### 赛博朋克
- 重点：科技感、霓虹、对比
- 关键词：`霓虹`、`雨夜`、`反光`、`高科技`
- 示例：`雨夜街道，霓虹反光，黑衣人物，高科技背景，赛博朋克`

### 中国风
- 重点：意境、留白、古韵
- 关键词：`水墨`、`古装`、`山水`、`诗意`
- 示例：`山水意境，古装女子，撑伞湖边，雾气朦胧，中国风水墨`

## 记住

**精简≠简陋，关键词≠信息少**

一个好的提示词就像俳句：
- 字数少，但意境深
- 关键词精准，画面感强
- 留白适度，让AI发挥
