# 人物一致性保存修复说明

## 问题描述

**用户反馈：**
"我刚生成的人物信息，打开后关闭就没有了"

**问题分析：**
1. 用户在一致性设定对话框中填写人物信息
2. 点击关闭或窗口X按钮
3. 数据没有保存，再次打开时信息丢失

## 问题原因

### 1. 回调机制问题
原来的实现中，关闭对话框时的回调绑定不正确：
```python
# 错误的实现
dialog.protocol("WM_DELETE_WINDOW", lambda: [on_dialog_close(), dialog.destroy()])
```

这种绑定方式在对话框关闭时无法正确获取 `dialog.result`。

### 2. 缺少保存确认
用户点击窗口X按钮时，没有询问是否保存，直接关闭。

### 3. 没有自动保存
即使点击了"保存"按钮，数据只存在内存中，没有写入项目文件。

## 修复方案

### 1. 改进关闭回调机制

**文件：** `src/gui/mixins/director_modules/director_mixin.py`

**修复前：**
```python
dialog.protocol("WM_DELETE_WINDOW", lambda: [on_dialog_close(), dialog.destroy()])
```

**修复后：**
```python
def check_dialog_result():
    """定期检查对话框是否关闭并获取结果"""
    if dialog.winfo_exists():
        # 对话框还在，继续检查
        self.after(100, check_dialog_result)
    else:
        # 对话框已关闭，获取结果
        result = dialog.result
        if result is not None:
            self.consistency_data = result
            self.status.set("✅ 一致性设定已保存")
            
            # 更新UI显示
            char_count = len(result.get("characters", {}))
            if hasattr(self, 'consistency_status_label'):
                self.consistency_status_label.config(
                    text=f"已设定 {char_count} 个人物",
                    foreground="green"
                )
            
            # 自动保存项目
            if hasattr(self, 'save_complete_project'):
                self.save_complete_project()
                print("✅ 一致性设定已自动保存到项目")
        else:
            self.status.set("❌ 未保存一致性设定")

# 开始检查
self.after(100, check_dialog_result)
```

**优点：**
- 使用定时检查机制，可靠地获取对话框结果
- 支持非模态对话框
- 自动保存到项目文件

### 2. 添加关闭确认对话框

**文件：** `src/gui/mixins/director_modules/consistency_dialog.py`

**新增方法：**
```python
def _on_window_close(self):
    """点击窗口关闭按钮时"""
    # 询问是否保存
    answer = messagebox.askyesnocancel(
        "保存设定",
        "是否保存人物一致性设定？\n\n是：保存并关闭\n否：放弃修改并关闭\n取消：继续编辑"
    )
    
    if answer is True:
        # 保存
        self._on_save()
    elif answer is False:
        # 不保存
        self.result = None
        self.destroy()
    # answer is None: 取消，不做任何操作
```

**绑定到关闭事件：**
```python
self.protocol("WM_DELETE_WINDOW", self._on_window_close)
```

### 3. 自动保存到项目

数据保存后立即调用 `save_complete_project()` 写入项目文件。

## 使用流程

### 正常保存流程

1. **打开一致性设定对话框**
   - 导演页面 → 点击"📝 编辑设定表"

2. **填写人物信息**
   - 选择或添加人物
   - 填写基本信息、外观、服装等
   - 可使用"智能填写"自动生成

3. **保存数据（三种方式）**

   **方式一：点击"保存"按钮**
   - 点击对话框底部的"保存"按钮
   - 数据保存并关闭对话框
   - ✅ 自动保存到项目文件

   **方式二：点击窗口X按钮**
   - 弹出确认对话框："是否保存人物一致性设定？"
   - 点击"是" → 保存并关闭
   - 点击"否" → 放弃修改并关闭
   - 点击"取消" → 继续编辑

   **方式三：点击"取消"按钮**
   - 弹出确认对话框："是否放弃所有修改？"
   - 点击"是" → 放弃修改并关闭
   - 点击"否" → 继续编辑

4. **验证保存成功**
   - 状态栏显示："✅ 一致性设定已保存"
   - 一致性设定区显示："已设定 X 个人物"（绿色）
   - 控制台输出："✅ 一致性设定已自动保存到项目"

5. **重新加载验证**
   - 关闭应用
   - 重新打开并加载项目
   - 再次打开一致性设定对话框
   - ✅ 所有数据都应该恢复

## 技术细节

### 数据流

```
用户填写 → _save_current_character_data()
    ↓
保存到 self.consistency_data
    ↓
点击"保存" → _on_save()
    ↓
设置 self.result = self.consistency_data
    ↓
对话框关闭 → check_dialog_result()
    ↓
检测到对话框关闭 → 获取 dialog.result
    ↓
更新 self.consistency_data = result
    ↓
调用 save_complete_project()
    ↓
写入 project.json
    ↓
状态栏显示成功
```
