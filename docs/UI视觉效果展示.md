## 视觉效果细节

### 发光效果
1. **Logo图标** - 外圈紫色发光 (2px)

## 🎨 颜色使用建议

1. **主要操作** → PRIMARY (#7C3AED)
2. **次要操作** → SURFACE_LIGHT (#2A2C4E)
3. **强调操作** → ACCENT (#0EA5E9)
4. **成功提示** → SUCCESS (#10B981)
5. **警告提示** → WARNING (#F59E0B)
6. **错误提示** → ERROR (#EF4444)
7. **一般文本** → TEXT_PRIMARY (#F8F9FC)
8. **次要文本** → TEXT_SECONDARY (#A1A8C7)
9. **强调文本** → TEXT_ACCENT (#A78BFA)

## 💡 最佳实践

### ✅ 推荐
- 使用Theme定义的颜色常量
- 遵循8px间距体系
- 保持视觉层次一致
- 使用语义化的组件名称

### ❌ 不推荐
- 硬编码颜色值
- 随意的间距数值
- 过多的视觉层级
- 不一致的圆角半径
