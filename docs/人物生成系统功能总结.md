## 🎬 完整工作流程

### 从零到完整角色设定表

```mermaid
graph TD
    A[创建项目] --> B[添加人物]
    B --> C[生成特征描述]
    C --> D[选择图片风格]
    D --> E{生成照片}
    E -->|单张| F[生成单张照片]
    E -->|批量| G[批量生成15张]
    F --> H[查看照片画廊]
    G --> H
    H --> I[生成角色设定表]
    I --> J[选择布局模板]
    J --> K[自动拼接生成]
    K --> L[预览和导出]
```

### 详细步骤

#### 步骤1：创建项目和角色
```
1. 打开应用
2. 新建项目（例如："我的小说"）
3. 切换到"人物生成"标签
4. 填写人物名称（例如："林晓梦"）
```

#### 步骤2：生成角色描述
```
1. 点击"生成特征描述"
2. AI自动生成详细外貌描述
3. 可手动编辑调整
4. 保存描述
```

#### 步骤3：生成照片
```
# 方式A：生成完整角色照片集（推荐）
1. 选择图片风格：写实照片/日系动漫等
2. ✅ 勾选"批量生成三视图"
3. ✅ 勾选"批量生成多表情"
4. 点击"生成照片"
5. 等待15张照片生成完成（约5-8分钟）

# 方式B：按需生成
1. 选择单个视角和表情
2. 点击"生成照片"
3. 重复以上步骤生成多张
```

#### 步骤4：查看和管理照片
```
1. 点击"查看所有照片"
2. 浏览生成的照片
3. 可删除不满意的照片
4. 可重新生成特定角度/表情
```

#### 步骤5：生成角色设定表
```
1. 点击"生成角色设定表"
2. 选择布局模板：
   - 标准版 (3×5) - 完整档案
   - 三视图版 (3×1) - 快速参考
   - 表情版 (5×1) - 表情研究
   - 紧凑版 (2×3) - 简化档案
3. 选择显示选项：
   ✅ 显示角度和表情标签
   ✅ 显示角色描述
4. 点击"生成"
5. 自动拼接并打开预览
```
