# 智能提示词适配器系统说明

## 📚 概述

为了确保项目的健壮性和兼容性，我们实现了一个**智能提示词适配器系统**，它能够根据不同的图像生成API（Stable Diffusion、OpenAI DALL-E、腾讯混元等）自动生成最优的提示词格式。

## 🎯 核心特性

### 1. 多API支持
- **Stable Diffusion**: 标签式提示词，支持权重和负面提示词
- **OpenAI DALL-E**: 自然语言描述，完整句子
- **腾讯混元**: 中文简短描述，关键词堆叠

### 2. 双模式优化
- **文生图（txt2img）**: 完整质量标签，详细描述
- **图生图（img2img）**: 轻量化标签，保留原图特征

### 3. 一致性增强
- 人物一致性专用标签
- 一致性负面提示词
- 权重调整系统

## 🔧 技术实现

### 核心组件：`PromptAdapter`

位置：`src/gui/mixins/director_modules/prompt_adapter.py`

#### 主要方法

```python
PromptAdapter.build_prompt_for_api(
    api_type="sd",              # API类型: "sd", "openai", "hunyuan"
    scene_description=...,       # 场景描述
    characters=[...],            # 人物列表
    character_details={...},     # 人物详细信息
    shot_type=...,              # 镜头类型
    action=...,                 # 动作
    emotion=...,                # 情绪
    is_img2img=False,           # 是否图生图
    consistency_mode=True        # 是否一致性模式
) -> (positive_prompt, negative_prompt)
```

## 📝 Stable Diffusion 提示词最佳实践

### 文生图（txt2img）提示词结构

```
1. 质量标签（前置）
   - masterpiece, best quality, ultra detailed, 8k, high resolution
   - photorealistic, cinematic lighting, professional photography
   - sharp focus, highly detailed, intricate details

2. 人物描述（高优先级）
   - 具体特征：发型、服装、表情等
   - 添加一致性标签：character consistency, same person, same face

3. 场景描述
   - 环境、光线、氛围

4. 动作和情绪
   - 具体动作：walking, sitting, smiling
   - 情绪标签：happy, sad, angry

5. 镜头类型
   - close-up shot, medium shot, wide shot
```

### 图生图（img2img）提示词策略

```
1. 轻量质量标签
   - high quality, detailed, sharp focus, professional

2. 场景融合描述
   - 重点描述新场景环境
   - 保留人物特征引用

3. 重绘幅度自适应
   - 低重绘（<0.4）：详细提示词，保留原图
   - 中等重绘（0.4-0.7）：精简提示词，平衡模式
   - 高重绘（>0.7）：完整提示词，接近文生图
```

### 负面提示词

#### 通用负面提示词
```
nsfw, lowres, bad anatomy, bad hands, text, error, 
missing fingers, extra digit, fewer digits, cropped, 
worst quality, low quality, jpeg artifacts, signature, 
watermark, username, blurry, artist name
```

#### 一致性专用负面提示词
```
multiple people, crowd, different person, changing appearance,
inconsistent clothing, inconsistent hair, inconsistent face,
different hairstyle, hair color change, different outfit,
face inconsistency, character inconsistency, multiple identities,
changing features, wrong face, wrong person
```

### 权重系统

SD支持使用括号增加关键词权重：

```python
# 标准格式
(keyword:1.2)  # 1.2倍权重
(keyword:1.5)  # 1.5倍权重

# 一致性增强示例
"(same person:1.3), (character consistency:1.3), beautiful woman, ..."
```

**权重使用建议**：
- 推荐范围：1.1 - 1.5
- 过高权重（>1.5）可能导致结果不稳定
- 只为最关键的词添加权重

## 🌐 OpenAI DALL-E 提示词特点

### 风格差异

```python
# ❌ SD风格（不适合DALL-E）
"masterpiece, best quality, beautiful woman, long hair, 
red dress, smiling, in park, sunlight, high resolution"

# ✅ DALL-E风格（自然语言）
"A professional photograph of a beautiful woman with long 
flowing hair wearing a red dress, smiling warmly in a 
sunlit park. High quality professional photography with 
cinematic lighting."
```

### DALL-E最佳实践

1. **使用完整句子**
   - 不要用逗号分隔的标签
   - 用自然语言描述场景

2. **详细但简洁**
   - 提供足够细节
   - 避免冗余描述

3. **不需要质量标签**
   - DALL-E会自动生成高质量图片
   - 只需在最后简单说明"high quality"

4. **没有负面提示词**
   - DALL-E不支持负面提示词
   - 通过正向描述来引导结果

## 🇨🇳 腾讯混元提示词特点

### 字符限制

混元对提示词长度有严格限制（约256字符），需要精简：

```python
# ❌ 过长（会被截断）
"一个美丽的女子，有着乌黑亮丽的长发，穿着红色连衣裙，脸上洋溢着灿烂的笑容，
站在阳光明媚的公园里，周围有绿树和鲜花，高质量专业摄影，电影级灯光，8K分辨率"

# ✅ 精简版
"美丽女子，长发，红色连衣裙，微笑，公园，阳光，高质量，专业摄影"
```

### 混元最佳实践

1. **关键词提取**
   - 只保留核心特征
   - 移除修饰词

2. **中文描述**
   - 使用中文提示词
   - 简短清晰

3. **质量标签简化**
   - "高质量，专业摄影，电影级"
   - 不要使用"8K"、"ultra detailed"等英文

## 🔄 集成位置

### 1. 导演页面 - 普通分镜生成

**文件**: `src/gui/mixins/director_modules/director_mixin.py`

```python
# SD API
if provider == "sd":
    optimized_prompt, negative_prompt = PromptAdapter.build_prompt_for_api(
        api_type="sd",
        scene_description=scene_desc or description,
        characters=characters,
        character_details=character_details,
        shot_type=shot_type,
        action=action,
        emotion=emotion,
        is_img2img=False,  # 文生图
        consistency_mode=True
    )

# OpenAI API
elif provider == "openai":
    optimized_prompt, _ = PromptAdapter.build_prompt_for_api(
        api_type="openai",
        scene_description=scene_desc or description,
        characters=characters,
        character_details=character_details,
        shot_type=shot_type,
        action=action,
        emotion=emotion
    )
```

### 2. SD一致性生成器 - img2img模式

**文件**: `src/gui/mixins/director_modules/sd_consistency_generator.py`

```python
# 生成img2img专用提示词
optimized_prompt, negative_prompt = PromptAdapter.build_prompt_for_api(
    api_type="sd",
    scene_description=scene_desc,
    characters=characters,
    character_details=character_details,
    shot_type=shot_type,
    action=action,
    emotion=emotion,
    is_img2img=True,  # img2img模式
    consistency_mode=True
)

# 根据重绘幅度优化
optimized_prompt = PromptAdapter.optimize_for_img2img(
    optimized_prompt, 
    denoising_strength=0.6
)

# 添加一致性权重
if characters:
    optimized_prompt = PromptAdapter.add_consistency_weights(
        optimized_prompt, 
        characters[0]
    )
```
