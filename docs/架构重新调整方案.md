# 🏗️ 架构重新调整方案 - 功能清晰分工

## 🎯 新的功能分工

### 📸 图片管理页面（人物管理）
**职责**：生成和管理所有人物形象

**功能**：
1. ✅ 提取故事中的人物
2. ✅ 生成人物描述
3. 🆕 **生成标准人物形象**
4. 🆕 **生成人物表情库**（7种表情）
   - 😊 开心
   - 😢 难过
   - 😠 愤怒
   - 😲 惊讶
   - 😨 害怕
   - 😐 中性
   - 😄 微笑
5. 🆕 **生成人物角度库**（3种角度）
   - 👤 正面
   - 👥 侧面
   - 👤‍♂️ 背面
6. ✅ 查看和管理已生成的人物图片

**存储位置**：
```

├─ 张三_标准.png
├─ 张三_开心.png
├─ 张三_难过.png
├─ 张三_愤怒.png
├─ 张三_惊讶.png
├─ 张三_害怕.png
├─ 张三_中性.png
├─ 张三_微笑.png
├─ 张三_正面.png
├─ 张三_侧面.png
├─ 张三_背面.png
└─ characters_info.json
```

### 🎬 导演页面
**职责**：使用已生成的人物图片来创作视频

**功能**：
1. ✅ 生成视频脚本
2. ✅ 一致性设定（查看人物信息，不生成）
3. ✅ 生成分镜列表
4. 🆕 **智能选择人物表情**
   - 根据分镜描述自动选择合适的表情
   - 例如：分镜中有"笑"→使用"开心"表情
5. 🆕 **使用人物图片生成分镜**
   - 读取图片管理页面生成的人物形象
   - 使用img2img保持人物一致性
6. ✅ 生成即梦AI提示词

```python
def select_character_image(character_name, shot_description):
    """根据分镜描述智能选择人物图片"""
    
    # 情感关键词映射
    emotion_map = {
        "开心": ["笑", "高兴", "喜悦", "开心"],
        "难过": ["哭", "悲伤", "难过", "失落"],
        "愤怒": ["怒", "生气", "愤怒", "暴怒"],
        "惊讶": ["惊", "震惊", "意外", "吃惊"],
        "害怕": ["怕", "恐惧", "害怕", "惊恐"],
    }
    
    # 分析分镜描述
    for emotion, keywords in emotion_map.items():
        if any(kw in shot_description for kw in keywords):
            img_path = f"projects/当前项目/characters/{character_name}_{emotion}.png"
            if os.path.exists(img_path):
                return img_path
    
    # 默认返回标准形象
    return f"projects/当前项目/characters/{character_name}_标准.png"
```

## 🎨 用户工作流程

### 完整流程

```
第1步：📖 故事页面
   └─ 生成故事

第2步：👥 图片管理页面（人物管理）
   ├─ 提取故事中的人物
   ├─ 为每个人物生成描述
   ├─ 选择人物 → 生成标准形象
   ├─ 生成表情库（7种表情）
   └─ 生成角度库（3种角度）
   
第3步：🎬 导演页面
   ├─ 生成视频脚本
   ├─ 查看人物设定（一致性设定）
   ├─ 生成分镜列表
   ├─ 生成分镜图片
   │   └─ 自动使用图片管理页面生成的人物形象
   │   └─ 智能选择合适的表情
   └─ 生成即梦AI提示词

第4步：🎥 即梦AI
   └─ 上传分镜图片 + 提示词 → 生成视频
```

## 📊 优势分析

### 新架构的优势

✅ **功能分工明确**
- 图片管理 = 生成人物
- 导演页面 = 使用人物

✅ **避免重复**
- 不需要在两个地方都能生成人物
- 一个地方生成，一个地方使用

✅ **更符合逻辑**
- 先准备素材（人物图片）
- 再创作内容（分镜视频）

✅ **易于管理**
- 所有人物图片集中管理
- 可以查看、编辑、删除

✅ **提升效率**
- 人物形象一次生成，多次使用
- 不需要每次生成分镜都重新生成人物
