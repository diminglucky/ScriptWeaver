# 即梦AI视频功能 - 快速上手指南 🎬

## 30秒快速理解

这个功能可以帮你把分镜头图片变成短视频！

**就像拍电影一样**：
1. 📸 生成每个场景的第一帧（分镜图片）
2. 🎬 系统自动生成视频提示词
3. 📋 复制提示词到即梦AI
4. ✨ 用图片作为首帧生成5秒视频
5. 🎞️ 把所有视频片段拼在一起 = 完整短视频！

## 3步完成第一个视频

### 步骤1️⃣：生成图片（在本应用中）
```
故事页 → 图片创作 → 选择分镜 → 生成图片
```

### 步骤2️⃣：复制提示词（在本应用中）
生成完图片后，在右下方找到：
```
🎬 即梦AI视频提示词
┌────────────────────────────┐
│ 307病房内深夜，主角推门... │
│ ...画面流畅自然，5秒视频   │
└────────────────────────────┘
   [📋 复制视频提示词]
```
点击按钮复制！

### 步骤3️⃣：生成视频（在即梦AI中）
1. 打开即梦AI：https://jimeng.jianying.com/
2. 选择"图生视频"
3. 上传刚才生成的图片
4. 粘贴提示词
5. 点击生成

## 实战示例

假设你的故事是：
> "深夜，护士小王在307病房值班，老人突然睁眼，眼神清澈诡异..."

### 分镜1：护士值班
```
生成图片：护士在护士台刷手机
↓
自动生成提示词：
"深夜医院走廊，护士疲惫靠台刷手机，突然抬头惊恐环顾，
 镜头固定，画面流畅自然，动作连贯，5秒视频"
↓
在即梦AI生成5秒视频
```

### 分镜2：进入病房
```
生成图片：推门进入病房
↓
自动生成提示词：
"307病房内，主角推门进入，消毒水味弥漫，老人突然睁眼，
 镜头缓慢推进，画面流畅自然，动作连贯，5秒视频"
↓
在即梦AI生成5秒视频
```

### 最后：拼接
```
视频1（5秒）+ 视频2（5秒）= 10秒短视频
```

## 常用技巧

### 🎯 技巧1：场景时长灵活调整
```
✅ 标准场景：5秒（推荐）
✅ 快速切换：3-4秒
✅ 重点场景：6-8秒
```
在提示词中修改"5秒视频"即可！

### 🎯 技巧2：增强动作效果
如果想要动作更明显，在提示词中加上：
```
"快速奔跑" "突然转身" "猛地后退" "缓缓抬头"
```

### 🎯 技巧3：推荐的视频尺寸
```
📱 抖音/快手：1080x1920（竖屏）
🖥️ B站/Youtube：1920x1080（横屏）
```
在配置页面设置好尺寸！

## 小白避坑指南 ⚠️

### ❌ 常见错误1：图片质量太差
**问题**：视频模糊、人物变形
**解决**：
- 使用高分辨率（1080x1920）
- 选择"写实照片"或"日系动漫"风格
- 多生成几次，挑最好的

### ❌ 常见错误2：提示词太长
**问题**：即梦AI理解不了
**解决**：
- 系统已自动控制在200字以内
- 如果手动修改，保持简洁

### ❌ 常见错误3：场景跳跃太大
**问题**：拼接后不连贯
**解决**：
- 相邻场景保持相似的光线
- 人物服装要一致
- 使用转场效果（剪映中）

### ❌ 常见错误4：动作不明显
**问题**：生成的视频太静态
**解决**：
- 在提示词中强化动作词
- 添加"快速"、"突然"等形容词
- 确保分镜描述中包含动作

## 高级玩法 🚀

### 1. 多角度拍摄
同一个场景，生成不同角度：
```
场景1-全景：展示整体环境
场景1-中景：人物表情特写
场景1-近景：关键物品细节
```

### 2. 慢动作效果
```
提示词加上："慢动作效果，戏剧化呈现"
```

### 3. 情绪渲染
```
恐怖：加上"阴暗诡异，诡谲光影"
温馨：加上"温暖光线，柔和氛围"
紧张：加上"快速剪辑，紧张节奏"
```
