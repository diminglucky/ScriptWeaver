# 人物一致性保持功能说明

## 功能概述

在生成连续的故事图片时，系统会自动确保所有图片中的人物特征保持一致，包括外貌、服饰、体型等固定特征。

## 使用方法

### 1. 填写角色特征

在**图片生成 → 创作**页面的"图片类型与场景补充"区域，找到**角色特征**输入框。

#### 建议填写内容：

- **基本信息**：姓名、年龄、性别
- **外貌特征**：发型、发色、肤色、体型、身高
- **面部特征**：脸型、眼睛、鼻子、嘴巴、眉毛
- **服饰风格**：常穿的服装款式、颜色、材质
- **配饰**：眼镜、首饰、手表等固定佩戴的物品
- **特殊标记**：痣、疤痕、纹身等

#### 示例1（详细版）：
```
主角李明：
- 28岁男性，身高约175cm，偏瘦体型
- 黑色短发，中分发型，发丝微卷
- 鹅蛋脸，戴金色边框圆形眼镜
- 穿深蓝色修身西装、白色长袖衬衫、黑色皮鞋
- 左手戴银色手表
```

#### 示例2（简洁版）：
```
女主角小雨，22岁，黑色长发披肩，白色连衣裙，苗条身材
```

#### 示例3（多角色）：
```
主角：25岁男警察，短寸头，警服，身材健壮
配角：50岁女医生，灰白短发，白大褂，戴眼镜
```

### 2. 生成分镜头

点击"大致分镜"、"标准分镜"或"详细分镜"按钮，系统会从故事中生成分镜列表。

### 3. 生成图片描述

1. 在分镜列表中选择一个分镜
2. 点击"✨ 从当前分镜生成"按钮
3. 系统会自动：
   - 读取您填写的角色特征
   - 结合分镜描述
   - 生成详细的图片描述
   - **自动保持人物特征一致**

### 4. 一致性保证

生成的图片描述会：
- ✅ 严格遵守您设定的人物外貌
- ✅ 保持服饰款式、颜色、材质一致
- ✅ 只改变分镜要求的动态元素（表情、动作、姿态）
- ✅ 静态特征（发型、脸型、体型、服装）完全不变

## 工作原理

### AI提示词优化

系统在生成图片描述时，会通过以下方式确保一致性：

1. **优先级最高**：将您填写的角色特征放在提示词最前面，并标记为"必须严格遵守"
2. **一致性要求**：明确告知AI必须保持：
   - 人物特征一致性（年龄、性别、发型、发色、肤色、体型、五官）
   - 服饰一致性（款式、颜色、材质、风格）
   - 只改变动态元素，静态特征不变
3. **多重强调**：在系统提示词和用户提示词中都强调人物一致性的重要性

### 动态与静态元素

#### 静态元素（保持一致）：
- 年龄、性别
- 发型、发色、发长
- 脸型、五官特征
- 肤色、体型、身高
- 服装款式、颜色、材质
- 固定配饰（眼镜、手表等）

#### 动态元素（可以改变）：
- 表情（眼神、嘴角、眉头）
- 动作（站、坐、躺、跑）
- 姿态（身体角度、手部位置）
- 临时物品（手持物品、临时配件）

## 使用技巧

### 技巧1：越详细越好

角色特征描述越详细，AI生成的一致性越好。

❌ 不够详细：
```
一个女孩
```

✅ 更好：
```
18岁女生，长发，校服
```

✅✅ 最佳：
```
18岁女高中生，黑色长直发及腰，白色衬衫配深蓝色百褶裙，身高约160cm，苗条身材，戴黑色发箍
```

### 技巧2：包含服饰细节

服饰是视觉识别的重要元素，要描述清楚。

✅ 好的服饰描述：
```
穿米白色毛衣（高领、宽松款）、深蓝色牛仔裤、白色运动鞋
```

### 技巧3：固定配饰

如果角色有标志性配饰，一定要写清楚。

✅ 示例：
```
戴银色圆形眼镜、左耳戴小型耳钉、右手戴红色手串
```

### 技巧4：特殊标记

痣、疤痕等特殊标记有助于保持识别度。

✅ 示例：
```
右眼角下方有一颗小痣，额头有浅色疤痕
```

### 技巧5：多角色区分（重要！）

如果故事有多个角色，必须明确区分每个人的特征，并使用**明确的名字或标识**。

✅ 推荐格式（按名字区分）：
```
李明：28岁男性，黑色短发，深蓝色西装，戴金边眼镜，身高175cm
王芳：25岁女性，棕色长发披肩，白色连衣裙，苗条身材，身高162cm

✅ 详细格式（分段描述）：
```
【主角】李明
- 28岁男性，身高175cm，偏瘦体型
- 黑色短发，中分，戴金色边框圆形眼镜

【女主角】王芳

- 棕色长发披肩，略带卷度
- 白色连衣裙，浅蓝色围巾，棕色皮鞋

【配角】张伟
- 35岁男性，身高180cm，健壮体型

- 黑色皮夹克，深色牛仔裤，马丁靴

## 多人物场景处理（重要功能）

### 核心原理：人物-名字绑定

系统会为每个人物建立**名字→特征**的永久绑定关系：
- 李明 → 28岁男性，黑短发，深蓝西装，戴眼镜
- 王芳 → 25岁女性，棕长发，白色连衣裙
- 张伟 → 35岁男性，光头，黑色皮夹克

### 工作流程

#### 步骤1：识别当前场景人物
系统会分析分镜描述，识别场景中出现的具体人物（根据名字或角色）。

#### 步骤2：匹配特征
为每个出现的人物，从人物设定档案中找到对应的特征。

#### 步骤3：选择性描述
**只描述当前分镜中实际出现的人物**，不在场的人物不会被提及。

#### 步骤4：保持一致性
每个人物的特征严格遵守设定，不会混淆或改变。

### 关键规则

#### ✅ 正确做法

1. **按名字匹配特征**
   - 分镜说「李明」→ 使用李明的设定
   - 分镜说「王芳」→ 使用王芳的设定
   - 分镜说「张伟」→ 使用张伟的设定

2. **只描述在场人物**
   - 场景中有谁就描述谁
   - 不在场的人不要提及

3. **多人物清楚区分**
   - 每个人单独描述
   - 特征不要混淆
   - 名字与特征对应

4. **再次出现保持一致**
   - 李明在场景1、3、5出现，每次特征一致
   - 王芳在场景2、3、5出现，每次特征一致
   - 张伟在场景4、5、6出现，每次特征一致

#### ❌ 错误做法

1. **混淆特征**
   - ❌ 把李明的眼镜描述到王芳身上
   - ❌ 把张伟的光头描述到李明身上

2. **描述不在场的人**
   - ❌ 场景2只有王芳，却描述了李明

3. **特征不一致**
   - ❌ 李明在场景1是短发，场景3变成长发
   - ❌ 王芳在场景2穿白裙子，场景3变成黑裙子（无换装说明）

4. **遗漏在场人物**
   - ❌ 场景4有三个人，但只描述了两个

## 换装处理

如果分镜中明确说明角色换装，系统会自动识别并更新服装描述，但保持其他特征不变。

### 示例：

**角色设定**：
```
李明：28岁男性，黑色短发，戴金边眼镜，通常穿深蓝色西装
```

**分镜1**：李明在办公室工作
- **生成描述**：28岁男性李明，黑色短发，戴金色边框眼镜，穿深蓝色西装...

**分镜2**：李明下班后换上运动服去跑步
- **生成描述**：28岁男性李明，黑色短发，戴金色边框眼镜，穿黑色运动服...（外貌不变，只改服装）

**分镜3**：第二天，李明又穿西装上班
- **生成描述**：28岁男性李明，黑色短发，戴金色边框眼镜，穿深蓝色西装...（换回西装）

## 注意事项

### ⚠️ 必填项

如果不填写角色特征，AI会：
- 从故事上下文中自动提取人物特征
- 尽量保持一致，但可能不够精确

**建议**：为了最佳效果，请手动填写详细的角色特征。

### ⚠️ 首次生成最重要

第一张图片的描述会成为后续图片的参考，所以：
1. 第一张图片的角色特征要写得特别详细
2. 检查第一张图片的描述是否符合预期
3. 如果不满意，修改角色特征后重新生成

### ⚠️ 不同图片类型

某些图片类型（如"水墨画"、"油画"）的风格特征可能会影响人物细节的精确度，但核心特征（发型、服饰颜色、体型）仍会保持一致。

## 腾讯混元 vs 其他模型

### 腾讯混元模式
- 描述长度：200字以内（精简）
- 强调关键特征：年龄、发型、服饰、姿态
- 适合：快速生成、中文优化

### 其他模型模式（OpenAI/DALL-E等）
- 描述长度：600-1000字（超详细）
- 包含所有细节：外貌、服饰、环境、光线、构图
- 适合：高质量图片、专业级制作

两种模式都会严格保持人物一致性，只是详细程度不同。

## 效果对比

### 未使用一致性功能
- ❌ 每张图片中人物发型、服装可能不同
- ❌ 人物年龄感、体型可能变化
- ❌ 视觉连贯性差

### 使用一致性功能
- ✅ 所有图片中人物特征完全一致
- ✅ 只有表情、动作根据情节变化
- ✅ 视觉连贯性强，像连续剧

## 常见问题

### Q1: 为什么有时候人物还是不一致？

**A**: 可能原因：
1. 角色特征描述不够详细 → 解决：增加细节描述
2. 图片生成API的限制 → 解决：尝试更换模型或增加生成次数
3. 提示词被AI误解 → 解决：修改角色特征的表述方式

### Q2: 可以中途修改角色特征吗？

**A**: 可以，但建议：
1. 修改前生成的图片可能与修改后的不一致
2. 最好在生成所有图片前确定好角色特征
3. 如果必须修改，需要重新生成之前的图片

### Q3: 多个角色怎么保持一致？

**A**: 在角色特征框中为每个角色建立"名字→特征"档案：

**推荐格式**：
```
李明：28岁男性，黑短发，深蓝西装，戴金边眼镜
王芳：25岁女性，棕长发，白色连衣裙
张伟：35岁男性，光头，黑色皮夹克
```

**系统会自动**：
1. 识别每个分镜中出现的具体人物（根据名字）
2. 为出现的人物匹配对应的特征
3. 只描述当前场景在场的人物
4. 保持每个人物的特征一致，不混淆

**示例**：
- 分镜1说「李明在办公室」→ 只描述李明，使用李明的特征
- 分镜2说「王芳在咖啡厅」→ 只描述王芳，使用王芳的特征
- 分镜3说「李明和王芳对话」→ 描述两人，分别使用各自的特征

### Q4: 某个人物在前面没出现，后面才出现，会一致吗？

**A**: 会保持一致！这是系统的核心功能之一。

**工作原理**：
1. 系统为每个人物建立永久档案（名字→特征绑定）
2. 当该人物在任何场景出现时，都会查询档案
3. 即使人物缺席多个场景，再次出现时特征完全一致

**示例**：
- 场景1-3：只有李明和王芳
- 场景4：张伟第一次出现 → 使用张伟的设定特征
- 场景5-7：张伟没出现
- 场景8：张伟再次出现 → 仍然使用张伟的设定特征，与场景4完全一致

### Q5: 如何确保不同人物的特征不会混淆？

**A**: 系统通过"名字匹配"机制确保不混淆：

**关键机制**：
1. **名字识别**：AI会识别分镜中提到的具体人物名字
2. **特征查询**：根据名字从档案中查询对应的特征
3. **独立描述**：每个人物独立描述，特征不交叉
4. **多重检查**：系统提示词中有多处强调不能混淆特征

**用户需要做的**：
- 在人物设定中使用明确的名字（如"李明"、"王芳"）
- 在分镜中也使用相同的名字（不要一会叫"李明"，一会叫"男主角"）
- 如果使用"男主角"等称呼，在人物设定中也要标注清楚

### Q6: 动作变化会影响一致性吗？

**A**: 不会。系统会：
- 识别分镜中的动作要求
- 只改变动作、姿态、表情
- 保持外貌、服饰等静态特征不变

### Q7: 多人物场景，如何确保不遗漏任何人？

**A**: 系统会自动识别所有在场人物，但您可以：

**建议做法**：
1. **分镜描述要明确**：清楚列出场景中的所有人物
   - ✅ 好：「李明、王芳、张伟三人在会议室」
   - ❌ 差：「几个人在会议室」

2. **检查生成的描述**：生成后检查是否所有人都被描述到
   
3. **手动补充**：如果AI遗漏了某人，可以手动编辑图片描述添加

### Q8: 人物名字不一致怎么办？

**A**: 名字一致性很重要！

**问题示例**：
- 人物设定中叫「李明」
- 分镜1中叫「李明」
- 分镜2中叫「男主角」
- 分镜3中叫「小李」

**结果**：AI可能无法识别这是同一个人，导致特征不一致。

**解决方案**：
1. **统一名字**：在人物设定和所有分镜中使用相同的名字
2. **主名+别名标注**：
   ```
   李明（男主角、小李）：28岁男性，黑短发，深蓝西装
   ```
3. **在分镜中尽量使用主名**：优先使用"李明"而非"男主角"
