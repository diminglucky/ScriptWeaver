# 多角度生成功能说明

## 📅 实现时间：2025-10-14

## ✨ 功能概述

本功能允许为同一个人物生成多个视角的照片（正面、侧面、背面、斜侧），大大提升人物一致性和角色设定的完整性。

---

## 🎯 主要功能

### 1. 单独视角生成
用户可以选择特定视角生成单张照片：
- **正面**：面向镜头，双眼看向镜头
- **侧面**：90度侧面，侧脸视图
- **背面**：背对镜头，背影视图
- **斜侧**：45度角，四分之三视角

### 2. 批量三视图生成 🎯
勾选"批量生成三视图"选项后，系统将自动生成：
- 正面照
- 侧面照
- 背面照

所有照片使用统一的人物描述，确保外貌一致性。

---

## 📋 使用方法

### 方法一：生成单个视角

1. 在"人物描述"页面选择一个人物
2. 在"生成参数"区域选择视角（正面/侧面/背面/斜侧）
3. 点击"🎨 生成人物照片"
4. 照片将保存为：`人物名_视角.png`（如果不是正面）

### 方法二：批量生成三视图

1. 在"人物描述"页面选择一个人物
2. 勾选"🎯 批量生成三视图（正面+侧面+背面）"
3. 点击"🎨 生成人物照片"
4. 系统将自动生成3张照片：
   - `林晓梦_正面.png`
   - `林晓梦_侧面.png`
   - `林晓梦_背面.png`

### API调用优化
- 批量生成时，顺序调用API（避免并发限制）
- 实时显示进度：`[1/3]`、`[2/3]`、`[3/3]`
- 每个角度生成后立即保存

### 提示词优化

## 💡 使用场景

### 1. 完整角色设定
为主要角色生成三视图，用于：
- 确保多场景下的一致性
- 制作角色设定表
- 作为后续生成的参考

### 2. 特殊视角需求
某些场景需要特定视角：
- 追逐场景：背面照
- 对话场景：正面照
- 观察场景：侧面照

### 3. 动画制作准备
三视图是动画制作的标准要求：
- 正面：角色识别
- 侧面：体型比例
- 背面：服装细节

## 🐛 注意事项

### 1. API调用次数
批量生成会调用多次API，请注意：
- API额度消耗
- 生成时间较长
- 网络稳定性

### 2. 文件管理
- 相同文件名会覆盖旧照片
- 建议定期备份重要照片
- 使用照片管理功能查看所有照片

### 3. 一致性限制
- AI生成有随机性
- 建议使用相同的额外描述
- 可能需要多次生成选择最佳结果
