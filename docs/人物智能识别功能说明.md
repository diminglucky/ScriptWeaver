# 🤖 人物智能识别功能说明

## 功能概述

人物智能识别功能可以自动从故事或剧本中识别所有人物，并自动填写他们的基本信息，大大简化了人物设定的工作流程。

## 主要功能

### 1. 智能识别人物 🎯
- **按钮位置**：一致性设定对话框顶部工具栏
- **功能**：一键识别故事中的所有人物
- **自动创建**：为每个识别到的人物创建设定档案

### 2. 智能填写 🤖
- **功能**：为选定的人物自动填写详细信息
- **数据来源**：从故事/剧本中分析提取
- **填写内容**：年龄、性别、职业、外貌、服装等

## 使用流程

### 步骤1：生成故事
确保在"故事生成"页面已经生成了故事内容，或者在"导演"页面已经生成了剧本。

### 步骤2：打开一致性设定
在导演页面点击"👥 编辑设定表"按钮。

### 步骤3：智能识别人物
1. 点击"🎯 智能识别人物"按钮
2. 系统会自动分析故事内容
3. 识别出所有人物并显示在进度窗口中
4. 自动创建人物档案

### 步骤4：智能填写详情
1. 人物识别完成后，会自动选择第一个人物
2. 自动触发智能填写功能
3. 填充该人物的详细信息

### 步骤5：手动调整
1. 切换到不同的人物查看信息
2. 根据需要调整或补充信息
3. 点击"保存"按钮保存设定

## 功能特点

### 🎯 智能识别
- 自动识别所有有名字的人物
- 提取人物的基本描述
- 识别人物之间的关系

### 📝 自动填写
- 年龄：识别"28岁"、"青年"、"中年"等描述
- 性别：自动判断男女
- 职业：提取"医生"、"护士"、"老师"等职业信息
- 外貌：识别发型、服装等特征
- 性格：提取性格特点描述

### 🔄 批量处理
- 一次识别所有人物
- 自动创建多个人物档案
- 批量应用基础信息

## 示例

### 输入故事
```
张强是一位28岁的年轻医生，他穿着白大褂，有着短发...
护士长李梅已经在医院工作了10年，她总是穿着整洁的护士服...
```

### 识别结果
```
识别到的人物：
• 张强: 主角，年轻医生
• 李梅: 护士长
```

### 自动填写结果
**张强**
- 年龄：28岁
- 性别：男
- 职业：医生
- 服装：白大褂
- 发型：短发

**李梅**
- 性别：女
- 职业：护士长
- 服装：护士服

## 注意事项

1. **API配置**
   - 需要先配置DeepSeek API
   - 确保API可用且有余额

2. **故事质量**
   - 故事描述越详细，识别越准确
   - 人物特征描述清晰有助于自动填写

3. **手动检查**
   - AI识别可能有遗漏或错误
   - 建议手动检查和补充信息

4. **性能考虑**
   - 长篇故事可能需要较长分析时间
   - 建议故事不超过3000字

## 优化建议

1. **故事写作技巧**
   - 首次出现人物时详细描述
   - 使用明确的人物特征词汇
   - 保持人物命名的一致性

2. **使用技巧**
   - 可以多次使用智能填写更新信息
   - 先识别人物，再逐个完善
   - 保存前预览生成效果

3. **工作流程**
   - 故事生成 → 人物识别 → 信息完善 → 保存设定 → 生成图片

通过智能识别功能，你可以快速建立完整的人物设定体系，确保在后续的图片生成中保持人物的一致性！
