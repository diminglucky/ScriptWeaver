# 人物生成质量改进说明

## 问题分析

之前生成的人物照片存在以下问题：
1. **生成多个人物** - AI经常生成2-3个人而不是单人照片
2. **特征不清晰** - 人物特征模糊，不符合描述
3. **提示词过长** - 描述过于详细导致被截断，关键信息丢失

## 改进内容

### 1. 强化单人约束 ✅

**修改文件**: `src/gui/helpers/character_prompt_builder.py`

**改进点**:
- 在提示词**最开头**添加明确的单人约束
- 中文：`"单人照片，仅一个人，{构图}"`
- 英文：`"Single person portrait photo, only one person, {composition} photo of"`
- 确保单人约束不会被截断

**位置**: 第779-780行（中文）、第851行（英文）

### 2. 智能提取核心描述 ✅

**修改文件**: `src/gui/helpers/character_prompt_builder.py`

**改进点**:
新增 `_extract_core_description()` 方法，智能提取关键视觉特征：

**优先级排序**:
1. **第一优先级**: 年龄、性别（最关键）
2. **第二优先级**: 发型、发色
3. **第三优先级**: 服装
4. **第四优先级**: 体型
5. **第五优先级**: 面部特征
6. **第六优先级**: 肤色

**特点**:
- 不再简单截断，而是提取最重要的视觉特征
- 对腾讯混元等有字数限制的API特别有效
- 确保关键信息不丢失

**位置**: 第718-788行

### 3. 优化提示词截断策略 ✅

**修改文件**: `src/gui/helpers/character_prompt_builder.py`

**改进点**:
改进 `optimize_for_api()` 函数中对腾讯混元的处理：

- **识别关键约束词**: 自动识别"单人"、"仅一个人"等约束
- **优先保留约束**: 截断时优先保留关键约束词
- **智能填充**: 剩余空间填充其他重要信息
- **最后截断**: 确保不超过256字符限制

**位置**: 第1168-1211行

### 4. 添加负向提示词 ✅

**修改文件**: `src/gui/mixins/image_modules/handlers/character_photo_generator.py`

**改进点**:
为腾讯混元添加负向提示词（Negative Prompt）：

```python
negative_prompt = "两个人，多个人，多人，一群人，couple，two people，multiple people，坐着，躺着，lying，sitting，模糊，低质量，blurry，low quality"
```

**作用**:
- 明确告诉AI不要生成什么
- 防止多人、错误姿势、低质量
- 提高生成准确性

**位置**: 第155-157行

### 5. 优化人物描述生成提示词 ✅

**修改文件**: `src/gui/mixins/image_modules/char_description.py`

**改进点**:
改进AI生成人物描述的提示词：

**之前问题**:
- 生成的描述太详细（300-500字）
- 包含大量冗余信息
- 导致最终提示词被截断

**改进后**:
- 字数严格控制在 **100-150字**
- 按优先级提取特征
- 聚焦核心视觉特征
- 避免过度修饰和冗余

**位置**: 第63-92行

## 常见问题

### Q: 为什么还是生成了多个人？

**可能原因**:
1. 人物描述中有多人暗示（如"和朋友"、"一起"等）
2. API不支持负向提示词（部分API）
3. 风格设置问题（如"群像"、"合影"风格）

**解决方法**:
- 检查人物描述，删除多人暗示
- 切换到支持负向提示词的API（如SD、腾讯混元）
- 选择"单人照"、"证件照"风格

### Q: 生成的人物和描述不符？

**可能原因**:
1. 描述太长被截断（腾讯混元256字符限制）
2. 描述不够具体（如"年轻人"太模糊）
3. API理解偏差

**解决方法**:
- 使用新版"生成特征描述"功能（更简洁聚焦）
- 在描述中明确年龄（如"30岁"而不是"年轻"）
- 尝试不同API（OpenAI理解能力更强）

### Q: 如何提高生成质量？

**建议**:
1. **简洁描述**: 使用新版描述生成（100-150字）
2. **明确年龄**: 具体年龄数字（如"10岁"、"30岁"）
3. **关键特征**: 重点描述发型、服装、体型
4. **选对API**: 根据需求选择合适的API
5. **批量生成**: 生成多张选最好的
