# 图片类型快速使用指南

## 🎨 新增图片类型一览

### 🏮 中国风系列（7种）

| 类型 | 适用场景 | 风格特点 |
|------|---------|---------|
| **国风插画** | 现代国风作品 | 精美线条、典雅色彩、现代美学 |
| **古风** | 历史古装题材 | 传统汉服、古代建筑、唐宋美学 |
| **仙侠** | 修仙奇幻故事 | 仙境云海、飘逸长袍、仙气缭绕 |
| **武侠** | 武侠江湖 | 侠客剑客、竹林烟雨、山水意境 |
| **水墨画** | 写意禅意 | 笔墨韵味、黑白灰调、留白美学 |
| **工笔画** | 精细华丽 | 精细笔法、传统颜料、层次丰富 |
| **敦煌壁画** | 佛教艺术 | 飞天仙女、唐代色彩、壁画质感 |

### 👻 恐怖悬疑系列（4种）

| 类型 | 适用场景 | 风格特点 |
|------|---------|---------|
| **恐怖** | 恐怖故事 | 阴暗诡异、诡谲光影、惊悚元素 |
| **惊悚** | 悬疑紧张 | 戏剧化光影、神秘阴影、紧张氛围 |
| **诡异** | 超现实 | 异世界感、诡谲氛围、怪异细节 |
| **悬疑** | 推理侦探 | 黑色电影、戏剧阴影、谜团感 |

### ✨ 奇幻系列（3种）

| 类型 | 适用场景 | 风格特点 |
|------|---------|---------|
| **玄幻** | 东方玄幻 | 神秘元素、灵兽异兽、修真世界 |
| **科幻** | 未来科技 | 太空场景、霓虹光效、未来都市 |
| **魔幻** | 西方魔幻 | 神话生物、魔法森林、奇幻冒险 |

## 🚀 快速上手

### 步骤1：选择或输入图片类型

**方式A：从下拉框选择**
```
图片类型: [下拉选择] → 古风 / 仙侠 / 恐怖 / ...
```

**方式B：手动输入自定义**
```
图片类型: [直接输入] → 赛璐璐动画 / 洛可可风格 / ...
```
💡 提示：下拉框显示"（可手动输入自定义类型）"

### 步骤2：填写描述信息

```
场景描述: 江南水乡，烟雨朦胧
角色特征: 白衣女子，持油纸伞，长发飘逸
```

### 步骤3：生成图片

1. 点击"✨ 从当前分镜生成" - 自动生成中文描述
2. 点击"🖼️ 生成图片" - 开始生成

## 💡 使用技巧

### 1. 中国风类型选择技巧

- **需要写意效果** → 选择"水墨画"
- **需要精细效果** → 选择"工笔画"  
- **需要现代感** → 选择"国风插画"
- **需要仙气飘逸** → 选择"仙侠"
- **需要江湖豪情** → 选择"武侠"
- **需要历史厚重** → 选择"古风"
- **需要宗教神圣** → 选择"敦煌壁画"

### 2. 恐怖悬疑类型选择技巧

- **纯粹恐吓** → "恐怖"（血腥、惊吓）
- **心理恐惧** → "惊悚"（紧张、悬念）
- **超自然** → "诡异"（超现实、怪异）
- **推理侦探** → "悬疑"（黑色电影风格）

### 3. 提高图片质量的方法

✅ **详细描述场景**
```
❌ 古代街道
✅ 江南水乡，青石板路，木质建筑，烟雨朦胧，清晨薄雾
```

✅ **强调视觉元素**
```
光线: 柔和晨光 / 昏暗烛光 / 霓虹灯光
构图: 特写镜头 / 广角全景 / 俯视视角
氛围: 宁静祥和 / 紧张诡异 / 神秘梦幻
```

✅ **使用"从当前分镜生成"**
- 系统会自动生成高质量的图片描述
- 包含专业的视觉术语和构图建议

### 4. 自定义类型最佳实践

**输入格式建议**:
- ✅ 简洁明确："洛可可风格"
- ✅ 组合风格："古风+水墨"
- ❌ 过于复杂："18世纪欧洲洛可可艺术风格带有巴洛克元素"

**描述补充**:
在"场景描述"或图片描述中详细说明风格特点：
```
图片类型: 洛可可风格
场景描述: 宫廷舞会，华丽装饰，粉色金色调，繁复花纹，精致优雅
```

## 🔧 技术说明

### API支持

- **OpenAI/DALL-E**: 使用英文风格关键词
- **腾讯混元**: 使用中文风格描述（支持256字符限制自动优化）

### 风格关键词系统

每个图片类型都配置了：
1. **英文关键词** - 用于英文API
2. **中文详细描述** - 用于腾讯混元
3. **中文简短关键词** - 用于字符限制优化

### 自动翻译优化

系统会根据图片类型自动：
- 在翻译时加入风格专业术语
- 生成符合风格的视觉描述
- 优化提示词结构

## ❓ 常见问题

**Q: 图片类型太多，怎么选？**  
A: 参考上面的"适用场景"表格，根据您的故事主题选择。

**Q: 自定义类型效果如何？**  
A: 效果取决于您的描述详细程度。建议在场景描述中充分体现风格特点。

**Q: 可以混合多种风格吗？**  
A: 可以！在图片描述中手动说明，或使用自定义类型如"古风+科幻"。

**Q: 腾讯混元的256字符限制怎么办？**  
A: 系统会自动压缩和优化，使用关键词密集型描述。

**Q: 哪些类型最适合生成中国故事？**  
A: 
- 历史题材 → 古风、工笔画
- 武侠小说 → 武侠、水墨画  
- 仙侠玄幻 → 仙侠、玄幻
- 现代故事 → 国风插画
