# 📸 多角度 + 多表情人物生成功能说明

## 🎯 功能概述

本功能支持为角色生成**多视角**和**多表情**的照片，可以批量生成完整的角色参考资料，为后续的故事配图提供丰富的素材。

---

## ✨ 核心功能

### 1️⃣ 多角度生成

支持从不同视角生成人物照片：

| 视角 | 说明 | 用途 |
|------|------|------|
| 正面 (front) | 人物正面视图 | 最常用，适合对话场景 |
| 侧面 (side) | 人物侧面轮廓 | 适合行走、思考场景 |
| 背面 (back) | 人物背影 | 适合离开、神秘场景 |
| 斜侧 (three-quarter) | 3/4侧面视图 | 最自然，适合大部分场景 |

**批量生成选项：**
- ✅ 勾选"批量生成三视图"可一次生成：正面 + 侧面 + 背面

### 2️⃣ 多表情生成

支持为人物生成不同表情状态：

| 表情 | 英文 | 特点 | 适用场景 |
|------|------|------|----------|
| 😐 中性 | neutral | 平静、自然 | 日常对话、描述性场景 |
| 😊 开心 | happy | 微笑、愉悦 | 喜剧、温馨场景 |
| 😢 悲伤 | sad | 哀愁、沮丧 | 悲剧、离别场景 |
| 😠 愤怒 | angry | 生气、激动 | 冲突、争执场景 |
| 😮 惊讶 | surprised | 惊讶、意外 | 悬疑、转折场景 |

**批量生成选项：**
- ✅ 勾选"批量生成多表情"可一次生成所有5种表情

### 3️⃣ 组合生成

**最强大的功能：同时批量生成多角度 + 多表情！**

- ✅ 同时勾选两个批量选项
- 📦 将生成：3个角度 × 5种表情 = **15张照片**
- ⏱️ 自动化流程，一次性完成

## 🖼️ 文件命名规则

生成的照片文件名会自动包含角度和表情信息：

### 单一生成
- `林晓梦.png` - 正面 + 中性（默认）
- `林晓梦_侧面.png` - 侧面 + 中性
- `林晓梦_开心.png` - 正面 + 开心

### 批量生成
- `林晓梦_正面.png` - 正面 + 中性
- `林晓梦_侧面.png` - 侧面 + 中性
- `林晓梦_背面.png` - 背面 + 中性
- `林晓梦_正面_开心.png` - 正面 + 开心
- `林晓梦_侧面_悲伤.png` - 侧面 + 悲伤
- `林晓梦_背面_愤怒.png` - 背面 + 愤怒

**规则总结：**
```
{角色名}_{角度}_{表情}.png
```
- 如果是正面 + 中性，可省略后缀
- 如果只有角度或表情，只显示对应后缀

系统使用专业的 `CharacterPromptBuilder` 构建提示词：

```python

    "side": "side profile view, 90 degree angle",
    "back": "back view, facing away",
    "three-quarter": "three-quarter view, 45 degree angle"
}
```

### 表情控制
```python
expression_prompts = {
    "neutral": "neutral expression, calm face",
    "happy": "happy smiling expression, joyful",
    "sad": "sad expression, melancholic",
    "angry": "angry expression, fierce",
    "surprised": "surprised expression, wide eyes"
}
```

### 自动优化
- **腾讯混元**：提示词限制在256字符以内
- **OpenAI DALL-E**：提示词限制在1000字符以内
- 自动翻译：中文→混元，英文→OpenAI

# 双重循环：角度 × 表情
for angle, angle_name in angles_to_generate:
    for expr, expr_name in expressions_to_generate:
        # 构建提示词
        prompt = CharacterPromptBuilder.build_character_photo_prompt(
            description=description,
            style=style,
            view_angle=angle,      # 当前角度
            expression=expr,       # 当前表情
            composition=composition,
            extra_details=extra_desc,
            language="zh" or "en"

        # 调用API生成
        img = api_client.generate(prompt)
        
        # 构建文件名

        # 保存图片

## ❓ 常见问题

### Q1: 为什么批量生成需要很长时间？
A: 每张图片都需要调用AI API生成，15张照片需要15次API调用。建议先测试3-5张，满意后再批量生成。

### Q2: 如何保证同一角色不同角度/表情的一致性？
A: 系统使用相同的角色描述，只改变角度和表情关键词，AI会尽量保持一致。未来会增加参考图功能进一步提升一致性。

### Q3: 生成的照片可以重新生成吗？
A: 可以。重新生成会覆盖同名文件。建议先备份满意的照片。

### Q4: 额外描述应该填什么？
A: 补充不会变化的外貌细节，如：
- ✅ "戴着黑框眼镜"
- ✅ "右脸有一道疤痕"
- ✅ "穿着白色衬衫"
- ❌ 不要写表情（如"面带微笑"）
