# 🚀 快速入门指南 - 新架构版

## 🎯 5分钟快速上手

### 第一次使用？跟着这个流程走！

---

## 📖 第1步：生成故事 (1分钟)

1. 打开应用，进入【📖 故事】页面
2. 输入一个主题，例如："校园青春故事"
3. 点击【生成故事】
4. 等待30秒，故事生成完成！

**提示**: 可以编辑故事内容，让它更符合你的想法

---

## 👥 第2步：创建人物 (2分钟)

### 2.1 提取人物
1. 切换到【📸 图片管理】页面
2. 点击【🔍 提取故事人物】
3. 等待10秒，人物列表出现

### 2.2 完善人物信息
1. 在列表中选择一个人物（例如"张三"）
2. 点击【✨ 生成特征描述】（等待15秒）
3. 点击【✏️ 编辑人物详情】
4. 在弹出的对话框中：
   - 基本信息：填写年龄、性别、角色
   - 外观特征：选择脸型、发型、体型等
   - 服装造型：描述衣服风格和颜色
   - 表情动作：选择默认表情
5. 点击【💾 保存】

### 2.3 生成人物形象
1. 选择生成类型：
   - **推荐新手**: ○ 表情库(7张)
   - **完整版**: ○ 完整套装(11张)
2. 点击【🎨 开始生成】
3. 等待2-3分钟（取决于选择的类型）
4. 点击【📁 查看图片库】看效果

**重要**: 对故事中的每个主要人物重复2.2和2.3步骤

---

## 🎬 第3步：创作分镜 (2分钟)

### 3.1 生成脚本和分镜
1. 切换到【🎬 导演】页面
2. 点击【📝 生成视频脚本】（等待30秒）
3. 点击【🎬 生成分镜】（等待30秒）
4. 点击【📋 查看所有分镜】查看结果

### 3.2 生成分镜图片
1. 在【步骤4：生成图片】中
2. 选择要生成的分镜（或选择"all"生成全部）
3. 点击【🖼️ 生成图片】
4. 等待系统：
   - 🧠 自动分析分镜描述
   - 🎯 智能选择最合适的人物图片
   - 🎨 使用img2img生成高质量分镜
5. 生成完成！

### 3.3 查看结果
1. 生成的图片会自动显示
2. 可以生成多次，选择最满意的

## 💡 重要提示

### ✅ 做什么

1. **完善人物信息**
   - 外观越详细，生成效果越好
   - 服装描述要清楚
   - 至少选择一个默认表情

2. **生成完整形象库**
   - 推荐生成"表情库(7张)"或"完整套装(11张)"
   - 表情越多，智能选择效果越好

3. **检查生成结果**
   - 点击【📁 查看图片库】确认形象
   - 不满意可以重新生成

### ❌ 不要做

1. **不要跳过人物设定**
   - 必须先生成人物形象，再生成分镜
   - 否则系统无法智能选择图片

2. **不要只生成标准形象**
   - 标准形象只有1张，无法应对不同表情的分镜
   - 至少生成表情库(7张)

3. **不要修改人物图片文件名**
   - 系统通过文件名识别表情和角度
   - 修改文件名会导致智能选择失效

## 🎯 最佳实践

### 人物设定技巧

**外观描述**:
- ✅ 好：瓜子脸、双眼皮大眼睛、高挺鼻梁、黑色长发
- ❌ 差：好看

**服装描述**:
- ✅ 好：深蓝色连帽卫衣、黑色休闲裤、白色运动鞋
- ❌ 差：休闲装

**生成建议**:
- 主角：完整套装(11张) - 最全面
- 配角：表情库(7张) - 常用就够
- 龙套：标准形象(1张) - 够用即可

### 分镜生成技巧

**描述要清楚**:
- ✅ 好：张三高兴地笑着说话
- ❌ 差：张三说话

**关键词**:
- 表情词：笑、哭、怒、惊、怕
- 角度词：侧面、背面、转身
- 动作词：走、跑、坐、站

## 🔧 常见问题

### Q1: 提示"未找到人物照片"？
**A**: 你需要先在【图片管理】页面生成人物形象，然后才能在导演页面生成分镜图片。

### Q2: 生成的图片人物不一致？
**A**: 确保：
1. 已在图片管理页面生成了人物形象
2. 生成了表情库或完整套装（不只是标准形象）
3. 分镜描述中包含明确的表情词

### Q3: 生成速度慢？
**A**: 
- 表情库(7张)需要2-3分钟
- 完整套装(11张)需要4-5分钟
- 每张分镜图片需要30秒-1分钟
- 这是正常的，请耐心等待

### Q4: 如何查看已生成的图片？
**A**: 
- 图片管理页面：点击【📁 查看图片库】
- 导演页面：点击【📁 查看人物图片库】
- 文件位置：`projects/项目名/characters/`
