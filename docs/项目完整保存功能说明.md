# 项目完整保存功能说明

## 功能概述

本系统现已支持**完整项目保存和加载**功能，确保您的所有创作内容都能被完整保存，下次打开时可以无缝继续工作。

## 保存内容

### 1. 故事创作数据
- 故事正文内容
- 创作参数（类型、风格、字数要求）
- 特殊要求文本
- 解析的章节信息

### 2. 导演页面数据
- 生成的剧本
- 分镜头列表
- 人物一致性设定表
- 视频提示词

### 3. 图片生成数据
- 人物列表和描述
- 场景设定
- 分镜描述
- 当前提示词（中文）

### 4. 生成的文件
- 人物照片（characters/目录）
- 场景图片（images/目录）
- 分镜图片（director/shots/目录）

### 5. 配置信息
- API配置（不含密钥）
- 图片生成设置
- 模型参数

## 使用方法

### 手动保存

1. **保存当前故事**
   - 点击项目页面的"💾 保存当前故事"按钮
   - 保存故事内容和基本参数

2. **完整保存项目**
   - 点击"💯 完整保存项目"按钮
   - 保存所有数据，包括UI中的临时内容

### 自动保存

系统已启用自动保存功能：
- **保存间隔**：每5分钟
- **保存内容**：所有已修改的内容
- **保存时机**：检测到内容变化时

### 项目加载

1. 在项目页面选择要加载的项目
2. 点击"📂 加载项目"按钮
3. 系统会自动恢复：
   - 所有文本内容到对应的编辑框
   - 配置参数到对应的选项
   - UI状态（如已设定的人物数量）

## 数据存储结构

```
项目目录/
├── project.json          # 完整项目数据（v2.0）
├── story.txt            # 故事文本（兼容旧版）
├── characters/          # 人物照片
│   ├── 角色名.png
│   └── characters_info.json
├── images/              # 场景图片
├── director/            # 导演数据
│   ├── script.txt       # 剧本
│   ├── shots.json       # 分镜
│   ├── consistency.json # 一致性设定
│   ├── video_prompt.txt # 视频提示词
│   └── shots/           # 分镜图片
```

## 版本兼容性

- **新版本（v2.0）**：使用统一的project.json存储所有数据
- **旧版本（v1.0）**：自动识别并加载分散的文件
- 系统会自动处理版本差异，确保向后兼容

## 注意事项

1. **API密钥安全**：系统不会保存API密钥，需要在配置页面重新输入
2. **图片文件**：确保项目目录中的图片文件没有被移动或删除
3. **大型项目**：包含大量图片的项目加载可能需要几秒钟
4. **修改检测**：自动保存会检测内容变化，避免不必要的保存操作

## 故障排除

### 加载失败
- 检查项目文件是否完整
- 查看控制台输出的错误信息
- 尝试使用旧版加载方式

### 保存不完整
- 确保有足够的磁盘空间
- 检查文件写入权限
- 查看状态栏的提示信息

### 自动保存未生效
- 确认已创建或加载项目
- 检查控制台是否显示"自动保存功能已启用"
- 手动点击"完整保存项目"测试功能

## 最佳实践

1. **定期手动保存**：在完成重要工作后手动保存
2. **项目命名**：使用有意义的项目名称便于管理
3. **备份重要项目**：定期备份项目文件夹
4. **检查保存状态**：注意状态栏的保存提示
