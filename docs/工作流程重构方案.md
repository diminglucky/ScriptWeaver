# 🎬 AI短视频创作工作流程重构方案

## 📊 当前问题分析

### 1. 系统架构混乱
- **图片生成有两套系统**：
  - `SceneImageGeneratorMixin`：旧系统，功能较弱
  - `SDConsistencyMixin`：新系统，支持人物一致性
  - ❌ 问题：两套系统共存，用户不知道用哪个

### 2. 人物生成不完善
- ✅ 已实现：生成单张人物标准形象
- ❌ 缺失：多表情人物照片（开心、难过、愤怒、惊讶等）
- ❌ 缺失：不同角度（正面、侧面、背面）

### 3. 工作流程不清晰
- 用户需要在多个标签页之间跳转
- 不知道下一步该做什么
- 缺少进度提示和引导

---

## ✨ 理想工作流程

```
┌─────────────────────────────────────────────────────────────┐
│                     完整的视频创作流程                        │
└─────────────────────────────────────────────────────────────┘

第一步：📖 故事生成
   ↓
   输入：主题、风格、字数
   输出：完整故事文本
   
第二步：🎬 导演改编（生成视频脚本）
   ↓
   输入：故事文本
   输出：引人入胜的视频脚本（优化叙事节奏、增加戏剧性）
   
第三步：👤 人物形象生成
   ↓
   输入：人物特征描述
   输出：每个人物的多种形象
          ├─ 基础形象（标准照）
          ├─ 表情变化（开心、难过、愤怒、惊讶、害怕、厌恶、中性）
          └─ 角度变化（正面、侧面、背面）
   
第四步：🎞️ 分镜生成
   ↓
   输入：视频脚本 + 人物信息
   输出：详细分镜列表
          ├─ 场景描述
          ├─ 人物动作
          ├─ 镜头运动
          ├─ 情感基调
          └─ 时长估算
   
第五步：🖼️ 分镜图片生成
   ↓
   输入：分镜描述 + 人物形象库
   输出：每个分镜的图片
          ├─ 使用对应人物的形象
          ├─ 根据情节选择合适表情
          └─ 保持人物一致性
   
第六步：🎥 视频提示词生成（即梦AI）
   ↓
   输入：分镜图片 + 分镜描述
   输出：每个分镜的即梦AI提示词
          ├─ 镜头运动描述
          ├─ 场景氛围
          ├─ 人物动作
          └─ 转场建议
   
第七步：📺 视频生成（即梦AI）
   ↓
   输入：分镜图片 + 即梦AI提示词
   输出：完整连贯的视频
```

## 🔧 具体实施方案

### 方案1：扩展人物形象生成功能

**目标**：为每个人物生成完整的表情库和角度库

**实现**：
1. 在 `consistency_dialog.py` 中添加"表情库生成"功能
2. 支持7种基本表情：
   - 😊 开心/喜悦
   - 😢 难过/悲伤
   - 😠 愤怒/生气
   - 😲 惊讶/震惊
   - 😨 害怕/恐惧
   - 🤢 厌恶/不快
   - 😐 中性/平静

3. 支持3种角度：
   - 正面（front view）
   - 侧面（side view）
   - 背面（back view）

**存储结构**：
```json
{
  "characters": {
    "张三": {
      "portrait_image": "path/to/standard.png",
      "expressions": {
        "happy": "path/to/happy.png",
        "sad": "path/to/sad.png",
        "angry": "path/to/angry.png",
        "surprised": "path/to/surprised.png",
        "fear": "path/to/fear.png",
        "disgust": "path/to/disgust.png",
        "neutral": "path/to/neutral.png"
      },
      "angles": {
        "front": "path/to/front.png",
        "side": "path/to/side.png",
        "back": "path/to/back.png"
      }
    }
  }
}
```

### 方案2：整合图片生成系统

**目标**：统一为一套系统，避免混乱

**实现**：
1. 保留 `SDConsistencyMixin`（更强大）
2. 废弃 `SceneImageGeneratorMixin`（功能较弱）
3. 在 `director_mixin.py` 中统一使用SD一致性生成器
4. 移除UI中的多余选项

### 方案3：优化分镜图片生成逻辑

**目标**：根据分镜描述自动选择合适的人物表情和角度

**实现**：
```python
def _select_character_image(character_name, shot_description):
    """根据分镜描述智能选择人物形象"""
    
    # 情感关键词映射
    emotion_keywords = {
        "开心": ["笑", "高兴", "喜悦", "欢乐"],
        "难过": ["哭", "悲伤", "失落", "沮丧"],
        "愤怒": ["怒", "生气", "愤怒", "暴怒"],
        "惊讶": ["惊", "震惊", "意外", "吃惊"],
        # ...
    }
    
    # 分析分镜描述，判断情感
    for emotion, keywords in emotion_keywords.items():
        if any(kw in shot_description for kw in keywords):
            return get_character_expression(character_name, emotion)
    
    # 默认返回标准形象
    return get_character_standard_image(character_name)
```

### 方案4：增强即梦AI提示词生成

**目标**：为每个分镜生成准确、连贯的视频提示词

**实现**：
1. 分析分镜图片内容
2. 提取关键元素（人物、场景、动作）
3. 生成符合即梦AI格式的提示词
4. 添加镜头运动建议
5. 确保前后分镜的连贯性

**提示词模板**：
```
【分镜{num}】
场景：{location}
人物：{characters}
动作：{action}
镜头运动：{camera_movement}
氛围：{mood}
时长：{duration}秒

即梦AI提示词：
{optimized_prompt}

转场建议：{transition}
```
