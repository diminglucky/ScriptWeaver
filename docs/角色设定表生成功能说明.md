# 📋 角色设定表生成功能说明

## 🎯 功能概述

本功能可将已生成的多角度、多表情人物照片自动拼接成专业的**角色设定表**（Character Sheet），用于角色设计、动画制作、游戏开发等场景。

---

## ✨ 核心特性

### 1️⃣ 多种布局模板

系统提供4种专业布局模板：

| 模板名称 | 布局规格 | 照片数量 | 适用场景 |
|---------|---------|---------|---------|
| 标准版 | 3视图 × 5表情 | 15张 | 完整角色设定，适合动画/游戏 |
| 三视图版 | 3视图 × 1表情 | 3张 | 快速三视图参考 |
| 表情版 | 1视图 × 5表情 | 5张 | 表情研究，适合漫画 |
| 紧凑版 | 2视图 × 3表情 | 6张 | 简化版设定表 |

### 2️⃣ 智能照片匹配

系统会自动查找并匹配角色照片：

```
优先级匹配规则：
1. {角色名}_{角度}_{表情}.png  （完全匹配）
2. {角色名}_{角度}.png         （角度匹配）
3. {角色名}_{表情}.png         （表情匹配）
4. {角色名}.png               （默认照片）
```

**如果某个位置缺少照片**：
- 显示灰色占位符
- 标注"照片缺失"
- 不影响其他照片的拼接

### 3️⃣ 专业视觉设计

#### 顶部标题区
- 深灰色背景 (#3c3c3c)
- 大字号角色名称
- 布局名称副标题

#### 照片网格区
- 自动调整尺寸并裁剪
- 灰色边框分隔
- 保持照片比例

#### 标签系统
- 顶部：角度标签（正面、侧面、背面）
- 左侧：表情标签（😐中性、😊开心等）
- 可选显示/隐藏

#### 底部描述区
- 白色背景面板
- 显示完整角色描述
- 自动文本换行（最多5行）

## 🚀 使用步骤

### 基础流程

1. **准备照片**
   - 先使用"人物生成"功能生成多角度、多表情照片
   - 建议生成至少3张（三视图）

2. **选择角色**
   - 在人物列表中点击要生成设定表的角色

3. **点击生成**
   - 点击"📋 生成角色设定表"按钮
   - 弹出布局选择对话框

4. **选择模板**
   - 选择合适的布局模板
   - 勾选显示选项
   - 点击"✅ 生成"

5. **查看结果**
   - 系统自动拼接并保存
   - 自动打开预览
   - 文件保存在 `projects/{项目名}/characters/` 目录

## 🐛 常见问题

### Q1: 生成的设定表中有些位置是灰色的？
**A:** 这说明对应位置的照片缺失。请检查：
- 照片文件名是否正确
- 是否生成了足够的角度和表情组合
- 推荐使用"批量生成三视图+多表情"功能

### Q2: 如何选择合适的布局？
**A:** 根据用途选择：
- **动画/游戏** → 标准版 (3×5)
- **快速参考** → 三视图版 (3×1)
- **漫画表情研究** → 表情版 (5×1)
- **简化档案** → 紧凑版 (2×3)

### Q3: 可以自定义布局吗？
**A:** 目前提供4种预设布局。如需自定义，可以修改 `CharacterSheetBuilder.LAYOUTS` 配置。

### Q4: 生成的设定表可以用于商业用途吗？
**A:** 取决于您使用的图片生成API的服务条款。请查阅OpenAI或腾讯混元的用户协议。

### Q5: 如何批量生成多个角色的设定表？
**A:** 目前需要手动逐个生成。未来版本可能会添加批量处理功能。
