# 图片类型选择功能说明

## 功能概述

新增了图片类型选择功能，可以在生成图片时选择不同的艺术风格，系统会根据选择的类型自动调整描述和生成参数。

## 支持的图片类型

### 1. 写实照片 📷
- **风格特点**：高清摄影作品，写实风格，自然光线，真实质感
- **适用场景**：需要逼真效果的场景、人物肖像、风景照片
- **关键词**：photorealistic, high quality photography, natural lighting, realistic, detailed, 8K

### 2. 日系动漫 🎌
- **风格特点**：日系动漫风格，精美作画，色彩鲜艳，人物可爱
- **适用场景**：动漫角色、二次元插画、漫画场景
- **关键词**：anime style, Japanese animation, vibrant colors, cel shading, anime artwork

### 3. 3D渲染 🎮
- **风格特点**：3D渲染，高品质建模，精致材质，光影逼真
- **适用场景**：游戏角色、3D场景、产品渲染
- **关键词**：3D render, CGI, octane render, unreal engine, detailed textures

### 4. 水彩画 🎨
- **风格特点**：水彩画风格，色彩柔和，笔触自然，艺术感强
- **适用场景**：艺术插画、温馨场景、梦幻效果
- **关键词**：watercolor painting, soft colors, artistic, traditional art, delicate brushstrokes

### 5. 油画 🖼️
- **风格特点**：油画质感，笔触厚重，色彩浓郁，古典艺术风格
- **适用场景**：古典场景、肖像画、艺术创作
- **关键词**：oil painting, thick brushstrokes, classical art style, rich colors, fine art

### 6. 素描 ✏️
- **风格特点**：素描风格，线条流畅，黑白灰调，光影明确
- **适用场景**：概念设计、艺术草图、简约表现
- **关键词**：sketch style, pencil drawing, line art, monochrome, artistic sketch

### 7. 赛博朋克 🌃
- **风格特点**：赛博朋克风格，霓虹灯光，未来科技感，暗黑氛围
- **适用场景**：科幻场景、未来城市、高科技环境
- **关键词**：cyberpunk style, neon lights, futuristic, dark atmosphere, high-tech, sci-fi

### 8. 蒸汽朋克 ⚙️
- **风格特点**：蒸汽朋克风格，机械齿轮，复古科技，维多利亚时代
- **适用场景**：复古科幻、工业场景、蒸汽时代
- **关键词**：steampunk style, gears and machinery, Victorian era, retro-futuristic

### 9. 像素风 🕹️
- **风格特点**：像素艺术风格，8bit/16bit画风，复古游戏美术
- **适用场景**：复古游戏、像素艺术、怀旧风格
- **关键词**：pixel art style, 8-bit/16-bit graphics, retro game art, pixelated

### 10. 中国风 🏮
- **风格特点**：中国传统绘画风格，水墨意境，古典韵味，诗意氛围
- **适用场景**：古风场景、传统文化、水墨画效果
- **关键词**：Chinese traditional painting style, ink wash painting, classical Chinese art

## 使用方法

### 基本流程

1. **选择图片类型**
   - 在【图片生成】→【创作】页面
   - 找到"图片类型与场景补充"区域
   - 从下拉框中选择想要的图片类型

2. **生成描述**
   - 填写分镜或场景信息
   - 点击【✨ 从当前分镜生成】
   - 系统会根据选择的图片类型生成相应风格的描述

3. **生成图片**
   - 检查生成的描述（可编辑）
   - 点击【🎨 生成图片】
   - 系统会根据图片类型调整翻译和生成参数

### 高级技巧

#### 技巧1：组合使用
可以在场景描述中添加更多细节：
```
场景描述：雨后的街道，霓虹灯反射在水面
图片类型：赛博朋克
```

#### 技巧2：角色一致性
在角色特征中详细描述人物：
```
角色特征：
- 主角：25岁女性，黑色短发，穿着白色衬衫
- 配角：中年男子，戴眼镜，正装
图片类型：写实照片
```

#### 技巧3：风格强化
系统会自动添加风格关键词，但也可以在描述中强调：
```
描述：古代书院，水墨晕染效果，留白意境
图片类型：中国风
```

## 工作原理

### 1. 描述生成阶段
- 系统根据选择的图片类型调整生成提示词的指令
- 加入相应的风格描述要求
- 确保描述符合该类型的视觉特点

### 2. 翻译阶段（OpenAI API）
- 翻译时会加入风格特定的英文关键词
- 使用专业术语确保准确表达风格
- 优化提示词以获得最佳生成效果

### 3. 生成阶段
- **OpenAI API**：在英文提示词中融入风格关键词
- **腾讯混元**：在中文提示词中添加风格描述，使用style参数

## 不同API的处理方式

### OpenAI / DALL-E
```
原描述：雨中的竹林小路
图片类型：水彩画

翻译后：A path through bamboo forest in the rain, 
watercolor painting, soft colors, artistic, 
traditional art, watercolor style, delicate brushstrokes
```

### 腾讯混元
```
原描述：雨中的竹林小路
图片类型：水彩画

增强描述：雨中的竹林小路，watercolor painting, 
soft colors, artistic, traditional art
（直接使用中文+风格关键词）
```

## 注意事项

### ⚠️ 风格限制
1. 不同的AI模型对某些风格的支持程度不同
2. 极端风格可能需要多次尝试才能达到理想效果
3. 建议先用默认参数测试，再调整细节

### ⚠️ API兼容性
- OpenAI DALL-E：支持所有风格
- 腾讯混元：支持所有风格，但主要靠提示词控制
- 其他兼容API：效果取决于模型能力

### ⚠️ 提示词长度
- 不要让描述过长，保持在200-300字以内
- 风格关键词会自动添加，无需重复
- 过于复杂的描述可能导致生成偏离主题

## 最佳实践

### ✅ 推荐做法

1. **明确主题**：先确定要表达的核心内容
2. **选择风格**：根据内容特点选择合适的图片类型
3. **细节补充**：在场景和角色中添加关键细节
4. **多次迭代**：如果效果不理想，调整描述重新生成

### ❌ 避免的做法

1. 不要在描述中重复风格关键词（系统会自动添加）
2. 不要混合多种冲突的风格（如"写实的像素风"）
3. 不要过度描述（让AI有发挥空间）

## 常见问题

**Q: 选择了风格但效果不明显怎么办？**
A: 可以在描述中手动强调风格特点，或者调整生成参数重试。

**Q: 可以混合多种风格吗？**
A: 建议一次只选择一种风格，混合风格可能导致效果不佳。

**Q: 腾讯混元的风格支持如何？**
A: 腾讯混元主要通过提示词控制风格，会自动添加风格关键词。

**Q: 为什么生成的图片和预期风格有差异？**
A: AI生成具有一定随机性，可以：
1. 调整描述更明确
2. 多次生成选择最佳效果
3. 尝试不同的API
