## 🎯 功能流程图

### 完整工作流程：

```
1. 故事生成页面
   ↓
2. 图片生成页面 → 人物描述标签
   ↓
3. 点击"提取故事人物" → 自动识别主要人物
   ↓
4. 选择人物 → 点击"生成特征描述" → AI生成详细描述
   ↓
5. 点击"生成人物照片" → 生成全身照
   ↓
   → 照片自动保存到 projects/项目名/characters/人物名.png
   → 描述自动保存到 projects/项目名/characters/characters_info.json
   ↓
6. 切换到"图片创作"标签
   ↓
7. 在分镜下拉框选择分镜
   ↓
   → 系统自动识别分镜中提到的人物
   → 自动选中右侧"参考人物"列表中的对应人物
   ↓
8. 编辑或生成图片描述
   ↓
9. 点击"生成图片"
   ↓
   → 系统自动将选中人物的描述添加到提示词前面
   → 强调人物外貌一致性要求
   → 生成图片时保持人物特征一致
```

## 📝 使用建议

### 为了获得最佳的人物一致性效果：

1. **生成人物描述时要详细**：
   - 包含年龄、性别、身高、体型
   - 详细描述发型、发色、面容特征
   - 明确服装款式、颜色、材质
   - 添加"主角"、"我"等标识词（对于第一人称故事）

2. **人物描述开头加标识**：
   ```
   "22岁女性实习生，主角，我，黑色齐肩短发..."
   ```
   这样智能识别更准确。

3. **分镜描述要包含人物信息**：
   - 好的分镜："主角紧张环顾，快步行走"
   - 更好的分镜："主角林晓梦紧张环顾，快步行走"

4. **检查自动选择结果**：
   - 分镜选择后查看"参考人物"列表
   - 如有遗漏可手动勾选
   - 支持多人同时选择
