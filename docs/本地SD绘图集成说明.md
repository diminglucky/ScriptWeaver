# 本地 Stable Diffusion 集成说明

## 快速开始

### 1. 启动 SD WebUI

```bash
# 确保添加 --api 参数
python launch.py --api
```

### 2. 配置环境变量

在 `.env` 文件中添加：

```ini
SD_BASE_URL=http://localhost:7860
```

### 3. 使用

1. 打开应用，进入 **图片生成** 页面
2. 点击 **⚙️ 配置** 标签
3. 在 "API预设" 下拉框中选择 **"本地 Stable Diffusion"**
4. 点击保存配置
5. 返回 **🎨 图片创作** 标签开始生成

## 功能特性

### ✨ 文生图
- 根据文字描述生成图片
- 支持所有图片类型（写实、动漫、国风等）
- 自动翻译中文为英文提示词

### 🎨 图生图  
- 上传参考图片
- 选择人物照片作为参考
- 自动使用 img2img 模式

## 参数说明

- **尺寸**: 在配置页面选择（512x512、768x768等）
- **采样步数**: 固定20步（快速生成）
- **CFG Scale**: 固定7.0（平衡质量）
- **采样器**: Euler a（快速稳定）

如需调整参数，请直接修改 `src/gui/mixins/image_modules/image_generator.py` 中的SD生成部分。

## 注意事项

1. 确保 SD WebUI 已启动且带 `--api` 参数
2. 本地SD不需要 API Key
3. 生成速度取决于您的显卡性能
4. 支持所有现有的图片类型和风格
