## 🎯 最终工作流程

```
第1步：📖 故事页面
   └─ 输入主题 → 生成故事

第2步：👥 图片管理页面
   ├─ 提取故事中的人物
   ├─ 生成人物描述
   ├─ 选择人物
   ├─ 生成标准形象
   ├─ 生成表情库（7种）
   └─ 生成角度库（3种）
   
第3步：🎬 导演页面
   ├─ 生成视频脚本
   ├─ 查看人物设定
   ├─ 生成分镜列表
   ├─ 生成分镜图片
   │   └─ 自动使用图片管理页面的人物形象
   │   └─ 智能选择合适的表情
   └─ 生成即梦AI提示词

第4步：🎥 即梦AI
   └─ 上传分镜图片 + 提示词 → 生成视频
```
