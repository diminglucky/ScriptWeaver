# 分镜头双模式生成说明

## 更新概述

新增了两种分镜头生成模式，可以根据需求选择不同详细程度的分镜数量。

## 功能特性

###  1. **双按钮设计**

将原来的单一"从故事生成分镜"按钮改为两个按钮：

- **📝 大致分镜(5-8个)** - 快速概览，覆盖主要情节
- **📝 详细分镜(15-25个)** - 细致分割，完整呈现故事

### 2. **两种分镜模式对比**

| 特性 | 大致版 (5-8个) | 详细版 (15-25个) |
|------|---------------|-----------------|
| **分镜数量** | 5-8个 | 15-25个 |
| **适用场景** | 短篇故事、快速预览、概念验证 | 长篇故事、完整叙事、商业项目 |
| **覆盖内容** | 关键情节转折和高潮时刻 | 所有重要瞬间和细节 |
| **生成速度** | 快（约10-20秒） | 较慢（约30-60秒） |
| **图片制作成本** | 低（5-8张图） | 高（15-25张图） |
| **推荐使用** | 测试想法、简单故事 | 专业项目、复杂叙事 |

## 详细说明

### 大致版分镜 (5-8个)

#### 特点
- **精选核心场景**：只选取最关键、最具代表性的镜头
- **快速制作**：适合快速验证故事视觉效果
- **成本友好**：生成图片数量少，API费用低

#### 分镜原则
✅ 包含：
- 故事开场的定场镜头
- 主要情节转折点
- 高潮时刻
- 结局关键场景

❌ 省略：
- 过渡场景
- 次要对话
- 环境细节镜头
- 人物细微表情变化

#### 适用场景
1. **短篇故事**（1000-3000字）
2. **概念测试**：快速验证故事视觉风格
3. **预算有限**：控制图片生成成本
4. **快速迭代**：需要多次调整创意

#### 示例输出
```
1. 深夜办公室 / 加班的程序员 / 敲击键盘 / 疲惫专注 / 中景，侧光
2. 电脑屏幕 / 神秘代码 / 快速滚动 / 紧张诡异 / 特写，屏幕光
3. 窗外 / 黑影闪过 / 一闪而逝 / 惊悚不安 / 全景，逆光
4. 主角转头 / 惊恐表情 / 僵硬扭头 / 恐惧震惊 / 特写，正面
5. 走廊尽头 / 陌生人影 / 缓步走来 / 诡异阴森 / 远景，低角度
```

### 详细版分镜 (15-25个)

#### 特点
- **完整覆盖**：尽可能包含故事的每个重要时刻
- **专业水准**：适合商业项目和专业作品
- **细致入微**：每个情节转折都有对应镜头

#### 分镜原则
AI会遵循以下规则细致拆分：

1. **场景转换**：每次更换地点必须新开分镜
2. **表情变化**：人物情绪有明显变化时单独成镜
3. **情节转折**：每个转折点都有独立镜头
4. **对话场景**：重要对话拆分为多个角度
5. **氛围镜头**：环境渲染和细节展示也独立成镜

#### 镜头类型丰富
包含更专业的电影级镜头语言：

- **Extreme Close-up** (大特写) - 眼神、手部细节
- **Close-up** (特写) - 面部表情
- **Medium Shot** (中景) - 半身像
- **Wide Shot** (全景) - 完整场景
- **Establishing Shot** (定场镜头) - 环境介绍
- **High Angle** (高角度) - 俯视，营造压迫感
- **Low Angle** (低角度) - 仰视，彰显力量
- **POV** (主观视角) - 第一人称视角
- **Over-the-Shoulder** (过肩镜头) - 对话场景

#### 适用场景
1. **长篇故事**（5000字以上）
2. **商业项目**：需要完整视觉呈现
3. **专业作品集**：展示叙事能力
4. **漫画/动画**：需要详细分镜脚本
5. **广告脚本**：需要精确控制每个镜头

## 使用方法

### 步骤1：准备故事内容

1. 在 **故事生成** 页面生成或粘贴故事正文
2. 确保故事有完整的情节和场景描述
3. 故事越详细，生成的分镜越精准

### 步骤2：选择分镜模式

在 **图片生成 → 创作** 页面：

#### 选择大致版
- 点击 **📝 大致分镜(5-8个)** 按钮
- 等待10-20秒
- 查看生成的5-8个核心分镜

#### 选择详细版
- 点击 **📝 详细分镜(15-25个)** 按钮
- 等待30-60秒（根据故事长度）
- 查看生成的15-25个详细分镜

### 步骤3：查看和使用分镜

生成完成后：

1. **查看所有分镜**：在"分镜列表"文本框中查看完整列表
2. **选择单个分镜**：在下拉框中选择要生成图片的分镜
3. **生成图片描述**：点击"从当前分镜生成"生成中文图片描述
4. **生成图片**：点击"生成图片"按钮制作图片

## 选择建议

### 使用大致版的情况

✅ **推荐使用大致版**当：
- 故事篇幅较短（< 3000字）
- 预算有限，需要控制成本
- 快速测试创意和视觉风格
- 制作简单的故事插图
- 个人学习和练习
- 需要快速迭代多个版本

### 使用详细版的情况

✅ **推荐使用详细版**当：
- 故事篇幅较长（> 5000字）
- 商业项目，需要完整视觉呈现
- 制作漫画或动画分镜脚本
- 展示专业作品集
- 需要精确控制每个情节的视觉表现
- 客户要求完整的分镜规划

### 组合使用策略

💡 **最佳实践**：
1. 先用**大致版**快速测试整体风格和情节
2. 确认方向后，用**详细版**生成完整分镜
3. 从详细版中挑选关键镜头制作图片
4. 根据需求调整和补充分镜

## 技术细节

### 提示词策略

#### 大致版提示词特点
- 强调"核心分镜"、"关键场景"
- 要求"概括主要情节转折"
- 数量限制严格（5-8条）
- 筛选标准：高潮和转折

#### 详细版提示词特点
- 强调"极其详细"、"每个重要瞬间"
- 提供5条详细的分镜原则
- 数量范围较大（15-25条）
- 包含专业镜头类型术语
- 要求覆盖所有重要时刻

### AI生成策略

```python
# 大致版：筛选核心
if mode == "brief":
    shot_count = "5-8"
    - 只选取关键场景
    - 情节转折点
    - 高潮时刻
    
# 详细版：全面覆盖  
elif mode == "detailed":
    shot_count = "15-25"
    - 场景转换 → 新分镜
    - 表情变化 → 新分镜
    - 情节转折 → 独立分镜
    - 对话场景 → 多角度
    - 氛围细节 → 独立镜头
```

## 常见问题

### Q: 生成的分镜数量不在预期范围怎么办？

**A:** 这是正常的，AI会根据故事内容调整：
- 故事较简单：可能生成数量偏少
- 故事复杂：可能生成数量偏多
- 一般在目标范围±2个之内

### Q: 两次生成的分镜不一样？

**A:** 这是因为：
- AI有随机性（temperature参数）
- 每次分析角度可能不同
- 可以多生成几次，选择最满意的

### Q: 能同时生成两种模式吗？

**A:** 不能同时，但可以：
1. 先生成一种，保存结果
2. 再生成另一种进行对比
3. 选择更合适的版本使用

### Q: 哪个模式更准确？

**A:** 两者各有优势：
- **大致版**：抓大放小，突出核心
- **详细版**：面面俱到，完整呈现
- 没有绝对的"更准确"，根据需求选择

### Q: 成本差异有多大？

**A:** 主要差异在后续图片生成：
- 大致版：5-8张图 ≈ $0.10-0.16 (DALL-E-3)
- 详细版：15-25张图 ≈ $0.30-0.50
- 分镜生成本身成本相近
