## 🐛 遇到的问题与修复

### 问题1: `_show_style_menu` 方法缺失

**错误信息**:
```
AttributeError: '_tkinter.tkapp' object has no attribute '_show_style_menu'
```

**原因**:
- 删除了 `PromptOperationsMixin`
- 但故事生成页面的风格选择功能依赖此方法

**修复方案**:
✅ 恢复 `PromptOperationsMixin` 到 `ImageMixin`
- 这是通用的提示词辅助功能
- 故事页面确实需要风格选择

### 问题2: `_on_generate_character_photo` 方法缺失

**错误信息**:
```
AttributeError: '_tkinter.tkapp' object has no attribute '_on_generate_character_photo'
```

**原因**:
- 删除了 `CharacterPhotoMixin`
- 但人物管理页面UI仍引用此方法

**修复方案**:
✅ 重构人物管理页面UI
- 移除旧的"生成人物照片"按钮
- 添加友好的功能迁移提示
- 添加"前往导演页面"引导按钮
- 保留角色设定表生成功能

**新的UI设计**:

## 📌 关键设计决策

### 1. 为什么保留 `PromptOperationsMixin`？
- 故事生成页面需要风格选择功能
- 这是通用的提示词辅助工具
- 不影响图片生成系统的整合

### 2. 为什么不完全删除人物管理页面？
- 用户需要一个地方查看和管理人物信息
- 人物提取和描述生成功能有价值
- 通过引导按钮实现功能统一

### 3. 为什么统一到 SD 一致性系统？
- 支持人物一致性（最重要）
- 支持参考图（img2img）
- 质量最优
- 功能最强大
