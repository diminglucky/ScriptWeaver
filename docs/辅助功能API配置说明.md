# 辅助功能API配置说明

## 功能概述

在图片生成的**配置**页面，新增了"辅助功能 API 配置"模块，允许您为以下两个功能单独选择使用的聊天API：

1. **分镜头生成**：从故事文本生成分镜头列表
2. **图片描述生成**：从选中的分镜生成详细的图片描述

## 配置位置

**图片生成** → **配置** → **🤖 辅助功能 API 配置（使用聊天模型）**

## 功能特点

### 1. 共享API Key
- 辅助功能使用的API Key与故事生成页面配置的API相同
- 无需重复配置API Key，只需在故事生成页面配置一次即可

### 2. 灵活选择
- **分镜头生成API**：用于生成大致/标准/详细分镜头
- **图片描述生成API**：用于生成精简/详细的图片描述

### 3. 独立设置
- 可以为不同任务选择不同的模型
- 例如：用 DeepSeek 生成分镜，用 OpenAI GPT-4 生成图片描述

## 使用步骤

### 步骤1：配置故事生成API
1. 进入**故事生成** → **配置**页面
2. 选择要使用的API预设（如 DeepSeek、OpenAI、Moonshot等）
3. 填写API Key、Base URL和Model
4. 点击"保存API配置"

### 步骤2：配置辅助功能API
1. 进入**图片生成** → **配置**页面
2. 在"辅助功能 API 配置"区域：
   - **分镜头生成API**：从下拉框选择用于生成分镜的API
   - **图片描述生成API**：从下拉框选择用于生成图片描述的API
3. 点击"💾 保存辅助API配置"

### 步骤3：使用功能
1. 在**图片生成** → **创作**页面
2. 点击"大致分镜"、"标准分镜"或"详细分镜"按钮 → 使用选中的**分镜头生成API**
3. 选择一个分镜后，点击"从当前分镜生成"按钮 → 使用选中的**图片描述生成API**

## 配置示例

### 场景1：全部使用DeepSeek
```
分镜头生成API: DeepSeek
图片描述生成API: DeepSeek
```
**优点**：配置简单，成本低

### 场景2：混合使用
```
分镜头生成API: DeepSeek
图片描述生成API: OpenAI (GPT-4)
```
**优点**：用DeepSeek快速生成分镜（便宜），用GPT-4生成高质量图片描述（精准）

### 场景3：使用国产模型
```
分镜头生成API: Moonshot (月之暗面)
图片描述生成API: 智谱AI
```
**优点**：支持国产大模型，符合合规要求

## 配置保存

配置会自动保存到项目根目录的 `.env` 文件中：

```env
# 辅助功能API配置
ASSIST_SHOT_GEN_API=DeepSeek
ASSIST_DESC_GEN_API=OpenAI
```

下次启动应用时会自动加载上次的配置。

## 常见问题

### Q1: 为什么要单独配置辅助功能API？
**A**: 不同的AI模型有不同的特长：
- **DeepSeek**：性价比高，适合大量分镜生成
- **GPT-4**：理解能力强，适合生成精准的图片描述
- **Claude**：细节描述丰富，适合艺术风格图片描述

### Q2: 提示"请先在故事生成页面配置API Key"怎么办？
**A**: 
1. 先到**故事生成** → **配置**页面
2. 选择对应的API预设
3. 填写API Key并保存
4. 返回图片生成页面重试

### Q3: 我能为所有功能使用同一个API吗？
**A**: 可以。只需在辅助功能API配置中，将两个下拉框都选择同一个API即可。

### Q4: 如何知道哪个API适合我？
**A**: 建议测试流程：
1. 先用DeepSeek测试（快速、便宜）
2. 如果效果满意，继续使用
3. 如果需要更高质量，尝试GPT-4或Claude
4. 如果需要支持国产，使用Moonshot、智谱AI等

## 技术说明

### 实现原理
1. 辅助功能从 `self.api_presets` 读取可用的API列表
2. 用户选择的API配置保存到 `.env` 文件
3. 生成时，从 `api_presets[selected_api]` 获取API Key和配置
4. 使用 `DeepSeekClient` 初始化，传入对应的API配置

### 兼容性
- 所有聊天API都通过 `DeepSeekClient` 调用
- 只要API兼容OpenAI格式，就可以使用
- 支持自定义Base URL和Model
