# 代码重构方案 - GUI模块化

## 当前问题

`src/gui_app.py` 文件过大（约3000行），包含了所有功能：
- 项目管理
- 故事生成  
- 图片生成
- 知识库管理
- API配置

这导致代码难以维护和理解。

## 重构方案

### 1. 目录结构

```
src/
├── gui_app.py           # 保留兼容性入口（简化版）
├── gui_app_backup.py    # 原文件备份
└── gui/                 # 新的模块化代码
    ├── __init__.py
    ├── utils.py         # 工具函数
    ├── config_manager.py # 配置管理
    ├── mixins/          # 功能模块
    │   ├── __init__.py
    │   ├── project_mixin.py  # 项目管理
    │   ├── story_mixin.py    # 故事生成
    │   ├── image_mixin.py    # 图片生成
    │   └── kb_mixin.py       # 知识库
    └── main_window.py   # 主窗口
```

### 2. Mixin模式

使用Mixin模式组织代码：

```python
# src/gui/mixins/project_mixin.py
class ProjectMixin:
    """项目管理功能"""
    
    def _build_project_page(self):
        # 构建项目管理页面
        pass
    
    def _on_new_project(self):
        # 创建新项目
        pass
    
    def _on_load_project(self):
        # 加载项目
        pass
    
    # ... 其他项目相关方法

# src/gui/mixins/story_mixin.py  
class StoryMixin:
    """故事生成功能"""
    
    def _build_story_page(self):
        # 构建故事页面
        pass
    
    def on_generate_outline(self):
        # 生成大纲
        pass
    
    def on_generate(self):
        # 生成故事
        pass
    
    # ... 其他故事相关方法

# src/gui/mixins/image_mixin.py
class ImageMixin:
    """图片生成功能"""
    
    def _build_image_page(self):
        # 构建图片页面
        pass
    
    def _on_img_generate(self):
        # 生成图片
        pass
    
    # ... 其他图片相关方法
```

### 3. 主窗口类

```python
# src/gui/main_window.py
from tkinter import tk
from .mixins import ProjectMixin, StoryMixin, ImageMixin, KBMixin
from .config_manager import ConfigManager

class MainWindow(tk.Tk, ProjectMixin, StoryMixin, ImageMixin, KBMixin):
    """主窗口 - 组合所有功能"""
    
    def __init__(self):
        super().__init__()
        self.config_manager = ConfigManager()
        self._build_ui()
    
    def _build_ui(self):
        # 创建标签页
        self.notebook = ttk.Notebook(self)
        
        # 各个功能页面由Mixin提供
        self._build_project_page()
        self._build_story_page()
        self._build_image_page()
        
        self.notebook.pack(fill=BOTH, expand=True)
```

### 4. 兼容性入口

```python
# src/gui_app.py (简化版)
from src.gui.main_window import MainWindow as App

# 保持原有的导出方式
__all__ = ['App']
```

## 优势

1. **模块化**: 每个功能独立，职责清晰
2. **易维护**: 修改某功能只需编辑对应文件
3. **易测试**: 每个Mixin可独立测试
4. **易扩展**: 添加新功能只需创建新Mixin
5. **向后兼容**: 保持原有API不变

## 注意事项

1. 保留 `gui_app_backup.py` 作为参考
2. 逐步迁移，每次迁移后测试
3. 注意Mixin之间的依赖关系
4. 共享状态通过实例变量传递
