# 图片预览优化说明

## 更新概述

优化了图片预览功能，解决了只能看到部分图片的问题，现在可以完整查看生成的图片。

## 问题描述

### 之前的问题

- ❌ 预览区域只能显示图片的一部分
- ❌ 无法看到完整的图片内容
- ❌ 没有滚动条支持
- ❌ 缩放比例计算不准确
- ❌ 图片超出预览区域时被裁切

### 用户体验

生成图片后，只能看到图片的一小部分，需要手动保存后在外部查看完整图片，非常不便。

## 解决方案

### 1. **添加Canvas和滚动条支持**

将简单的Label预览改为Canvas + 滚动条的组合：

**之前**：
```python
self.img_preview = ttk.Label(grp_preview, text="...")
self.img_preview.pack(fill=BOTH, expand=True)
```

**现在**：
```python
# 创建Canvas
self.img_canvas = tk.Canvas(preview_frame, ...)

# 添加垂直和水平滚动条
v_scroll = ttk.Scrollbar(preview_frame, orient="vertical")
h_scroll = ttk.Scrollbar(preview_frame, orient="horizontal")

# 在Canvas上创建图片显示区域
self.img_preview = ttk.Label(self.img_canvas, ...)
```

### 2. **智能缩放算法**

改进了图片缩放逻辑，确保：
- ✅ 保持宽高比
- ✅ 自适应预览区域大小
- ✅ 小图片不放大（保持原尺寸）
- ✅ 大图片智能缩小以完整显示
- ✅ 使用高质量的LANCZOS重采样

**缩放逻辑**：
```python
# 计算缩放比例（取较小的比例以确保图片完全显示）
scale_w = max_w / orig_w
scale_h = max_h / orig_h
scale = min(scale_w, scale_h, 1.0)  # 不放大，只缩小

if scale < 1.0:
    # 图片较大，缩放
    img.thumbnail((new_w, new_h), Image.Resampling.LANCZOS)
else:
    # 图片较小，保持原尺寸
    img = self.img_last_image.copy()
```

### 3. **自动居中显示**

图片会自动在预览区域中居中显示：
- 图片宽度小于预览区域：水平居中
- 图片高度小于预览区域：垂直居中
- 图片超出预览区域：通过滚动条查看

### 4. **响应式调整**

窗口大小改变时，图片会自动重新缩放以适应新的预览区域：
```python
self.img_canvas.bind('<Configure>', self._on_canvas_configure)
```

## 新功能特性

### 1. **完整图片显示**
- 无论图片多大，都能完整查看
- 自动缩放以适应预览区域
- 保持原始宽高比

### 2. **滚动条支持**
- 垂直滚动条：图片高度超出时显示
- 水平滚动条：图片宽度超出时显示
- 支持鼠标滚轮滚动

### 3. **自适应缩放**
- 窗口变大：图片自动放大（但不超过原尺寸）
- 窗口变小：图片自动缩小以完整显示
- 实时响应窗口大小变化

### 4. **高质量渲染**
- 使用LANCZOS重采样算法
- 保证缩放后的图片质量
- 避免锯齿和模糊

### 5. **智能居中**
- 小图片自动居中显示
- 大图片靠左上角，通过滚动查看
- 视觉效果更美观

## 使用方法

### 生成图片后自动预览

1. 在"图片生成 → 创作"页面
2. 点击 **🎨 生成图片** 按钮
3. 图片生成后自动在右侧预览区显示
4. 如果图片较大，会自动缩放以完整显示

### 查看大图

如果图片被缩放了：
- 使用滚动条查看图片的各个部分
- 或点击 **💾 保存** 按钮保存原图查看

### 调整预览大小

- 拖动窗口边缘改变窗口大小
- 预览区域会自动调整
- 图片会重新缩放以适应新的大小

## 技术细节

### Canvas布局结构

```
预览区域 (grp_preview)
└── 框架 (preview_frame)
    ├── Canvas (img_canvas)
    │   └── Label (img_preview)  ← 图片显示在这里
    ├── 垂直滚动条 (v_scroll)
    └── 水平滚动条 (h_scroll)
```

### 缩放计算

```python
# 获取Canvas尺寸
canvas_width = self.img_canvas.winfo_width()
canvas_height = self.img_canvas.winfo_height()

# 留出边距
max_w = canvas_width - 20
max_h = canvas_height - 20

# 计算缩放比例
scale_w = max_w / orig_w
scale_h = max_h / orig_h
scale = min(scale_w, scale_h, 1.0)
```

### 居中计算

```python
# 水平居中
if new_w < canvas_width:
    x_offset = (canvas_width - new_w) // 2
else:
    x_offset = 0

# 垂直居中
if new_h < canvas_height:
    y_offset = (canvas_height - new_h) // 2
else:
    y_offset = 0
```

## 性能优化

### 1. **延迟更新**
- 窗口大小改变时不会频繁重新缩放
- 使用事件绑定，只在需要时更新

### 2. **高效缩放**
- 使用PIL的thumbnail方法
- 原地修改，避免内存浪费
- 使用LANCZOS算法平衡质量和速度

### 3. **内存管理**
- 只保留一份原图（img_last_image）
- 显示图片使用缩放后的副本
- 及时释放旧的PhotoImage对象

## 注意事项

### 1. **首次显示**
Canvas初始化需要时间，第一次显示可能有轻微延迟。

### 2. **超大图片**
- 原图始终保存在内存中（用于保存）
- 显示时使用缩放版本
- 非常大的图片（如4K+）可能消耗较多内存

### 3. **窗口大小**
- 建议窗口宽度至少800像素
- 窗口太小时图片会被大幅缩小
- 可以最大化窗口以获得最佳预览效果

## 故障排查

### 问题1: 图片显示不出来

**原因**: Canvas未正确初始化

**解决**:
- 重启应用
- 检查是否有错误日志
- 确认PIL库已正确安装

### 问题2: 滚动条不显示

**原因**: 图片小于预览区域

**解决**:
- 这是正常的，小图片不需要滚动条
- 只有当图片超出预览区域时才显示滚动条

### 问题3: 图片质量模糊

**原因**: 缩放比例过小

**解决**:
- 放大窗口以获得更大的预览区域
- 使用"保存"功能查看原图
- 原图质量不受影响
