### 1. 智能提示词适配器系统

#### 新增文件
- `src/gui/mixins/director_modules/prompt_adapter.py`
- `docs/智能提示词适配器说明.md`

#### 核心功能
实现了一个智能提示词适配器系统，能够根据不同的图像生成API自动生成最优格式的提示词。

**支持的API类型**：
- **Stable Diffusion (SD)**: 
  - 标签式提示词（逗号分隔）
  - 支持质量标签、权重调整
  - 完善的负面提示词系统
  
- **OpenAI DALL-E**:
  - 自然语言完整句子
  - 不使用负面提示词
  
- **腾讯混元**:
  - 中文简短描述
  - 关键词堆叠，256字符限制

#### 双模式优化

**文生图（txt2img）模式**：
```python
质量标签 = [
    "masterpiece", "best quality", "ultra detailed", "8k",
    "high resolution", "photorealistic", "cinematic lighting",
    "professional photography", "sharp focus", "highly detailed",
    "intricate details"
]
```

**图生图（img2img）模式**：
```python
质量标签 = [
    "high quality", "detailed", "sharp focus", "professional"
]
# 更轻量化，保留原图特征
```

#### 一致性增强系统

**一致性专用标签**：
- `character consistency`
- `consistent character design`
- `same person`
- `same face`

**权重增强**：
```python
# SD权重语法：(keyword:weight)
"(same person:1.3), (character consistency:1.3), ..."
```

**一致性负面提示词**：
```
multiple people, crowd, different person, changing appearance,
inconsistent clothing, inconsistent hair, inconsistent face,
different hairstyle, hair color change, different outfit,
face inconsistency, character inconsistency, multiple identities,
changing features, wrong face, wrong person
```

#### 2.2 SD一致性生成器 - img2img模式
**文件**: `src/gui/mixins/director_modules/sd_consistency_generator.py`

**集成点**：`_generate_shot_with_sd_consistency` 方法

**img2img 提示词优化**：
```python
# 生成img2img专用提示词
optimized_prompt, negative_prompt = PromptAdapter.build_prompt_for_api(
    api_type="sd",
    scene_description=scene_desc,
    characters=characters,
    character_details=character_details,
    shot_type=shot_type,
    action=action,
    emotion=emotion,
    is_img2img=True,  # img2img模式
    consistency_mode=True
)

# 根据重绘幅度优化提示词
optimized_prompt = PromptAdapter.optimize_for_img2img(
    optimized_prompt, 
    denoising_strength=0.6
)

# 添加一致性权重
if characters:
    optimized_prompt = PromptAdapter.add_consistency_weights(
        optimized_prompt, 
        characters[0]
    )

# 将优化后的提示词注入到shot中
shot['_optimized_prompt'] = optimized_prompt
shot['_optimized_negative'] = negative_prompt
```

**在 `generate_shot_with_consistency` 中使用**：
```python
# 构建基础提示词 - 优先使用优化后的提示词
if '_optimized_prompt' in shot:
    base_prompt = shot['_optimized_prompt']
    print(f"✅ 使用优化后的img2img提示词")
else:
    base_prompt = self._build_shot_prompt(shot, consistency_data)
    print(f"⚠️ 使用默认提示词")

# img2img调用时使用优化后的负面提示词
neg_prompt = shot.get('_optimized_negative', self._get_scene_negative_prompt())

images = self.sd_client.img2img(
    init_image=ref_image,
    prompt=base_prompt,
    negative_prompt=neg_prompt,
    denoising_strength=0.6,
    ...
)
```

### 3. 错误修复

#### 问题描述
应用启动后加载项目时报错：
```
加载项目失败：'tkinter.tkapp' object has no attribute 'ref_character_listbox'
```

#### 原因分析
在项目加载过程中，某些方法（如 `_auto_select_characters_from_shot`、`_update_reference_character_list` 等）被调用，但此时UI组件 `ref_character_listbox` 可能还未初始化。

#### 修复方案
在所有使用 `ref_character_listbox` 的方法中添加 `hasattr` 保护性检查。

#### 修复文件

**1. `src/gui/mixins/image_modules/shot_manager.py`**
```python
def _auto_select_characters_from_shot(self, shot_text: str, description: str = "") -> None:
    """智能识别分镜中的人物并自动选中（支持名字、别名、特征匹配）"""
    try:
        # ✅ 添加保护性检查
        if not hasattr(self, 'ref_character_listbox'):
            print(f"⚠️ ref_character_listbox 不存在，跳过自动选择人物")
            return
        
        # ... 后续逻辑 ...
```

**2. `src/gui/mixins/image_modules/char_extract.py`**
```python
def _get_selected_reference_characters(self) -> list:
    """获取选中的参考人物列表"""
    # ✅ 添加保护性检查

        print(f"⚠️ ref_character_listbox 不存在，返回空列表")
        return []
    
    # ... 后续逻辑 ...
```

**3. `src/gui/mixins/image_modules/char_utils.py`**
```python

    """更新图片创作页面的参考人物列表（仅当前项目，支持多选）"""
```
