## 🎯 用户工作流程

### 完整流程（清晰版）

```
第1步: 📖 故事页面
   └─ 输入主题 → 生成故事

第2步: 👥 图片管理页面 - 人物管理
   ├─ 点击【提取故事人物】
   ├─ 选择人物 → 生成人物描述
   ├─ 选择生成类型：
   │   ○ 标准形象 (1张)
   │   ○ 表情库 (7张)
   │   ○ 角度库 (3张)
   │   ○ 完整套装 (11张)
   ├─ 点击【🎨 开始生成】
   └─ 点击【📁 查看图片库】查看结果
   
第3步: 🎬 导演页面
   ├─ 生成视频脚本
   ├─ 点击【一致性设定】
   │   └─ 在【📸 图片库】中查看已生成的人物照片
   ├─ 生成分镜列表
   ├─ 生成分镜图片
   │   └─ 系统自动使用图片管理页面生成的人物照片
   │   └─ 根据分镜描述智能选择合适的表情
   └─ 生成即梦AI提示词

第4步: 🎥 即梦AI
   └─ 上传分镜图片 + 提示词 → 生成视频
```
