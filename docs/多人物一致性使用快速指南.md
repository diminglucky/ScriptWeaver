# 多人物一致性使用快速指南

## 🎯 核心功能

AI能够自动识别故事中的不同人物，为每个人物建立"名字→特征"档案，确保：
- 每个人物在所有出现的场景中保持外貌、服饰一致
- 某人物即使缺席多个场景，再次出现时特征完全不变
- 多人物同框时，不会混淆彼此的特征
- 只描述当前场景中实际出现的人物

## 📝 快速上手（3步）

### 第1步：填写角色特征

在**图片生成 → 创作**页面，找到"角色特征"输入框。

#### 单人物示例：
```
李明：28岁男性，黑色短发，身高约175cm，穿深蓝色西装白衬衫，戴金色边框眼镜
```

#### 多人物示例（推荐格式）：
```
李明：28岁男性，黑色短发，深蓝色西装，戴金边眼镜，身高175cm
王芳：25岁女性，棕色长发披肩，白色连衣裙，苗条身材，身高162cm
张伟：35岁男性，光头，黑色皮夹克，健壮体型，身高180cm
```

💡 **关键提示**：
- 必须给每个人物一个明确的**名字**（如：李明、王芳）
- 描述要包含：年龄、性别、发型、发色、服饰、体型
- 越详细越好，最好包括身高、配饰、特殊标记

### 第2步：生成分镜

点击"大致分镜"、"标准分镜"或"详细分镜"按钮。

系统会从故事中生成分镜列表，每个分镜会提到具体出现的人物。

### 第3步：生成图片描述

1. 在下拉框中选择一个分镜
2. 点击"✨ 从当前分镜生成"按钮
3. 系统会自动：
   - 识别该分镜中出现的人物（根据名字）
   - 为每个人物匹配对应的特征
   - 只描述在场的人物，不在场的不描述
   - 生成详细的图片描述，保持一致性

## 🔍 工作原理

### 人物档案系统

系统内部会建立这样的档案：

```
【人物档案】
├── 李明
│   ├── 年龄：28岁
│   ├── 性别：男性
│   ├── 发型：黑色短发
│   ├── 服饰：深蓝色西装、白衬衫
│   └── 配饰：金边眼镜
│
├── 王芳
│   ├── 年龄：25岁
│   ├── 性别：女性
│   ├── 发型：棕色长发披肩
│   └── 服饰：白色连衣裙
│
└── 张伟
    ├── 年龄：35岁
    ├── 性别：男性
    ├── 发型：光头
    └── 服饰：黑色皮夹克
```

### 场景识别流程

#### 场景1：李明独自在办公室
- **分镜**: 李明坐在办公桌前工作
- **系统识别**: 只有"李明"
- **生成描述**: 只描述李明，使用档案中李明的所有特征
- **结果**: ✅ 28岁男性李明，黑色短发，深蓝西装...

#### 场景2：王芳在咖啡厅
- **分镜**: 王芳坐在咖啡厅等人
- **系统识别**: 只有"王芳"
- **生成描述**: 只描述王芳，使用档案中王芳的所有特征
- **结果**: ✅ 25岁女性王芳，棕长发，白裙子...
- **注意**: 李明没出现，所以不描述李明

#### 场景3：李明和王芳见面
- **分镜**: 李明走进咖啡厅，与王芳握手
- **系统识别**: "李明"和"王芳"
- **生成描述**: 分别描述两人，各自使用对应的档案特征
- **结果**: ✅ 28岁男性李明，黑短发，深蓝西装...；25岁女性王芳，棕长发，白裙子...

#### 场景4：张伟登场
- **分镜**: 张伟推门而入
- **系统识别**: "张伟"、"李明"、"王芳"
- **生成描述**: 描述三人，各自使用对应的档案特征
- **结果**: ✅ 35岁男性张伟，光头，黑夹克...；李明和王芳的特征与之前完全一致

#### 场景5：张伟第二天单独训练（李明、王芳不在）
- **分镜**: 张伟在健身房举铁
- **系统识别**: 只有"张伟"
- **生成描述**: 只描述张伟，使用档案中张伟的特征
- **结果**: ✅ 35岁男性张伟，光头，健壮体型...（基本特征与场景4一致）

## ✅ 一致性保证

| 特征类型 | 是否一致 | 说明 |
|---------|---------|------|
| 名字 | ✅ 固定 | 李明就是李明，不会混淆 |
| 年龄性别 | ✅ 固定 | 28岁男性，始终如此 |
| 发型发色 | ✅ 固定 | 黑色短发，不会突然变长发 |
| 脸型五官 | ✅ 固定 | 鹅蛋脸、大眼睛，始终如此 |
| 体型身高 | ✅ 固定 | 175cm偏瘦，不会变成180cm健壮 |
| 服饰风格 | ✅ 固定 | 深蓝西装，除非明确换装 |
| 表情 | 🔄 可变 | 根据情节：微笑→皱眉→惊讶 |
| 动作姿态 | 🔄 可变 | 根据情节：站→坐→跑 |

## ⚠️ 重要提示

### ✅ 做这些：

1. **使用明确的名字**
   ```
   ✅ 李明：28岁男性...
   ✅ 王芳：25岁女性...
   ```

2. **保持名字一致**
   - 人物设定：李明
   - 分镜1：李明在办公室
   - 分镜2：李明回家 ← 都用"李明"

3. **描述要详细**
   ```
   ✅ 李明：28岁男性，黑色短发中分，鹅蛋脸，戴金色边框圆眼镜，
           身高175cm偏瘦，穿深蓝色修身西装配白衬衫，黑色皮鞋
   ```

### ❌ 不要这样：

1. **名字不一致**
   ```
   ❌ 人物设定：李明
      分镜1：李明
      分镜2：男主角 ← AI可能认不出这是同一人
   ```

2. **描述太简略**
   ```
   ❌ 一个男人 ← 太模糊
   ❌ 主角，年轻人 ← 没有具体特征
   ```

3. **混淆人物**
   ```
   ❌ 李明和王芳，都是年轻人，穿着随意 ← 没有区分特征
   ```

## 🎨 高级技巧

### 技巧1：标注别名
如果故事中会用不同称呼：
```
李明（男主角、小李）：28岁男性，黑短发，深蓝西装...
王芳（女主角、小王）：25岁女性，棕长发，白裙子...
```

### 技巧2：服装备注
如果人物有多套服装：
```
李明：28岁男性，黑短发，戴金边眼镜
      - 工作时：深蓝西装、白衬衫
      - 休闲时：黑色T恤、牛仔裤
```

### 技巧3：特殊标记
帮助识别人物：
```
李明：28岁男性，黑短发，左眼角下有小痣，戴金边眼镜...
```

### 技巧4：分段描述（适合复杂角色）
```
【主角】李明
基本信息：28岁男性，身高175cm，偏瘦体型
外貌特征：黑色短发中分，鹅蛋脸，浓眉大眼
服饰特征：深蓝色修身西装，白色长袖衬衫，黑色领带，黑皮鞋
配饰特征：金色边框圆形眼镜，银色手表
```

## 💡 常见问题速查

**Q: 我有5个角色，都要写吗？**
A: 建议写出主要角色（2-4个），配角可简略描述。

**Q: 人物可以换装吗？**
A: 可以！在分镜中明确说明"李明换上运动服"，AI会自动更新服装。

**Q: 某人物只在最后出现，前面都没有，会一致吗？**
A: 会！档案是永久的，无论何时出现，都会使用档案中的特征。

**Q: 如果忘记填角色特征怎么办？**
A: AI会从故事中自动提取，但可能不够精确。建议手动填写。

**Q: 多人场景会不会混淆？**
A: 不会！AI会按名字精确匹配，每个人独立描述。
