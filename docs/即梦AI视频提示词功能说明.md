# 即梦AI视频提示词功能说明

## 功能概述

在分镜头图片生成完成后，系统会自动生成适合即梦AI的视频提示词，让您可以用生成的图片作为第一帧，在即梦AI中生成5秒的短视频。通过多个场景的视频片段，可以组合成一个完整的短视频作品。

## 功能位置

该功能位于 **图片创作** 页面的右侧栏：
- **🖼️ 预览区域**：显示生成的分镜头图片
- **🎬 即梦AI视频提示词**：预览区域下方的新增区域

## 使用步骤

### 第一步：生成分镜头图片

1. 在 **故事** 页面创建或输入故事内容
2. 切换到 **图片创作** 标签页
3. 点击 **🎬 智能推荐** 或其他分镜模式按钮（如"简短"、"平衡"、"标准"、"精细"）
4. 从下拉框中选择要生成的分镜
5. 点击 **🎨 生成图片** 按钮

### 第二步：获取视频提示词

图片生成成功后，**即梦AI视频提示词** 区域会自动显示优化后的提示词。

提示词会包含：
- 📍 场景信息：原分镜的场景设定
- 🎭 动作描述：提取和强化的动作关键词
- 📹 镜头运动：推进、拉远、平移、跟随等运镜描述
- ✨ 视频优化：强调画面流畅性、动作连贯性等

### 第三步：在即梦AI中生成视频

1. 点击 **📋 复制视频提示词** 按钮
2. 打开即梦AI网站（https://jimeng.jianying.com/）
3. 选择 **图生视频** 功能
4. 上传刚生成的分镜图片作为首帧
5. 粘贴复制的视频提示词
6. 点击生成，等待5秒视频生成完成

### 第四步：制作完整短视频

1. 重复以上步骤，为每个分镜生成对应的视频片段
2. 使用视频编辑软件（如剪映）将所有视频片段按顺序拼接
3. 添加背景音乐、转场效果等，完成短视频制作

## 提示词生成原理

系统会智能分析分镜头描述，提取以下关键信息：

### 1. 场景识别
从分镜描述中提取场景信息，如：
- "307病房内深夜" → 保留为视频开场设定
- "医院走廊灯光昏暗" → 建立视频氛围

### 2. 动作提取
识别并强化动作关键词，包括：
- **人物动作**：走、跑、转身、回头、推开、拉开等
- **表情变化**：笑、哭、惊恐、紧张等
- **物体运动**：飘、落、飞、流动等

### 3. 镜头运动翻译
将专业分镜术语转换为即梦AI易理解的描述：

| 分镜术语 | 视频提示词 |
|---------|-----------|
| 推进 | 镜头缓慢推进 |
| 拉远 | 镜头缓慢拉远 |
| 平移 | 镜头平稳移动 |
| 跟随 | 镜头跟随主体 |
| 环绕 | 镜头环绕 |
| 固定 | 镜头稳定 |

### 4. 视频优化关键词
自动添加增强视频质量的描述：
- "画面流畅自然"
- "动作连贯"
- "光影变化自然"
- "5秒视频"


## 使用技巧

### 1. 场景时长控制
- 标准场景：生成5秒视频
- 快速切换：如果场景需要快速切换，可以手动编辑提示词，将"5秒"改为"3秒"
- 重点场景：可以将"5秒"改为"8秒"，延长重要场景

### 2. 动作强化
如果某个场景动作不够明显，可以在复制后手动添加：
- 增加动作词："快速奔跑"、"缓慢转身"
- 强调情绪："惊恐地后退"、"欣喜地上前"

### 3. 镜头运动调整
可以修改镜头运动来增强效果：
- **静态场景**：删除镜头运动描述
- **动态场景**：加强镜头运动，如"镜头快速推进"

### 4. 视频拼接建议
- **相邻场景**：保持镜头连贯，避免过度跳跃
- **转场过渡**：场景切换处添加淡入淡出或交叉溶解
- **节奏把控**：根据故事情节调整每个场景的实际时长

## 注意事项

1. **提示词长度**：系统会自动控制提示词长度在200字以内，确保即梦AI能正确理解

2. **场景连贯性**：
   - 相邻分镜的视频片段要保持风格一致
   - 注意人物服装、场景设定的连续性
   
3. **生成图片质量**：
   - 分镜图片质量直接影响视频效果
   - 建议使用1080x1920（竖屏）或1920x1080（横屏）分辨率
   
4. **即梦AI限制**：
   - 免费用户每天有生成次数限制
   - 视频生成需要等待时间，建议批量生成

## 常见问题

### Q1: 视频提示词生成失败？
**A:** 确保已经选择了分镜头，或者在图片描述框中有内容。

### Q2: 生成的视频效果不理想？
**A:** 可以尝试：
- 调整提示词，增加更多动作描述
- 在即梦AI中调整生成参数
- 重新生成分镜图片，确保首帧质量

### Q3: 多个视频拼接不流畅？
**A:** 建议：
- 在视频编辑时添加过渡效果
- 调整每个片段的播放速度
- 检查场景连续性，必要时重新生成

### Q4: 如何控制每个场景的时长？
**A:** 可以手动修改提示词中的"5秒视频"为其他时长，但要注意：
- 即梦AI的推荐时长是5秒
- 太短（<3秒）可能导致动作不完整
- 太长（>10秒）可能影响画面质量
