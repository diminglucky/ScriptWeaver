# 🎯 人物一致性优化功能说明

## 📋 功能概述

本功能通过智能算法提升同一角色在多张照片中的**视觉一致性**，确保角色的外貌特征在不同视角、表情、服装变体中保持稳定和可识别。

**版本**：v3.2  
**状态**：已完成 ✅  
**默认启用**：是（medium级别）

---

## 🎯 核心目标

### 问题背景

在批量生成角色照片时，可能遇到以下一致性问题：

1. **外貌漂移**：同一角色在不同照片中五官特征有差异
2. **特征模糊**：AI对关键特征（如眼睛、发型）的理解不一致
3. **风格混乱**：不同照片之间风格差异过大
4. **辨识度低**：难以识别是同一个角色

### 解决方案

通过以下技术提升一致性：

1. ✅ **关键特征提取**：自动识别并强调重要特征
2. ✅ **一致性关键词注入**：添加一致性提示词
3. ✅ **批量类型优化**：针对不同批量类型定制提示
4. ✅ **特征权重提升**：重复关键特征以提高AI注意力

### 2️⃣ 一致性级别

系统提供4个一致性级别（当前默认medium）：

#### None - 不启用
- 不添加任何一致性优化
- 适合：单张照片生成

#### Low - 低级别
- 最小化一致性提示
- 保持描述原样
- 适合：风格多样化需求

#### Medium - 中级别（默认）
- 添加适度的一致性关键词
- 重复1-2个最重要的特征
- 适合：大多数场景

**优化效果：**
```python
原始描述：
"28岁女性，黑色长发，圆脸，大眼睛"

优化后：
"28岁女性，黑色长发，圆脸，大眼睛，
同一个人，固定特征，圆脸，黑色长发"
```

#### High - 高级别
- 添加完整的一致性关键词
- 重复多个重要特征
- 适合：批量生成15张及以上

**优化效果：**
```python
原始描述：
"28岁女性，黑色长发，圆脸，大眼睛"

优化后：
"28岁女性，黑色长发，圆脸，大眼睛，
同一个人，相同的人，固定特征，不变的外貌，
圆脸，黑色长发，大眼睛"
```

### 3️⃣ 批量类型优化

针对不同的批量生成类型，添加专门的一致性提示：

#### angle - 多角度生成
```
原始描述 + "保持服装和身材一致，相同的整体形象"

适用：批量生成三视图
重点：确保服装、姿态一致
```

#### expression - 多表情生成
```
原始描述 + "保持五官特征不变，只改变表情"

适用：批量生成多表情
重点：确保五官不变，只有表情变化
```

#### variant - 多变体生成
```
原始描述 + "保持面部特征和体型一致，只改变服装和配饰"

适用：生成不同服装变体
重点：确保基础外貌一致，只改变服装
```

#### angle+expression - 角度+表情组合
```
综合角度和表情的优化策略
```

## 🔧 技术原理

### 工作流程

```
1. 接收原始描述
   ↓
2. 提取关键特征（feature extraction）
   ↓
3. 评估批量类型（batch type detection）
   ↓
4. 应用一致性增强（consistency enhancement）
   ├─ 添加一致性关键词
   ├─ 重复重要特征
   └─ 添加批量类型提示
   ↓
5. 返回优化后描述
```

### 算法实现

#### 1. 特征提取算法

```python
def extract_key_features(description: str):
    features = {}
    
    # 遍历所有特征类型
    for feature_type, keywords in FEATURE_KEYWORDS.items():
        found = []
        for keyword in keywords:
            # 使用正则表达式查找包含关键词的片段
            pattern = rf'[^，。,.\n]*{keyword}[^，。,.\n]*'
            matches = re.findall(pattern, description)
            found.extend(matches)
        
        # 去重并限制数量
        if found:
            features[feature_type] = list(set(found))[:3]
    
    return features
```

#### 2. 一致性增强算法

```python
def build_consistency_prompt(description, level):
    # 1. 提取关键特征
    features = extract_key_features(description)
    
    # 2. 添加一致性关键词
    if level == "high":
        keywords = ["同一个人", "相同的人", "固定特征", "不变的外貌"]
    elif level == "medium":
        keywords = ["同一个人", "固定特征"]
    else:
        keywords = []
    
    # 3. 重复重要特征
    重点特征 = []
    for type in ["eyes", "face_shape", "hair_color"]:
        if type in features:
            重点特征.append(features[type][0])
    
    # 4. 组合
    return description + "，" + "，".join(keywords + 重点特征)
```

## 🎯 一致性评分

系统会自动评估描述的一致性潜力：

### 评分标准

```
分数 = (已描述特征类型数 / 总特征类型数) × 100
```

### 评分等级

| 分数 | 等级 | 说明 | 建议 |
|------|------|------|------|
| 80-100 | 优秀 | 特征非常完整 | 无需改进 |
| 60-79 | 良好 | 特征较完整 | 可适当补充 |
| 40-59 | 一般 | 特征不够详细 | 建议补充重要特征 |
| 0-39 | 较差 | 特征过于简单 | 强烈建议补充 |

### 评分示例

```python
描述1：
"女性，长发"
评分：17分（较差）
建议：补充年龄、脸型、五官、肤色等

描述2：
"28岁女性，黑色长发，圆脸，大眼睛"
评分：50分（一般）
建议：补充鼻子、嘴巴、肤色等

描述3：
"28岁女性，黑色长发披肩，圆脸蛋，
大眼睛双眼皮，高鼻梁，薄唇，
白皙肤色，身高165cm，苗条身材，
右脸颊有一颗痣"
评分：92分（优秀）
建议：无需改进
```

## 💡 最佳实践

### DO's ✅

1. ✅ **提供详细的角色描述**
   ```
   好：28岁女性，黑色长发披肩，圆脸，大眼睛双眼皮，
       高鼻梁，薄唇，白皙肤色，身高165cm，
       右脸颊有一颗小痣
   
   差：女性，长发
   ```

2. ✅ **包含独特标识**
   ```
   - 特殊的疤痕、痣
   - 独特的发色
   - 明显的五官特征
   ```

3. ✅ **使用具体的形容词**
   ```
   好：大眼睛、圆脸、高鼻梁
   差：漂亮、好看、可爱
   ```

4. ✅ **批量生成时保持基础参数一致**
   ```
   - 使用相同的图片风格
   - 使用相同的API
   - 不要中途修改角色描述
   ```

### DON'Ts ❌

1. ❌ **不要描述过于简单**
   ```
   错误：年轻女性
   正确：25岁女性，黑色短发，鹅蛋脸，清秀
   ```

2. ❌ **不要使用模糊词汇**
   ```
   错误：长得很美，气质好
   正确：瓜子脸，柳叶眉，肤色白皙
   ```

3. ❌ **不要中途修改描述**
   ```
   错误：
   照片1：28岁，长发
   照片2：28岁，短发（改了发型）
   照片3：30岁，长发（改了年龄）
   
   正确：
   所有照片使用相同的基础描述
   通过变体功能改变服装
   ```

## 🔍 故障排除

### Q1: 优化后一致性仍然不理想？

**可能原因**：
1. 角色描述过于简单
2. 使用了不同的图片风格
3. 使用了不同的API
4. 原始描述包含冲突信息

**解决方案**：
- 补充更详细的特征描述
- 保持风格和API一致
- 检查描述中是否有矛盾
- 尝试增加一致性级别（但通常medium已足够）

### Q2: 提示词被截断？

**原因**：
- API有字符限制
- 系统会自动优化

**不用担心**：
- 腾讯混元：自动截断到256字符
- OpenAI：自动截断到1000字符
- 保留最重要的信息

### Q3: 如何手动调整一致性级别？

**当前版本**：
- 默认使用medium级别
- 无UI选项调整

**如需自定义**：
```python
# 在代码中修改
consistency_level="high"  # none/low/medium/high
```
