# 一致性生成快速指南 ⚡

> **5分钟学会生成高一致性人物照片**

---

## 🎯 核心原则

要让正面、侧面、背面看起来像**同一个人**，需要保证：

```
✅ 脸型一样     （瓜子脸就是瓜子脸）
✅ 发型一样     （齐肩短发就是齐肩短发）
✅ 服装一样     （黑西装就是黑西装）
```

---

## 📝 第一步：生成高质量描述

### ⭐ 关键：描述必须包含三大特征

#### 检查清单：
```
□ 脸型：瓜子脸、圆脸、方脸、鹅蛋脸...
□ 发型：黑色齐肩短发、长直发、棕色卷发...
□ 服装：黑色西装、白色连衣裙、蓝色T恤...
```

#### 示例：

**✅ 好的描述**：
```
28岁女性，瓜子脸，黑色齐肩短发直发，
穿黑色修身西装配白色衬衫...
```
- ✅ 脸型：瓜子脸
- ✅ 发型：黑色齐肩短发直发
- ✅ 服装：黑色修身西装配白色衬衫

**❌ 不好的描述**：
```
年轻女性，漂亮，职业装...
```
- ❌ 没有脸型
- ❌ 发型太模糊
- ❌ 服装太笼统

### 💡 如果描述不够详细？

**方案A**：手动补充
```
在"人物特征描述"文本框中，直接添加：
- 脸型：瓜子脸
- 发型：黑色齐肩短发，直发
- 服装：黑色西装，白色衬衫
```

**方案B**：重新生成
```
1. 点击「重新提取」
2. 重新生成描述
3. 检查是否包含三大特征
```

---

## ⚙️ 第二步：选择最高一致性级别

找到「🎯 面部一致性级别」选项：

```
● 🔥 最高 - 强力保持脸型五官    ← 选这个！
○ ⚡ 中等 - 平衡一致性
○ 💨 较低 - 允许更多变化
```

### 为什么选「最高」？

- ✅ 脸型重复3次
- ✅ 发型重复3次  
- ✅ 服装重复3次
- ✅ 添加10条强约束
- ✅ 一致性提升40%+

---

## 🎯 第三步：批量生成三视图

### ⭐ 重点：勾选批量生成

```
☑ 🎯 批量生成三视图（正面+侧面+背面）
```

### 为什么要批量生成？

**批量生成时，系统会额外添加10条约束**：
```
1. 完全相同的脸型和五官
2. 一模一样的面部轮廓  
3. 完全一致的发型发长
4. 完全相同的发型
5. 保持服装颜色和款式完全一致
6. 相同的衣服
7. 同一个人的不同角度
8. 面部特征绝对不变
9. 头发长度和样式不变
10. 服装细节完全相同
```

**效果对比**：
- 分开生成：一致性70%
- 批量生成：一致性**90%+** ⭐

## 📊 效果检查

### 三张照片应该：

```
✅ 脸型相同     （都是瓜子脸）
✅ 发型一致     （都是齐肩短发）
✅ 服装统一     （都是黑西装）
✅ 整体像同一个人
```

### 如果不一致怎么办？

#### 方案1：检查描述 ⭐⭐⭐
```
问题：脸型变了（瓜子脸→方脸）
原因：描述中可能没有明确写"瓜子脸"
解决：在描述中添加明确的脸型
```

#### 方案2：检查设置 ⭐⭐
```
问题：发型长度不一致
原因：可能选了「中等」或「较低」级别
解决：改成「最高」级别
```

#### 方案3：重新生成 ⭐⭐
```
问题：服装颜色不统一
原因：AI生成有随机性
解决：删除照片，重新生成
```

#### 方案4：多生成几次 ⭐
```
- AI生成有随机性
- 多试几次可能得到更好结果
- 选择最满意的一组保存
```

## 💡 进阶技巧

### 技巧1：在描述中强调关键特征

在描述开头添加：
```
【关键特征：瓜子脸、黑色齐肩短发、黑色西装】
```

### 技巧2：使用更具体的描述

**普通**：
```
短发，西装
```

**具体** ⭐：
```
黑色齐肩短发，长度到肩膀，直发，中分，
深灰色修身西装，单排扣，白色衬衫
```

### 技巧3：添加独特标记

在描述中添加：
```
右眼角有一颗小痣，左脸颊有浅浅的酒窝
```

这些独特标记能帮助AI更好地保持一致性。

## ⚠️ 常见问题

### Q1：为什么脸型还是会变？

**A**：可能原因：
1. 描述中没有明确脸型 → 补充脸型描述
2. 一致性级别选择太低 → 改成「最高」
3. 没有批量生成 → 勾选「批量生成三视图」

### Q2：为什么头发长度不一样？

**A**：
1. 描述太模糊（"短发"） → 改成"齐肩短发"
2. 需要更详细（"黑色齐肩短发，长度到肩膀，直发"）
3. 在额外描述中强调："头发长度必须一致"

### Q3：为什么服装颜色变了？

**A**：
1. 只写了"西装"没写颜色 → 改成"黑色西装"
2. 描述不具体 → 改成"深灰色修身西装配白衬衫"
3. 可以在额外描述中强调："服装颜色和款式完全一致"

### Q4：已经按步骤做了，为什么还是不完美？

**A**：正常现象
- AI生成有随机性，无法100%保证一致
- 不同角度的光影效果天然不同
- 推荐做法：多生成几次，选最佳结果
