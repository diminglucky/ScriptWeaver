================================
   ScriptWeaver 智能剧本与故事编织工具 - 使用说明
================================

欢迎使用ScriptWeaver 智能剧本与故事编织工具！

【快速开始】

1. 双击运行"ScriptWeaver 智能剧本与故事编织工具.exe"

2. 首次使用需要配置API密钥：
   方法一：在程序界面中配置
   - 在"配置"选项卡中填写您的DeepSeek API Key
   - 点击"保存配置"按钮
   
   方法二：使用.env文件
   - 复制.env.example为.env
   - 编辑.env文件，填入您的API密钥：
     API_PRESET=DeepSeek
     STORY_DeepSeek_KEY=your_api_key_here
     STORY_DeepSeek_BASE_URL=https://api.deepseek.com/v1
     STORY_DeepSeek_MODEL=deepseek-chat

3. 准备文本素材
   - 在data/raw/文件夹中放入您的文本素材（.txt或.md文件）
   - 这些素材将用于AI学习和参考

4. 构建知识库
   - 在程序中点击"构建索引"按钮
   - 等待索引构建完成（首次可能需要下载模型）

5. 开始创作
   - 选择故事类型（如：惊悚、爱情、科幻等）
   - 点击"生成目录"创建故事大纲
   - 点击"生成故事"开始创作完整故事
   - 可随时修改和保存您的作品

【主要功能】

📝 故事创作
   - 支持多种故事类型选择
   - 智能生成故事大纲和正文
   - 基于您的素材库进行创作
   - 流式输出，实时查看创作过程

🖼️ 图片生成
   - 为故事场景生成配图
   - 支持多种图片风格
   - 自动保存到项目文件夹

💾 项目管理
   - 保存和加载创作项目
   - 支持导出为txt或md格式
   - 自动保存图片和文本

🔍 知识库检索
   - 基于 ChromaDB 的本地向量检索
   - 智能匹配相关素材
   - 支持自定义检索参数

【系统要求】

✅ 操作系统：Windows 10/11 (64位)
✅ 内存：至少4GB RAM（推荐8GB）
✅ 磁盘空间：至少2GB可用空间
✅ 网络：首次运行需要联网（下载AI模型）

【首次运行说明】

⚠️ 首次启动时，程序需要：
   1. 下载AI模型文件（约500MB-1GB）
   2. 初始化知识库系统
   3. 这可能需要5-10分钟，请耐心等待

⚠️ 模型文件下载位置：
   - Windows: C:\Users\你的用户名\.cache\huggingface
   - 请确保该位置有足够的磁盘空间

【常见问题】

Q: 程序启动很慢？
A: 首次启动需要解压和加载依赖，之后会快很多。单文件版本会比文件夹版本慢一些。

Q: 提示"找不到模型"？
A: 首次运行需要联网下载模型，请确保网络连接正常。如果下载失败，可以重启程序重试。

Q: 如何获取DeepSeek API Key？
A: 访问 https://platform.deepseek.com/ 注册账号并创建API密钥。

Q: 生成的故事质量不好？
A: 可以尝试：
   - 添加更多高质量的素材文件
   - 重新构建知识库索引
   - 调整检索参数（top-k值）
   - 使用更详细的故事描述

Q: 程序崩溃或出错？
A: 1. 检查.env配置是否正确
   2. 确保API密钥有效
   3. 查看错误提示信息
   4. 尝试重启程序

Q: 如何升级程序？
A: 下载新版本后，可以复制旧版本的以下文件到新版本：
   - .env（配置文件）
   - data/（数据目录）
   - projects/（项目目录）
   - index/（索引目录）

【文件夹说明】

📁 data/raw/        - 放置您的文本素材
📁 data/processed/  - 处理后的数据（自动生成）
📁 index/           - 向量索引文件（自动生成）
📁 projects/        - 保存的创作项目
📁 docs/            - 详细文档和使用指南
📄 .env             - 配置文件（需要自己创建）
📄 .env.example     - 配置文件示例

【进阶使用】

🔧 自定义API配置
   可以在.env文件中配置：
   - STORY_DeepSeek_KEY：API密钥
   - STORY_DeepSeek_BASE_URL：API地址（可选）
   - STORY_DeepSeek_MODEL：使用的模型（可选）
   - （兼容）DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL / DEEPSEEK_MODEL

🎨 图片生成配置
   可以自定义图片API设置：
   - 编辑custom_image_api_presets.json
   - 支持多种图片生成服务

📚 知识库优化
   - 定期更新素材文件
   - 重新构建索引以获得最佳效果
   - 使用高质量、相关性强的素材
