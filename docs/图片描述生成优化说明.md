# 图片描述生成优化说明

## 更新概述

优化了图片描述生成逻辑，根据不同的API提供商自动调整描述的详细程度和长度。

## 核心改进

### 1. **智能识别API类型**

系统会自动检测当前使用的图片生成API：
- **腾讯混元**：生成简洁版描述（180字以内）
- **其他API**（OpenAI/DALL-E等）：生成详细版描述（300-400字）

### 2. **两种描述模式**

#### 模式A：腾讯混元简洁版（180字以内）

**原因**：腾讯混元API的Prompt限制为256个UTF-8字符

**特点**：
- 高密度关键词
- 精简但信息完整
- 覆盖核心元素：人物、场景、光线、构图

**示例输出**：
```
深夜医院走廊，白色墙面，灰绿色地板，女医生白大褂，疲惫神情，眉头微蹙，
双手插口袋，站立姿态，昏暗日光灯，惨白光线，走廊尽头红色安全标志，
中景，平视角度，浅景深，人物居中偏右，寂静压抑氛围
```

#### 模式B：详细版（300-400字）

**适用**：OpenAI DALL-E、V-API、GPT-Image等

**特点**：
- 极度详细的分层描述
- 涵盖所有视觉细节
- 专业的电影摄影级别描述

**描述结构**：

1. **人物细节**（如有人物）
   - 外貌：年龄、性别、发型、发色、肤色、体型、五官特征
   - 服饰：款式、颜色、材质、配饰、细节（纽扣、花纹等）
   - 表情：眼神、嘴角、眉头、整体情绪
   - 动作/姿态：身体姿势、手部动作、站姿坐姿、动态感
   - 位置：在画面中的位置和占比

2. **背景环境**（极度详细）
   - 场所：具体地点类型
   - 建筑/空间：墙壁材质、地面类型、天花板、门窗、建筑风格
   - 物品/道具：重要物品的位置、形态、状态
   - 自然元素：天空、云层、植被、水体
   - 纵深感：前景、中景、背景的层次关系

3. **光线与氛围**
   - 光源：类型、方向、强度
   - 时间：具体时段
   - 天气/季节：晴天、阴天、雨雪、雾气
   - 色温：暖色调/冷色调
   - 阴影：阴影的形态和分布

4. **构图与镜头**
   - 镜头类型：特写/近景/中景/全景/远景
   - 拍摄角度：平视/俯视/仰视/侧面
   - 景深：浅景深/深景深、焦点位置
   - 构图方式：三分法、中心构图、对角线构图

5. **情绪与氛围**
   - 整体情绪基调
   - 视觉张力和戏剧性

**示例输出**：
```
人物：28岁女性医生，黑色长发披肩至腰，发梢微卷，肤色白皙略显疲惫，
体型纤细，眼神涣散无神，嘴角微微下垂，眉头深锁显露疲惫，穿着白色医生
制服，制服领口略显松垮，袖口卷起至手肘，双手无力地插在制服口袋里，
身体略微前倾，站立姿态不稳定，位于画面中心偏右位置，占画面约40%；

背景：深夜医院内科大楼三层走廊，墙面为白色瓷砖，部分墙砖边缘有裂纹，
地面是灰绿色PVC地板，地板上有多处黑色划痕和污渍，天花板上安装着

安全出口标志，走廊两侧有塑料椅子和医用推车；

光线：深夜凌晨2点左右，顶部日光灯发出惨白色冷光，色温约4000K，

走廊尽头背光较弱形成昏暗区域，整体光线呈现冷色调，略带青灰色调；

构图：中景镜头，平视角度拍摄，相机位于人物正前方略偏左，浅景深效果，
焦点集中在人物面部和上半身，背景走廊适度虚化但可辨认细节，
采用略偏离中心的构图方式，人物位于画面右侧三分线位置，左侧留出
较多空间展现走廊纵深；

氛围：寂静压抑，略带不安感，医院深夜特有的孤寂氛围，暗示长时间
工作的疲惫状态，冷色调加强了疏离感和寂寥感
```

## 使用方法

### 步骤1：选择API预设

在**图片生成 → 配置**页面：
- 选择 **腾讯混元**：自动使用简洁版（180字）
- 选择其他预设（如 V-API图片生成）：自动使用详细版（300-400字）

### 步骤2：生成图片描述

在**图片生成 → 创作**页面：
1. 先生成或输入分镜
2. 在下拉框选择要生成图片的分镜
3. 点击 **📸 从当前分镜生成** 按钮

系统会自动：
- 识别当前使用的API类型
- 生成对应详细程度的描述
- 在状态栏显示描述类型和字数

### 步骤3：查看和编辑

生成后：
- 查看"中文描述"文本框中的内容
- 状态栏显示：`✨ 已生成【写实照片】详细版图片描述（358字，可编辑后生成）`
- 可以手动编辑描述来调整细节

### 步骤4：生成图片

点击 **🎨 生成图片** 按钮，系统会：
1. 将中文描述翻译为英文提示词
2. 调用相应的图片生成API
3. 显示生成的图片

## 技术细节

### API类型检测

```python
# 检测是否使用腾讯混元
is_hunyuan = False
if hasattr(self, 'img_api_preset'):
    preset_name = self.img_api_preset.get()
    if "腾讯混元" in preset_name or "hunyuan" in preset_name.lower():
        is_hunyuan = True
```

### 上下文长度调整

```python
# 根据API类型调整上下文长度
context_length = 500 if is_hunyuan else 1000
```

### 提示词模板切换

系统维护两套完整的提示词模板：
- `inst_hunyuan`：简洁版指令（要求180字以内）
- `inst_detailed`：详细版指令（要求300-400字，包含5大类细节要求）

## 优势对比

### 之前的问题

- ❌ 所有API使用相同的180字描述
- ❌ 描述信息密度不够，细节不足
- ❌ 背景环境描述过于简略
- ❌ 人物动作、神态描述不够精准
- ❌ 没有充分利用DALL-E等高级模型的理解能力

### 现在的优势

- ✅ 根据API能力智能调整描述详细程度
- ✅ 腾讯混元：精简高效，符合256字符限制
- ✅ DALL-E等：详细精准，涵盖所有视觉元素
- ✅ 专业的电影摄影级别描述（人物、背景、光线、构图、氛围）
- ✅ 详细的背景环境描述（建筑材质、物品状态、空间层次）
- ✅ 精准的人物动作和神态描述（姿态、表情、情绪）
- ✅ 具体的数值和位置描述（避免模糊词汇）
- ✅ 状态栏实时显示描述类型和字数统计

## 注意事项

1. **API类型识别**：系统根据"API预设"名称自动识别，请确保预设名称包含关键词
   - 腾讯混元：预设名称需包含"腾讯混元"或"hunyuan"
   - 其他API：自动使用详细版

2. **字数控制**：
   - 简洁版：通常在150-180字之间
   - 详细版：通常在300-400字之间
   - 实际字数会显示在状态栏

3. **编辑建议**：
   - 生成后可以手动编辑中文描述
   - 可以根据需要增删细节
   - 编辑完成后再点击"生成图片"

4. **性能影响**：
   - 详细版描述会使DeepSeek生成耗时略微增加（约2-3秒）
   - 翻译为英文时耗时也会略增加
   - 但生成的图片质量会显著提升
