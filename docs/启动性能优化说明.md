# 启动性能优化说明

## 问题诊断

应用启动缓慢的根本原因是 **SentenceTransformer 模型在启动时被加载**。

### 性能瓶颈

- `sentence_transformers` 库在导入时需要加载 AI 模型文件：**3.8秒**
- 4个 story 模块在顶部直接导入了该库
- 导致应用启动时间长达 **9.77秒**

## 优化方案

### 延迟导入（Lazy Import）

将 `KnowledgeBaseSearcher` 和相关类的导入从**文件顶部**移到**实际使用时**：

```python
# ❌ 优化前：在文件顶部导入（启动时加载）
from src.kb.search import KnowledgeBaseSearcher, SearchConfig

# ✅ 优化后：在使用时才导入（延迟加载）
def on_generate():
    # 只在需要时才导入
    from src.kb.search import KnowledgeBaseSearcher, SearchConfig
    searcher = KnowledgeBaseSearcher(...)
```

### 修改的文件

1. `src/gui/mixins/story_modules/outline_generator.py`
2. `src/gui/mixins/story_modules/story_generator.py`
3. `src/gui/mixins/story_modules/ui_builder.py`
4. `src/gui/mixins/story_modules/config_handler.py`

## 技术说明

### 为什么 sentence_transformers 这么慢？

1. **模型文件加载**：需要从磁盘加载预训练的神经网络模型（几百MB）
2. **依赖库初始化**：PyTorch/TensorFlow 等深度学习框架的初始化
3. **首次运行**：可能需要从 Hugging Face 下载模型文件

### 延迟导入的优势

- ✅ **快速启动**：只加载必需的轻量级模块
- ✅ **按需加载**：只在使用知识库功能时才加载 AI 模型
- ✅ **内存优化**：不使用知识库功能时不占用内存
- ✅ **用户体验**：应用立即启动，无需等待

### 延迟导入的注意事项

- ⚠️ **首次使用延迟**：第一次使用知识库搜索时会有 3-4 秒延迟（加载模型）
- ⚠️ **错误提示延迟**：如果模型文件缺失，错误会在使用时才提示，而非启动时

## 使用建议

1. **正常使用**：直接启动应用，速度飞快（0.8秒）
2. **使用知识库**：第一次使用知识库搜索功能时会有短暂延迟（3-4秒加载模型）
3. **后续使用**：模型加载后会保持在内存中，后续使用无延迟

## 进一步优化建议

如果仍觉得启动慢，可以考虑：

### 1. 优化环境变量加载
```python
# 使用缓存避免重复加载
if not os.getenv("LOADED"):
    load_dotenv()
    os.environ["LOADED"] = "1"
```

### 2. 异步UI构建
将某些非关键UI组件延迟创建：
```python
# 启动后延迟构建
self.after(100, self._build_advanced_features)
```

### 3. 使用更轻量的嵌入模型
如果不需要高精度搜索，可以考虑：
- `paraphrase-MiniLM-L3-v2`（更小更快）
- `all-MiniLM-L6-v2`（平衡性能和速度）
