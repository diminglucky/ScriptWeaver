# 一致性设定功能说明

## 功能概述

一致性设定功能是导演页面中的核心功能之一，用于确保在生成多个分镜图片时，人物的外观、服装等特征保持一致。

## 使用流程

### 1. 生成分镜后编辑设定

1. 在导演页面生成剧本和分镜后
2. 点击【步骤3】中的"👥 编辑设定表"按钮
3. 系统会自动从分镜中提取人物列表

### 2. 设定人物特征

在弹出的一致性设定对话框中，可以为每个人物设定：

#### 基本信息
- 姓名
- 年龄（如：25岁、青年、中年等）
- 性别
- 身份/职业
- 性格特征
- 背景故事

#### 外观设定
- **面部特征**：脸型、肤色、眼睛、眉毛、鼻子、嘴巴、特殊标记
- **发型特征**：发色、长度、发型、刘海
- **身材特征**：身高、体型、特征

#### 服装设定
- 支持多场景服装（默认、工作、休闲、正式等）
- 上装、下装、鞋子、配饰
- 整体风格和颜色主调

#### 表情动作
- 默认表情
- 常用表情集
- 常用动作描述

### 3. 预览和保存

- 点击"预览"标签可查看AI生成的约束提示词
- 点击"保存"按钮保存设定
- 设定会自动保存到项目文件中

### 4. 应用到图片生成

当生成分镜图片时，系统会：

1. 自动识别每个镜头中的人物
2. 根据一致性设定添加人物约束
3. 确保生成的图片中人物特征保持一致

## 功能特点

### 智能识别
- 自动从剧本和分镜中提取人物名称
- 支持中文姓名识别

### 灵活设定
- 可为不同场景设定不同服装
- 支持导入/导出设定文件
- 可添加多个人物

### 持久保存
- 设定随项目保存
- 下次打开项目时自动加载
- 支持JSON格式导出

## 注意事项

1. **人物名称一致性**：确保在剧本和分镜中使用相同的人物名称
2. **详细设定**：越详细的设定，生成的图片一致性越好
3. **合理描述**：使用AI能理解的描述词汇
4. **保存习惯**：编辑完成后记得保存

## 示例

假设有一个人物"李明"：

```
基本信息：
- 姓名：李明
- 年龄：28岁
- 性别：男
- 职业：软件工程师

外观设定：
- 脸型：瓜子脸
- 肤色：自然
- 眼睛：大眼睛
- 发型：黑色短发直发

服装（默认）：
- 上装：蓝色格子衬衫
- 下装：深色牛仔裤
- 鞋子：白色运动鞋
```

生成的约束提示词：
```
李明：28岁男，自然肤色，黑色短发直发，大眼睛，穿着蓝色格子衬衫，深色牛仔裤
注意：生成的李明必须严格符合上述特征，确保在所有镜头中保持一致。
```
