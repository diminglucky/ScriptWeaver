# 项目对象访问修复说明

## 问题描述

**错误信息：**
```
旗标项目失败: 'Project' object is not subscriptable
```

**错误原因：**
代码中将 `Project` 对象当作字典来访问（使用 `project['key']`），但 `Project` 是一个类实例，应该使用属性访问（`project.property`）或字典方法（`.get()`）。

## 修复策略

### 项目对象兼容性处理

为了兼容不同类型的项目对象，使用以下标准化方法：

```python
# 获取项目路径
if hasattr(self.current_project, 'project_dir'):
    # 项目管理器对象
    project_path = str(self.current_project.project_dir)
elif isinstance(self.current_project, dict):
    # 字典类型
    project_path = self.current_project.get('path', '')
else:
    # 其他类型，尝试转换为字符串
    project_path = str(self.current_project)

# 获取项目名称
if hasattr(self.current_project, 'metadata'):
    # 项目管理器对象
    project_name = self.current_project.metadata.get('name', '未命名项目')
elif isinstance(self.current_project, dict):
    # 字典类型
    project_name = self.current_project.get('name', '未命名项目')
else:
    # 默认值
    project_name = '未命名项目'
```

## 最佳实践

### ✅ 推荐做法

1. **使用 .get() 方法访问字典**
   ```python
   value = dict_obj.get('key', 'default_value')
   ```

2. **检查对象类型后再访问**
   ```python
   if hasattr(obj, 'attribute'):
       value = obj.attribute
   elif isinstance(obj, dict):
       value = obj.get('key', default)
   ```

3. **提供默认值**
   ```python
   project_name = project.metadata.get('name', '未命名项目')
   ```

### ❌ 避免的做法

1. **直接使用方括号访问**
   ```python
   value = dict_obj['key']  # 如果key不存在会抛出KeyError
   ```

2. **假设对象类型**
   ```python
   value = obj['attribute']  # 如果obj不是字典会抛出TypeError
   ```

3. **不提供默认值**
   ```python
   value = dict_obj.get('key')  # 返回None可能导致后续错误
   ```
