## 📖 使用文档

### 完整工作流程

#### 步骤1: 创建故事
1. 打开【📖 故事】页面
2. 输入主题或直接输入故事
3. 点击生成故事

#### 步骤2: 管理人物
1. 切换到【📸 图片管理】页面
2. 点击【🔍 提取故事人物】
3. 选择一个人物
4. 点击【✨ 生成特征描述】
5. 点击【✏️ 编辑人物详情】
   - 填写基本信息
   - 完善外观特征
   - 设定服装造型
   - 选择默认表情
6. 点击【💾 保存】

#### 步骤3: 生成人物形象
1. 选择生成类型：
   - ○ 标准形象 (1张)
   - ○ 表情库 (7张) ← 推荐
   - ○ 角度库 (3张)
   - ○ 完整套装 (11张) ← 最佳
2. 点击【🎨 开始生成】
3. 等待生成完成
4. 点击【📁 查看图片库】确认效果

#### 步骤4: 创作分镜
1. 切换到【🎬 导演】页面
2. 点击【📝 生成视频脚本】
3. 点击【🎬 生成分镜】
4. 选择要生成的分镜
5. 点击【🖼️ 生成图片】
6. 等待智能选择+img2img生成

#### 步骤5: 导出视频
1. 查看生成的分镜图片
2. 点击【📺 生成即梦AI提示词】
3. 复制提示词和图片
4. 在即梦AI中生成视频
