# 项目保存功能快速指南

## 🎯 核心功能

系统现已支持**完整的项目保存和恢复**，让您的创作永不丢失！

## 🚀 快速上手

### 1️⃣ 创建项目
```
项目管理页面 → 点击"➕ 新建项目" → 输入项目名称
```

### 2️⃣ 保存内容

**方式一：保存当前故事**（推荐日常使用）
```
点击"💾 保存当前故事"按钮
```
- 保存故事文本
- 保存创作参数
- 触发完整项目保存

**方式二：完整保存**（重要时刻使用）
```
点击"💯 完整保存项目"按钮
```
- 显示详细保存内容列表
- 确保所有数据完整保存

**方式三：自动保存**（无需操作）
```
系统每5分钟自动保存一次
```
- 只在内容有变化时保存
- 状态栏显示保存时间

### 3️⃣ 加载项目
```
项目管理页面 → 选择项目 → 点击"📂 加载项目"
```
系统会自动恢复：
- ✅ 故事内容
- ✅ 剧本和分镜
- ✅ 人物设定
- ✅ 所有配置
- ✅ UI状态

| 操作 | 建议保存方式 |
|------|------------|
| 日常编辑故事 | 自动保存 |
| 完成一个章节 | 保存当前故事 |
| 生成剧本/分镜后 | 完整保存项目 |
| 设置人物一致性后 | 完整保存项目 |
| 生成大量图片后 | 完整保存项目 |


**状态栏显示：**
```

```

## ⚠️ 注意事项

### ❌ 不会保存的内容
- API密钥（安全考虑）
- 临时缓存
- 生成日志

### ✅ 需要手动处理
- API密钥需要在配置页重新输入
- 图片文件不要手动移动或删除
- 项目文件夹不要重命名

## 🔧 故障处理

### 问题：加载后内容不完整

**解决方案：**
1. 检查项目文件夹是否完整
2. 查看 `project.json` 文件是否存在
3. 查看控制台错误信息
4. 尝试手动加载单个部分

### 问题：自动保存不工作

**解决方案：**
1. 检查控制台是否显示"自动保存功能已启用"
2. 确认已打开项目
3. 等待5分钟后查看是否有保存日志
4. 手动点击"完整保存"测试

### 问题：保存失败

**可能原因：**
- 磁盘空间不足
- 文件被其他程序占用
- 权限不足

**解决方案：**
1. 检查磁盘空间
2. 关闭可能占用文件的程序
3. 以管理员权限运行
4. 更换保存位置

## 🎓 进阶使用

### 导出项目
```python
# 项目文件夹包含所有内容
projects/
  └── 你的项目_20241022/
      ├── project.json      # 主数据
      ├── story.txt         # 故事文本
      ├── characters/       # 人物
      ├── images/          # 图片
      └── director/        # 导演数据
```

### 迁移项目
1. 复制整个项目文件夹
2. 粘贴到新位置的 `projects/` 目录
3. 重新打开应用即可看到

### 共享项目
1. 压缩项目文件夹
2. 发送给他人
3. 解压到 `projects/` 目录
4. 刷新项目列表
