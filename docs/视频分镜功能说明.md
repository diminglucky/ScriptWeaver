# 🎬 视频分镜功能说明

## 功能概述

全新的"视频分镜模式"专门为视频制作优化，生成的分镜脚本包含镜头时长、运镜方式、转场效果、音效提示等专业视频制作要素，让你能够直接基于分镜进行视频拍摄或动画制作。

## 🌟 核心特点

### 与普通分镜的区别

| 特性 | 普通分镜 | 视频分镜 |
|------|---------|---------|
| **镜头数量** | 静态场景 | 10-15个连贯镜头 |
| **镜头时长** | ❌ 无 | ✅ 每个镜头标注建议时长（如3-5秒） |
| **运镜方式** | ❌ 无 | ✅ 推/拉/摇/移/跟随/环绕等 |
| **转场效果** | ❌ 无 | ✅ 切/淡入淡出/叠化/闪白等 |
| **音效提示** | ❌ 无 | ✅ 环境音/配乐/对白提示 |
| **视频节奏** | ❌ 无考虑 | ✅ 优化快慢节奏和视觉流畅性 |
| **用途** | 静态插图、漫画分镜 | **视频拍摄、动画制作、短视频** |

## 📋 视频分镜格式说明

每个视频分镜包含7个要素，用 `|` 分隔：

```
序号. 场景描述 | 人物与动作 | 镜头类型 | 运镜方式 | 时长 | 转场 | 声音
```

### 要素详解

#### 1. **场景描述**
- 具体地点和环境
- 时间（白天/傍晚/夜晚/黎明等）
- 天气状况（如适用）

示例：
- `深夜城市街道，路灯昏暗，薄雾弥漫`
- `公寓客厅，白天，阳光透过窗帘`
- `办公室走廊，日光灯闪烁，夜晚23:00`

#### 2. **人物与动作**
- 主体是谁（人物/物体）
- 在做什么动作
- 表情和状态

示例：
- `年轻女性，快步走过街道，不时回头张望，神情紧张`
- `男主角坐在沙发上，低头看手机，眉头紧锁`
- `空无一人的走廊，只有监控摄像头的红灯在闪烁`

#### 3. **镜头类型**
专业电影镜头术语：

| 镜头类型 | 英文缩写 | 说明 | 用途 |
|---------|---------|------|------|
| 大特写 | ECU | 眼睛、手指等细节 | 强调细节、情绪 |
| 特写 | CU | 面部表情 | 展现情绪变化 |
| 近景 | MS | 胸部以上 | 对话、表情 |
| 中景 | MCU | 腰部以上 | 日常动作 |
| 全景 | WS | 全身 | 展示完整动作 |
| 远景 | LS | 环境+人物 | 展示空间关系 |
| 过肩镜头 | OTS | 从肩膀后看向对方 | 对话场景 |
| 主观视角 | POV | 第一人称视角 | 代入感强 |

#### 4. **运镜方式**
摄像机运动方式：

| 运镜 | 效果 | 常用场景 |
|------|------|---------|
| **固定镜头** | 稳定、平静 | 对话、静态展示 |
| **推镜** | 接近主体、聚焦 | 强调重点、营造紧张 |
| **拉镜** | 远离主体、展示环境 | 揭示全貌、情绪释放 |
| **摇镜** | 左右/上下移动 | 展示空间、跟随视线 |
| **跟随** | 跟随主体移动 | 动态场景、行走 |
| **环绕** | 围绕主体旋转 | 展示全貌、戏剧化 |
| **升降** | 垂直移动 | 气势、视角变化 |

运镜速度描述：
- `缓慢推进` - 平稳、舒缓
- `快速拉远` - 紧张、惊恐
- `平稳跟随` - 自然、流畅

#### 5. **镜头时长**
建议停留时间：

- **瞬间闪过** (0.5-1秒) - 快节奏剪辑、冲击力
- **2-3秒** - 快速信息传递
- **3-5秒** - 标准镜头时长
- **5-8秒** - 重要场景展示
- **8-10秒** - 关键对话、情绪酝酿
- **10-15秒** - 复杂动作、氛围营造
- **15秒以上** - 长镜头、一镜到底

💡 **节奏技巧**：
- 紧张场景：短镜头(2-4秒)
- 舒缓场景：长镜头(8-15秒)
- 高潮转折：从短到长或从长到短

#### 6. **转场效果**
镜头之间的衔接方式：

| 转场 | 效果 | 用途 |
|------|------|------|
| **切** | 直接切换 | 标准转场，节奏快 |
| **淡入淡出** | 渐变过渡 | 时间流逝、场景转换 |
| **叠化** | 两画面叠加 | 回忆、梦境、关联 |
| **闪白/闪黑** | 突然亮/暗 | 惊吓、重大转折 |
| **擦除** | 画面擦过 | 动感、有趣 |
| **黑场** | 短暂黑屏 | 章节分隔、悬念 |
| **结束** | 最后一个镜头 | 标记结尾 |

#### 7. **声音提示**
音频设计参考：

**环境音**：
- `城市环境音，远处汽车声`
- `安静办公室，空调嗡嗡声`
- `雨声，雷声`
- `寂静无声，突出压抑感`

**音乐情绪**：
- `紧张悬疑配乐渐起`
- `舒缓钢琴曲`
- `激烈鼓点，节奏加快`
- `阴森诡异音效`

**对白/音效**：
- `人物对白："你在哪里？"`
- `脚步声渐近`
- `门突然关闭的声音`
- `手机震动声`

## 🎯 完整示例

### 示例1：惊悚短视频（10个镜头）

```
1. 深夜城市街道，路灯昏暗，薄雾弥漫 | 空旷街道，远处有脚步声 | 远景(LS) | 缓慢右摇 | 5-6秒 | 淡入 | 低沉环境音，远处脚步声

2. 女主角背影，黑色风衣，快步行走 | 女性从远处走来，不时回头 | 全景(WS) | 跟随拍摄 | 4-5秒 | 切 | 脚步声清晰，呼吸急促

3. 女主角侧脸特写，眼神惊恐 | 眼神四处张望，眉头紧锁 | 特写(CU) | 固定镜头 | 3-4秒 | 切 | 紧张配乐起，心跳声

4. 女主角主观视角，看向身后街道 | 街道空无一人，路灯闪烁 | 主观视角(POV) | 晃动镜头 | 2-3秒 | 切 | 环境音放大

5. 建筑物阴影中，隐约人影 | 黑影快速闪过 | 中景(MCU) | 快速推进 | 1-2秒 | 闪白 | 突然的低频音效

6. 女主角惊恐表情，瞪大眼睛 | 猛然转头，嘴巴微张 | 大特写(ECU) | 固定镜头 | 2秒 | 切 | 尖锐弦乐

7. 女主角开始奔跑，风衣飘扬 | 全力奔跑，手臂摆动 | 全景(WS) | 跟随奔跑 | 5-6秒 | 切 | 快节奏鼓点，沉重呼吸

8. 巷口出现的人影剪影 | 神秘人物站立，不动 | 远景(LS) | 固定镜头 | 3-4秒 | 淡出淡入 | 音乐停止，只有风声

9. 女主角躲入小巷，背靠墙壁 | 喘息，用手捂嘴，眼神恐惧 | 近景(MS) | 缓慢推进 | 6-8秒 | 切 | 急促呼吸声，心跳声

10. 小巷尽头，黑暗中一双发光的眼睛 | 眼睛缓慢眨动，盯着镜头 | 大特写(ECU) | 极慢推进 | 8-10秒 | 黑场 | 诡异音乐达到高潮，突然静默
```

**总时长**：约45-55秒（适合短视频平台）

## 💡 使用方法

### 第1步：创作故事
1. 在"故事生成"页面创作或粘贴你的故事正文
2. 确保故事有完整的情节和场景描述

### 第2步：生成视频分镜
1. 切换到"图片生成"页面
2. 点击 **🎬 视频版(10-15)** 按钮
3. 等待AI生成专业的视频分镜脚本

### 第3步：查看和使用分镜
生成的分镜会显示在"所有分镜头"文本框中，格式如下：

```
1. 场景描述 | 人物与动作 | 镜头类型 | 运镜方式 | 时长 | 转场 | 声音
2. 场景描述 | 人物与动作 | 镜头类型 | 运镜方式 | 时长 | 转场 | 声音
...
```

### 第4步：基于分镜制作视频

#### 方案A：真人拍摄
1. 将分镜导出为拍摄脚本
2. 按照镜头类型、运镜方式进行拍摄
3. 根据时长和转场效果进行剪辑

#### 方案B：AI生成视频
1. 选择单个分镜
2. 点击"从当前分镜生成"生成图片描述
3. 使用图片生成功能生成关键帧
4. 使用视频生成工具（如Runway、Pika）将图片转为视频
5. 根据分镜中的时长和转场进行剪辑

#### 方案C：动画制作
1. 使用分镜作为故事板参考
2. 在动画软件中按照镜头规划创建场景
3. 根据运镜方式设置相机运动
4. 根据时长控制每个镜头的帧数
5. 应用转场效果

## 📊 视频分镜的优势

### ✅ 专业性
- 使用电影级镜头术语
- 完整的视觉语言设计
- 考虑视频节奏和情绪变化

### ✅ 实用性
- 每个镜头都可直接执行
- 时长标注便于控制节奏
- 转场设计保证流畅性

### ✅ 完整性
- 不仅是画面，还包含声音设计
- 从视觉到听觉的全方位规划
- 适合团队协作（摄影师、剪辑师、音效师各取所需）

### ✅ 灵活性
- 可根据实际情况调整
- 每个要素都可单独修改
- 适应不同预算和制作条件

## 🔥 实战技巧

### 1. 根据视频平台调整时长
- **抖音/快手** (15-60秒)：使用8-10个镜头，每个2-6秒
- **B站/YouTube** (3-10分钟)：使用15-20个镜头，每个5-15秒
- **电影短片** (10分钟+)：使用20-30个镜头，灵活控制

### 2. 情绪节奏控制
- 开场：长镜头(6-8秒) → 建立氛围
- 发展：中等镜头(4-6秒) → 推进情节
- 高潮：短镜头(2-3秒) → 制造紧张
- 结尾：长镜头(8-10秒) → 情绪释放

### 3. 运镜搭配建议
- 静态场景：固定镜头 + 推镜
- 动作场景：跟随 + 摇镜
- 情绪场景：缓慢推进/拉远
- 转折场景：环绕 + 快速切换

### 4. 转场使用技巧
- **切**：80%的转场使用直切
- **淡入淡出**：时间流逝、场景大转换
- **叠化**：关联镜头、回忆梦境
- **闪白/闪黑**：强烈情绪转折（慎用）

### 5. 声音设计要点
- 环境音：营造真实感
- 音乐：控制情绪节奏
- 音效：强化关键时刻
- 沉默：制造悬念和张力

## 📝 导出和使用

### 导出为拍摄脚本
1. 复制所有分镜
2. 粘贴到Excel或Word中
3. 按 `|` 符号分列（Excel）
4. 添加实际拍摄备注列
5. 打印或分享给团队

### 导出为剪辑参考
1. 在剪辑软件（Premiere/Final Cut）中创建序列
2. 根据分镜时长创建空白片段
3. 添加标记，注明镜头类型和转场
4. 导入素材后按标记进行剪辑

## ⚠️ 注意事项

1. **时长仅供参考**
   - AI给出的时长是建议值
   - 实际剪辑时根据节奏调整
   - 音乐节拍可能影响实际时长

2. **运镜难度评估**
   - 推拉摇移：需要稳定器或滑轨
   - 跟随：需要跟焦设备
   - 环绕：需要摇臂或无人机
   - 根据设备条件调整方案

3. **转场效果实现**
   - 简单转场（切、淡）：任何剪辑软件可做
   - 复杂转场（叠化、擦除）：需要专业软件
   - 某些转场需要拍摄时配合

4. **多次生成对比**
   - AI每次生成可能不同
   - 建议生成2-3次
   - 选择最适合的版本
   - 或混合不同版本的优点
