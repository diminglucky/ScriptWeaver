### 方案B: 使用Mixin模式（高级）

将大类拆分成多个Mixin：

```python
# src/gui/mixins/project_mixin.py
class ProjectMixin:
    """项目管理功能"""
    
    def _build_project_page(self):
        # ... 项目页面代码
        pass
    
    def _on_new_project(self):
        # ... 创建项目代码
        pass

# src/gui/main_window.py
from src.gui.mixins import ProjectMixin, StoryMixin, ImageMixin

class App(tk.Tk, ProjectMixin, StoryMixin, ImageMixin):
    """主窗口 - 组合所有功能"""
    def __init__(self):
        super().__init__()
        self._build_ui()
```

## ❓ 常见问题

**Q: 会影响现有功能吗？**
A: 不会。我们保留了原文件备份，可以随时回退。

**Q: 需要改动其他文件吗？**
A: 不需要。`run_app.py` 等文件无需改动。

**Q: 建议用哪种方式？**
A: 建议先用**方式1**（使用已重构的工具），这样改动最小、风险最低。

**Q: 自动化脚本可靠吗？**
A: 脚本会生成基础框架，但需要手动调整导入和依赖关系。
