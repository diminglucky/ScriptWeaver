# 项目级人物一致性功能说明 🎭📁

## 核心改进

人物照片管理已升级为 **项目级管理**，每个故事项目独立保存和管理人物照片，实现完全的项目隔离。

## ✨ 功能特性

### 1. 自动项目隔离 ✅
- 每个项目有独立的 `characters/` 文件夹
- 不同项目的人物互不干扰
- 同名人物可在不同项目中有不同外貌

### 2. 自动创建文件夹 ✅
- **新建项目时**：自动创建 `项目目录/characters/` 文件夹
- **无需手动操作**：系统自动管理

### 3. 自动加载人物 ✅
- **切换项目时**：自动加载该项目的人物照片
- **清空旧数据**：自动清除上一个项目的人物列表
- **实时更新**：参考人物列表自动刷新

### 4. 智能保存 ✅
- 人物照片自动保存到 **当前项目** 的 `characters/` 文件夹
- 提示信息显示项目名称
- 若未创建项目，提示用户先创建项目

## 🎯 使用流程

### 第一步：创建或打开项目
1. 在 **项目管理** 页面创建新项目
2. 或打开已有项目
3. 系统自动创建/加载 `characters/` 文件夹

### 第二步：生成人物照片
1. 切换到 **图片生成** → **人物生成** 页面
2. 点击 **🔍 提取故事人物**
3. 为每个人物生成照片
4. 照片自动保存到 **当前项目/characters/**

### 第三步：使用人物一致性
1. 切换到 **图片生成** → **图片创作** 页面
2. 在 **🎭 参考人物** 下拉框中选择人物
3. 只显示 **当前项目** 中已生成照片的人物
4. 生成图片时自动使用该人物的外貌

## ❓ 常见问题

### Q1: 切换项目后，之前的人物还能看到吗？
**A:** 不能。切换项目时会自动清空人物列表，只加载新项目的人物。这是设计的特性，确保项目隔离。

### Q2: 两个项目有同名人物怎么办？
**A:** 完全没问题！每个项目的 `characters/` 文件夹是独立的：
- 项目A的"李明"：`projects/项目A/characters/李明.png`
- 项目B的"李明"：`projects/项目B/characters/李明.png`
- 两者互不影响，可以有不同外貌

### Q3: 没有创建项目能生成人物照片吗？
**A:** 不能。系统会提示"请先创建或打开一个项目"。必须有项目才能保存人物照片。

### Q4: 如何查看某个项目的人物照片？
**A:** 
1. 在文件管理器中打开 `projects/项目名/characters/` 文件夹
2. 或在应用中切换到该项目，人物会自动加载

### Q5: 可以手动复制人物照片到其他项目吗？
**A:** 可以！直接复制 PNG 文件到目标项目的 `characters/` 文件夹，然后重新加载项目即可。

### Q6: 删除项目会删除人物照片吗？
**A:** 是的。删除项目会删除整个项目文件夹，包括 `characters/` 下的所有人物照片。建议删除前备份重要照片。

## 📊 数据管理建议

### ✅ 最佳实践

1. **一个项目一个故事**
   - 每个故事创建独立项目
   - 保持人物库清晰

2. **及时保存项目**
   - 人物照片随项目保存
   - 避免数据丢失

3. **定期备份**
   - 备份整个 `projects/` 文件夹
   - 包含所有项目和人物照片

4. **人物命名规范**
   - 使用有意义的人物名
   - 避免特殊字符

### ❌ 避免的做法

1. **不创建项目就生成人物** → 无法保存
2. **频繁切换项目不保存** → 数据丢失风险
3. **手动修改项目文件夹结构** → 可能导致加载失败
