# 多人物参考功能说明 👥🎨

## 功能概述

现在支持在生成故事图片时**同时参考多个人物**，保持多个角色在不同场景中的外貌一致性！

---

## 🎯 使用场景

### 适用情况
- ✅ 图片中有多个主要角色同时出现
- ✅ 需要保持多个人物的外貌一致性
- ✅ 群像场景、对话场景、互动场景

### 示例场景
1. **对话场景**：李明和王芳在咖啡厅交谈
2. **群像场景**：主角团队的合影
3. **互动场景**：张三递给李四一份文件

---

## 📋 完整使用流程

### 第一步：准备人物照片
1. 进入 **图片生成** → **人物生成** 页面
2. 提取故事人物
3. 为每个主要人物生成特征描述和照片
4. 照片自动保存到项目的 `characters/` 文件夹

### 第二步：选择参考人物（支持多选！）
1. 进入 **图片生成** → **图片创作** 页面
2. 在 **🎭 参考人物** 列表框中，使用以下方式多选：
   - **Mac**: `Cmd + 点击` 选择多个
   - **Windows/Linux**: `Ctrl + 点击` 选择多个
   - **连续选择**: `Shift + 点击` 选择范围
3. 列表显示格式：
   - `❌ 不使用参考` - 不使用任何参考
   - `✅ 人物名` - 可选的人物

**示例多选：**
```
☑️ ✅ 李明
☑️ ✅ 王芳
☐  ✅ 张三
```

### 第三步：生成带多人物的图片
1. 填写或生成图片描述（描述中提到选中的人物）
2. 点击 **🎨 生成图片**
3. 系统自动：
   - 将所有选中人物的外貌特征添加到提示词中
   - 使用第一个人物的照片作为主要参考
   - 生成包含这些人物的图片

## 🔧 技术实现

### 1. 自动提示词增强
当你选择参考人物后，系统会自动修改提示词：

**原始提示词：**
```
李明和王芳在咖啡厅交谈
```

**自动增强后：**
```
画面中的人物特征：
【李明】男，约30岁，短发，穿西装，眼镜，微笑...
【王芳】女，约25岁，长发，职业装，温柔的眼神...

场景描述：
李明和王芳在咖啡厅交谈
```

### 2. 参考图使用策略
- **单人选择**：使用该人物的照片作为参考
- **多人选择**：使用**第一个**选中人物的照片作为主参考
- **提示词包含所有人**：所有选中人物的特征都会添加到提示词中

### 3. 人物一致性保证
```python
第1步：获取选中的多个人物
第2步：提取每个人物的详细外貌描述
第3步：将描述添加到提示词前面
第4步：使用第一个人物的照片作为视觉参考
第5步：生成包含所有人物的图片
```

## 💡 最佳实践

### ✅ 推荐做法

1. **按重要性排序选择**
   - 先选择最重要的人物
   - 第一个选择的人物会作为主参考图

2. **限制选择数量**
   - 建议选择 2-4 个主要人物
   - 人物太多可能影响生成质量

3. **描述要清晰**
   - 在图片描述中明确说明每个人物的位置
   - 例如："左边是李明，右边是王芳"

4. **特征要详细**
   - 确保每个人物都有详细的特征描述
   - 越详细，一致性越好

### ❌ 避免的做法

1. **选择不相关的人物**
   - 不要选择图片中不出现的人物
   
2. **描述与选择不符**
   - 图片描述："李明和王芳交谈"
   - 但只选择了张三 ❌

3. **同时选择太多人物**
   - 选择5个以上人物可能导致混乱 ❌

## ⚙️ 技术细节

### 多选列表框特性
- **类型**: `tk.Listbox` with `selectmode=tk.MULTIPLE`
- **高度**: 4行（可滚动）
- **颜色**: 深色主题适配
- **选中颜色**: 绿色 (#4CAF50)

### 数据流
```
用户多选人物
    ↓
_get_selected_reference_characters()
    ↓
返回包含 name, photo_path, description 的列表
    ↓
_on_img_generate() 处理
    ↓
自动增强提示词 + 使用参考图
    ↓
生成包含多人物的图片
```

## ❓ 常见问题

### Q1: 最多可以选择几个人物？
**A:** 技术上没有限制，但建议2-4个。人物太多可能导致生成质量下降或某些人物不够清晰。

### Q2: 选择顺序重要吗？
**A:** 重要！第一个选择的人物会作为主要参考图。如果有主角，建议先选择主角。

### Q3: 如何取消选择？
**A:** 
- 再次点击已选择的项目即可取消
- 或选择"❌ 不使用参考"清除所有选择

### Q4: 选择了人物但图片中只有一个？
**A:** 这是正常的。系统会使用所有人物的特征描述，但实际生成结果取决于你的图片描述。确保描述中明确提到了所有选中的人物。

### Q5: 人物外貌还是不一致怎么办？
**A:** 
1. 确保人物特征描述足够详细
2. 在图片描述中明确说明每个人物的具体特征
3. 尝试多次生成选择最好的结果
4. 考虑在"额外描述"中补充关键特征
