# 人物一致性完整使用指南 🎭

## 功能概述

本系统实现了完整的人物一致性功能，可以：
1. ✅ 自动提取故事中的人物
2. ✅ 为每个人物生成外貌特征描述
3. ✅ 生成全身照片（自动保存到专用文件夹）
4. ✅ 在图片创作时自动使用人物照片作为参考，保持一致性

---

## 📁 照片自动保存机制

### 保存位置
所有人物照片自动保存在项目根目录的 `characters/` 文件夹中：
```
创作知乎故事/
  └── characters/
      ├── 林辉梦.png
      ├── 王霜琴.png
      ├── 欧老奶奶.png
      └── ...
```

### 文件命名规则
- **格式**：`人物名.png`
- **特点**：
  - 同一人物重复生成会自动覆盖旧照片
  - 确保始终使用最新版本的人物照片
  - 文件名自动去除特殊字符，只保留有效字符

## 🎯 完整使用流程

### 第一步：生成故事
1. 在**故事生成**页面创建一个故事
2. 确保故事中包含明确的人物名字和描述

### 第二步：提取人物并生成照片

#### 2.1 提取人物列表
1. 切换到**图片生成** → **人物生成**标签页
2. 点击 **🔍 提取故事人物** 按钮
3. AI自动分析故事，提取所有关键人物
4. 人物列表显示在左侧列表框中

#### 2.2 生成人物特征描述
1. 从列表中点击选择一个人物
2. 点击 **✨ 生成特征描述** 按钮
3. AI分析该人物的外貌特征，生成详细描述
4. 特征描述包括：
   - 性别、年龄
   - 面部特征（脸型、五官）
   - 身材体型
   - 发型发色
   - 穿着打扮
   - 显著特征

#### 2.3 生成人物照片
1. 选择**图片风格**（写实照片、日系动漫、古风等）
2. 可选：在**额外描述**中添加姿态、表情等细节
3. 点击 **🎨 生成人物照片** 按钮
4. 等待生成（右上角显示进度）
5. **照片自动保存到 `characters/` 文件夹**
6. 预览区显示生成的照片

> **💡 提示**：照片生成时已自动优化为全身照，清晰展示所有人物特征

#### 2.4 为其他人物生成照片
重复步骤 2.2-2.3，为所有重要人物生成照片

---

### 第三步：使用人物一致性生成故事图片

#### 3.1 切换到图片创作页面
1. 切换到**图片生成** → **图片创作**标签页
2. 生成或选择一个分镜头

#### 3.2 选择参考人物
在**🎭 参考人物**下拉框中：
- 选择 **不使用参考**：生成全新人物
- 选择 **具体人物名**（如"林辉梦"）：使用该人物的外貌

**重要**：只有在"人物生成"页面生成过照片的人物才会出现在列表中

#### 3.3 生成图片
1. 选择参考人物后，系统自动：
   - 将该人物的照片路径填入**参考图**字段
   - 在生成图片时使用该照片作为外貌参考
2. 按正常流程生成图片
3. 生成的图片中，人物外貌会与参考照片保持一致

## 🎨 图片生成优化说明

### 全身照生成
人物照片生成时自动优化为全身照：
- 自动添加"全身照"、"站姿"关键词
- 强调"完整人物形象"、"清晰展示所有特征"
- 确保人物从头到脚完整显示

### 特征强化
生成时自动强化：
- 人物的面部特征
- 身材体型
- 服装配饰
- 姿态动作

## 💡 使用技巧

### 1. 人物描述越详细越好
在生成特征描述时，如果故事中人物描述不够详细：
- 可以在**额外描述**框中补充细节
- 添加具体的服装、配饰、姿态描述
- 增加面部表情、眼神等细节

### 2. 风格选择建议
| 故事类型 | 推荐风格 | 说明 |
|---------|---------|------|
| 现代都市 | 写实照片 | 真实自然 |
| 古代武侠 | 武侠/古风 | 符合时代特征 |
| 修仙玄幻 | 仙侠/国风插画 | 仙气飘飘 |
| 轻松愉快 | 日系动漫 | 色彩明亮 |
| 悬疑惊悚 | 写实照片/惊悚 | 写实更有代入感 |

### 3. 保持一致性的最佳实践
✅ **推荐做法**：
- 先为主要人物生成照片
- 在故事图片生成时始终选择同一个参考人物
- 不要频繁修改人物照片

❌ **避免**：
- 同一人物生成多张不同风格的照片
- 在一个故事中混用不同风格的人物照片
- 参考人物与图片描述严重不符

### 4. 多次生成优化
如果第一次生成的照片不满意：
- 可以修改**额外描述**
- 尝试不同的图片风格
- 重新生成会自动覆盖旧照片

## 🔧 技术说明

### 参考图工作原理
1. 选择参考人物后，系统自动将 `characters/人物名.png` 的路径填入参考图字段
2. 调用图片生成API时，传入参考图路径
3. API使用参考图的人物外貌作为约束，生成新场景的图片
4. 保证同一人物在不同场景中外貌一致

### API配置要求
人物一致性功能需要两个API：

**1. 文本生成API**（用于提取人物、生成特征描述）
- 位置：故事生成-配置页面
- 推荐：DeepSeek（性价比高，中文理解好）

**2. 图片生成API**（用于生成人物照片和故事图片）
- 位置：图片生成-配置页面
- 支持：
  - OpenAI DALL-E
  - V-API（兼容DALL-E的代理）
  - 腾讯混元
  - 其他兼容OpenAI格式的API

## ❓ 常见问题

### Q1: 参考人物列表是空的？
**A:** 
- 确保已在"人物生成"页面为人物生成过照片
- 只有生成照片成功并保存的人物才会出现在列表中
- 检查 `characters/` 文件夹中是否有对应的照片文件

### Q2: 选择参考人物后，生成的图片人物不像？
**A:**
- 检查参考图路径是否正确（可以在参考图字段中看到路径）
- 确认图片描述与人物特征相符
- 部分API的参考图功能可能有限制
- 尝试在描述中明确说明人物外貌特征

### Q3: 照片没有自动保存？
**A:**
- 查看终端输出，确认是否有错误信息
- 检查 `characters/` 文件夹是否存在（第一次会自动创建）
- 确认有文件写入权限
- 重新生成照片会再次尝试保存

### Q4: 想要半身照而不是全身照？
**A:**
- 在**额外描述**中明确写"半身照"或"特写镜头"
- 系统会优先采用你的描述

### Q5: 如何删除或更换人物照片？
**A:**
- 直接在 `characters/` 文件夹中删除对应文件
- 或者重新生成会自动覆盖
