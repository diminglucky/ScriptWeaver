# 人物信息持久化功能说明 💾

## 📋 功能概述

现在系统支持**完整的人物信息持久化**，所有提取的人物都会自动保存，不需要每次重新提取！

---

## ✨ 核心改进

### 改进前 ❌
- 只有生成过照片的人物才会被保存
- 未生成照片的人物在关闭应用后丢失
- 每次打开项目都需要重新提取人物

### 改进后 ✅
- **所有提取的人物都会立即保存**
- **生成描述后自动更新保存**
- **打开项目时自动加载所有人物**
- 即使没有照片，人物信息也会保留

---

## 🔄 完整工作流程

### 第一步：提取人物
1. 在**图片生成 → 人物描述**页面
2. 点击 **🔍 提取故事人物** 按钮
3. ✅ **系统立即保存所有人物名字**

**保存位置**：`projects/项目名/characters/characters_info.json`

**保存内容示例**：
```json
{
  "林晓梦": {
    "description": "",
    "photo_path": ""
  },
  "王阿姨": {
    "description": "",
    "photo_path": ""
  }
}
```

### 第二步：生成描述（可选）
1. 从列表中选择一个人物
2. 点击 **✨ 生成特征描述**
3. ✅ **系统自动更新并保存描述**

**更新后的内容**：
```json
{
  "林晓梦": {
    "description": "22岁女性实习生，黑色齐肩短发整齐利落...",
    "photo_path": ""
  }
}
```

### 第三步：生成照片（可选）
1. 点击 **🎨 生成人物照片**
2. ✅ **系统自动保存照片路径**

**完整信息**：
```json
{
  "林晓梦": {
    "description": "22岁女性实习生，黑色齐肩短发整齐利落...",
    "photo_path": "projects/惊悚短故事/characters/林晓梦.png"
  }
}
```

### 第四步：重新打开项目
1. 下次打开项目时
2. ✅ **系统自动加载所有保存的人物**
3. 人物列表自动恢复到之前的状态

---

## 📊 自动保存时机

| 操作 | 保存内容 | 状态提示 |
|-----|---------|---------|
| 提取人物 | 所有人物名字 | ✅ 成功提取到 X 个人物并已保存 |

| 生成照片 | 更新照片路径 | ✅ 人物照片已自动保存 |

## 💡 使用建议

### 1. 一次性提取所有人物 ⭐
```
第一次使用项目时：
1. 提取所有人物（自动保存）
2. 按需生成描述和照片
3. 后续使用时自动加载，无需重复操作
```

### 2. 增量式工作流 ⭐
```
可以分多次完成：
1. 今天：提取人物并保存
2. 明天：为部分人物生成描述
3. 后天：为重要人物生成照片
```

### 3. 灵活管理 ⭐
```
- 不需要一次性完成所有人物
- 可以只为重要人物生成照片
- 次要人物只保留名字和描述即可
```

## 🔍 数据文件说明

### 文件位置
```
projects/
  └── 项目名/
      └── characters/
          ├── characters_info.json  ← 所有人物信息（核心文件）
          ├── 林晓梦.png            ← 人物照片
          ├── 王阿姨.png
          └── ...
```

### JSON文件格式
```json
{
  "人物名": {
    "description": "人物描述（可以为空）",
    "photo_path": "照片路径（可以为空）"
  }
}
```

### 数据完整性
- **只有名字**：最小保存，占用极少空间
- **有描述**：可用于生成照片
- **有照片**：可用作图片生成的参考

---

## ⚠️ 注意事项

### 1. 项目独立性
- 每个项目有独立的人物库
- 不同项目的人物不会互相干扰
- 同名人物可以在不同项目中存在

### 2. 自动覆盖
- 重新提取人物会**完全替换**旧列表
- 建议只提取一次，后续手动调整

### 3. 数据安全
- `characters_info.json` 是纯文本文件
- 可以手动编辑（小心格式错误）
- 建议定期备份项目文件夹
