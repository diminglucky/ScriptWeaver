# 👔 服装造型变体功能说明

## 🎯 功能概述

本功能允许为同一个角色生成**不同服装、发型、配饰**的变体照片，在保持角色基本外貌特征的同时，展现角色在不同场合、不同时期的形象变化。

**版本**：v3.1  
**状态**：已完成 ✅

---

## ✨ 核心特性

### 1️⃣ 三种变体模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 默认 | 不使用变体，按照角色描述生成 | 标准照片生成 |
| 预设变体 | 使用6种预定义的服装风格 | 快速生成常见风格 |
| 自定义 | 输入自定义的服装/造型描述 | 特殊场合、独特需求 |

### 2️⃣ 预设变体类型

系统提供6种专业预设变体：

#### 👔 正装 (Formal)
**特点**：正式、优雅、职业
- 西装、礼服
- 领带、皮鞋
- 适合：商务、婚礼、正式场合

**示例**：
```
林晓梦_正面_中性_正装.png
```

#### 👕 休闲 (Casual)
**特点**：轻松、日常、随意
- T恤、牛仔裤
- 运动鞋
- 适合：日常生活、朋友聚会

**示例**：
```
林晓梦_正面_开心_休闲.png
```

#### 🏃 运动 (Sport)
**特点**：活力、健康、运动风
- 运动服、健身装
- 运动鞋
- 适合：运动场景、健身房

**示例**：
```
林晓梦_正面_中性_运动.png
```

#### 🎭 古装 (Traditional)
**特点**：古典、传统、东方美
- 汉服、旗袍、长袍
- 传统发饰
- 适合：古风故事、历史剧

**示例**：
```
林晓梦_正面_悲伤_古装.png
```

#### 🎨 艺术 (Artistic)
**特点**：独特、个性、创意
- 波西米亚风
- 独特设计
- 适合：艺术家、创作者形象

**示例**：
```
林晓梦_正面_惊讶_艺术.png
```

#### 💼 职业 (Professional)
**特点**：专业、干练、职场感
- 职业套装、衬衫
- 西裤
- 适合：职场角色、白领

**示例**：
```
林晓梦_正面_中性_职业.png
```

### 3️⃣ 自定义变体

**灵活性**：完全自由定义角色的服装和造型

**示例输入**：
- "穿着白色婚纱，戴着头纱和项链"
- "戴着黑框眼镜，穿着医生白大褂"
- "头发染成粉色，穿着朋克风皮夹克"
- "穿着校服，背着书包"
- "穿着睡衣，拿着咖啡杯"

**文件命名**：
- 自定义变体会取前10个字符作为文件名标识
- 示例：`林晓梦_正面_开心_穿着白色婚纱.png`

## 📐 变体与其他参数的组合

### 完整参数矩阵

```
角色照片 = 基础外貌 × 视角 × 表情 × 服装变体 × 额外细节
```

#### 参数优先级

1. **基础外貌** ⭐⭐⭐⭐⭐（最高）
   - 年龄、性别、五官特征
   - 这些特征保持不变

2. **服装变体** ⭐⭐⭐⭐
   - 改变服装、发型、配饰
   - 影响整体风格

3. **视角** ⭐⭐⭐
   - 改变拍摄角度
   - 不影响外貌和服装

4. **表情** ⭐⭐⭐
   - 改变面部表情
   - 不影响服装和外貌

5. **额外细节** ⭐⭐
   - 补充姿态、背景等
   - 微调细节

### 组合示例

#### 示例1：职场女性多变体
```
基础描述：28岁女性，黑色长发，面容清秀，身高165cm

组合1：
- 视角：正面
- 表情：中性
- 变体：职业装
- 结果：职场证件照风格

组合2：
- 视角：三视图
- 表情：微笑
- 变体：正装
- 结果：商务形象展示

组合3：
- 视角：正面
- 表情：开心
- 变体：休闲
- 结果：生活照风格
```

#### 示例2：古装男子多表情
```
基础描述：30岁男性，长发束冠，面容俊朗，身高180cm

组合：
- 视角：正面
- 变体：古装
- 表情批量生成：中性/开心/悲伤/愤怒/惊讶
- 结果：5张不同表情的古装照
```

```

林晓梦_侧面.png                # 侧面+中性+默认
林晓梦_正面_开心.png            # 正面+开心+默认
```

#### 预设变体
```
林晓梦_正装.png                # 正面+中性+正装
林晓梦_正面_休闲.png            # 正面+中性+休闲
林晓梦_侧面_开心_运动.png        # 侧面+开心+运动
林晓梦_正面_悲伤_古装.png        # 正面+悲伤+古装
```

#### 自定义变体
```
林晓梦_穿着白色婚纱.png          # 正面+中性+自定义（取前10字符）
林晓梦_戴着黑框眼镜.png          # 正面+中性+自定义
林晓梦_正面_开心_穿着校服背着.png  # 正面+开心+自定义
```

### 命名规则

1. ✅ 正面+中性+默认 → 只显示角色名
2. ✅ 非正面 → 添加角度名
3. ✅ 非中性 → 添加表情名
4. ✅ 有变体 → 添加变体名（预设或前10字符）
5. ✅ 用下划线`_`分隔各部分

## 📈 性能与限制

### 性能指标

| 指标 | 数值 | 说明 |
|------|------|------|
| 变体提示词增加 | 30-60字符 | 预设变体 |
| 变体提示词增加 | 自定义长度 | 最多60字符 |
| 生成时间 | 无明显影响 | 与无变体相同 |
| 一致性 | 较高 | 基础外貌保持 |

### 使用限制

1. **字符限制**
   - 自定义变体最多60字符
   - 超过会自动截断

2. **一致性说明**
   - 基础外貌（年龄、性别、五官）保持一致
   - 服装、发型、配饰会改变
   - 不同API的一致性表现可能有差异

3. **变体冲突**
   - 如果角色描述中已包含服装信息，变体可能产生冲突
   - 建议：角色描述只写固定特征，服装用变体控制

## 🎯 最佳实践

### DO's ✅

1. ✅ **角色描述写固定特征**
   ```
   好：28岁女性，黑色长发，面容清秀，身高165cm
   避免：28岁女性，穿着西装，黑色长发（服装应该用变体）
   ```

2. ✅ **使用预设变体快速生成**
   - 常见场景直接用预设
   - 节省输入时间
   - 效果稳定

3. ✅ **自定义变体写具体细节**
   ```
   好：穿着白色婚纱，戴着珍珠项链和头纱
   一般：穿着漂亮的衣服（太模糊）
   ```

4. ✅ **批量生成多变体**
   - 为角色生成多套服装
   - 建立角色服装库
   - 适应不同场景需求

### DON'Ts ❌

1. ❌ **不要在角色描述中写服装**
   ```
   错误：生成"穿着西装的林晓梦"，同时选择"休闲"变体
   结果：可能出现西装+休闲混合的奇怪效果
   ```

2. ❌ **不要变体描述过长**
   ```
   错误：穿着一件精致的手工刺绣白色婚纱，上面有蕾丝边和珍珠装饰，配合着长长的拖尾和华丽的头纱...
   正确：穿着白色婚纱，有刺绣和蕾丝（保持在60字符内）
   ```

3. ❌ **不要混淆变体和额外细节**
   ```
   变体：用于服装、发型、配饰
   额外细节：用于姿态、背景、光线等
   ```

## ❓ 常见问题

### Q1: 变体会改变角色的基本外貌吗？
**A:** 不会。变体只改变服装、发型、配饰，不会改变年龄、性别、五官等基本特征。

### Q2: 可以同时使用预设变体和自定义吗？
**A:** 不可以。只能选择一种模式：默认、预设或自定义。

### Q3: 如何确保不同变体照片的一致性？
**A:** 
- 使用相同的角色描述
- 保持基础参数（视角、表情）一致
- 只改变变体参数
- 使用相同的API和模型

### Q4: 自定义变体可以写多长？
**A:** 最多60个字符，超过会自动截断。建议简洁明确。

### Q5: 变体照片可以用于角色设定表吗？
**A:** 可以，但建议：
- 标准版设定表使用默认变体
- 单独生成变体版设定表
- 或者创建"角色换装展示"专题

### Q6: 如何为古装角色生成现代装？
**A:** 
```
方案1：
- 角色描述：只写固定外貌
- 默认生成：古装变体
- 现代装：休闲/职业变体

方案2：
- 创建两个角色版本
- 一个用于古装场景
- 一个用于现代场景
```
