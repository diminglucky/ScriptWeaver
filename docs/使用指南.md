# 🎯 AI Story Creator Pro - 使用指南

## 快速开始

### 1. 启动应用
```bash
python start_app.py
```

### 2. 配置自定义 API（首次使用）

#### 方法一：通过 UI 配置
1. 启动应用后，点击顶部的"设置"标签
2. 在"基础 API 配置"区域：
   - 选择"自定义"预设
   - 填写 API Key
   - 填写 Base URL（例如：`https://superai.dihappy.cfd/v1`）
   - 填写或输入模型名称（例如：`gemini-3-pro-preview`）
3. 点击"保存配置"按钮
4. 在"⚡ 快速 API 切换"区域：
   - 📝 故事生成：选择"自定义"
   - 🎨 图片生成：选择你想用的图片 API
5. 点击"保存快速切换配置"

#### 方法二：直接编辑配置文件
编辑 `custom_api_presets.json`：
```json
{
  "自定义": {
    "key": "你的API密钥",
    "base_url": "https://superai.dihappy.cfd/v1",
    "model": "gemini-3-pro-preview"
  }
}
```

编辑 `.env` 文件：
```bash
STORY_OUTLINE_GEN_API='自定义'
STORY_STORY_GEN_API='自定义'
```

### 3. 生成故事

#### 步骤 1：生成目录
1. 点击"故事生成"标签
2. 在"创作需求/主题"输入框中输入你的需求，例如：
   ```
   写一个关于程序员在创业公司的职场故事，要有冲突和成长
   ```
3. 设置参数：
   - 种类：职场/情感/悬疑等
   - 风格：情感起伏/反转/细节描写等
   - 目标字数：1800-15000字
4. 点击"生成目录"按钮
5. 等待目录生成完成（控制台会显示 `🔧 [补丁] 强制使用 API: 自定义`）

#### 步骤 2：生成章节
1. 在章节选择器中选择要生成的章节
2. 点击"生成选中章节"按钮
3. 等待章节生成完成
4. 点击"继续下一章"自动生成下一章
5. 或点击"自动生成全部"一次性生成所有章节

#### 步骤 3：保存和导出
1. 生成完成后，内容会自动保存到当前项目
2. 可以在"项目管理"标签中查看和管理项目
3. 可以导出为文本文件

## 功能说明

### 📝 故事生成
- **生成目录**：根据需求生成故事大纲
- **逐章生成**：选择章节逐个生成，可控制质量
- **自动生成全部**：一键生成所有章节
- **继续下一章**：快速生成下一章

### 🎨 图片生成
- **角色设计**：为故事角色生成形象
- **场景生成**：根据故事情节生成场景图
- **分镜生成**：为故事生成分镜脚本

### 📚 知识库
- **素材管理**：上传和管理创作素材
- **智能检索**：根据需求检索相关素材
- **辅助创作**：结合素材生成更丰富的内容

### ⚙️ 设置
- **API 配置**：配置多个 API 提供商
- **快速切换**：快速切换故事和图片生成的 API
- **参数调整**：调整生成参数（温度、字数等）

## 常见问题

### Q1: 为什么生成失败？
**A**: 检查以下几点：
1. API Key 是否正确
2. Base URL 是否正确（需要包含 `/v1`）
3. 模型名称是否在你的 API 平台上可用
4. 网络连接是否正常

运行测试脚本检查配置：
```bash
python 快速测试.py
```

### Q2: 如何切换不同的模型？
**A**: 
1. 进入"设置"页面
2. 选择"自定义"预设
3. 在"模型"下拉框中直接输入新的模型名称
4. 点击"保存配置"

支持的模型示例：
- `gemini-3-pro-preview`
- `claude-sonnet-4-5`
- `gpt-4o`
- `gpt-4o-mini`

### Q3: 为什么 Entry 输入框看不清文字？
**A**: 已修复！现在使用亮黄色文字 (#FCD34D) + 深色背景，清晰可见。

### Q4: 如何保存我的配置？
**A**: 配置会自动保存到以下文件：
- `custom_api_presets.json` - API 配置
- `.env` - 环境变量和 API 选择

### Q5: 生成的内容在哪里？
**A**: 
- 在应用界面的输出区域可以直接查看
- 自动保存到 `projects/` 目录下的项目文件夹
- 可以在"项目管理"标签中查看和管理

## 高级功能

### 自定义提示词
在生成时，系统会根据你的需求自动构建提示词。你可以通过以下方式影响生成结果：
- **详细描述**：提供更详细的需求描述
- **风格设置**：在"风格"输入框中指定写作风格
- **参数调整**：调整温度（创造性）和字数

### 批量生成
使用"自动生成全部"功能可以一次性生成所有章节：
1. 生成目录后
2. 点击"自动生成全部"按钮
3. 系统会自动逐章生成
4. 生成过程中可以在输出区域查看进度

### 项目管理
- **新建项目**：为每个故事创建独立项目
- **加载项目**：继续之前的创作
- **导出项目**：导出为文本或其他格式
