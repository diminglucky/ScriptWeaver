# 腾讯混元文生图集成说明

## 概述

本项目已集成腾讯混元文生图API，支持使用中文提示词直接生成图片，无需翻译为英文。

## 功能特点

- ✅ **中文原生支持**：直接使用中文描述生成图片，无需翻译
- ✅ **多种分辨率**：支持1:1、3:4、4:3、16:9等多种比例
- ✅ **绘画风格**：支持多种预设绘画风格
- ✅ **API兼容**：与现有OpenAI图片API无缝切换

## 配置步骤

### 1. 获取腾讯云API密钥

1. 访问[腾讯云控制台](https://console.cloud.tencent.com/)
2. 进入【访问管理】→【访问密钥】→【API密钥管理】
3. 创建密钥，获得：
   - **SecretId**（相当于用户名）
   - **SecretKey**（相当于密码）

### 2. 开通混元服务

1. 访问[腾讯混元控制台](https://console.cloud.tencent.com/hunyuan)
2. 开通文生图服务
3. 确保账户有足够余额

### 3. 在应用中配置

1. 打开应用，切换到【图片生成】→【配置】标签页
2. 在API预设下拉框中选择【腾讯混元】
3. 填写配置信息：
   - **API Key / SecretId**：填入你的SecretId
   - **SecretKey**：填入你的SecretKey
   - **Base URL**：保持默认 `https://hunyuan.tencentcloudapi.com`
   - **Model**：保持默认 `hunyuan-turbo`
4. 点击【保存配置】按钮
5. 点击【🔌 测试API】验证配置是否正确

## 使用方法

### 生成图片

1. 切换到【图片生成】→【生成】标签页
2. 在"图片描述"框中输入中文提示词，例如：
   ```
   雨中，竹林，小路，写实风格，高清
   ```
3. 选择图片尺寸（如1024x1024）
4. 点击【🎨 生成图片】按钮
5. 等待生成完成，图片将显示在预览区

### 支持的分辨率

腾讯混元支持以下分辨率：

| 分辨率 | 比例 | 适用场景 |
|--------|------|----------|
| 768x768 | 1:1 | 方形图片 |
| 768x1024 | 3:4 | 竖版图片 |
| 1024x768 | 4:3 | 横版图片 |
| 1024x1024 | 1:1 | 方形高清 |
| 720x1280 | 9:16 | 手机竖屏 |
| 1280x720 | 16:9 | 手机横屏 |
| 1080x1920 | 9:16 | 高清竖屏 |
| 1920x1080 | 16:9 | 高清横屏 |

## ⚠️ 重要限制

### 文本长度限制
- **Prompt最大长度**：256个UTF-8字符
- **建议长度**：150-200字以内
- **超长处理**：系统会自动截断过长的描述
- **优化建议**：生成描述时选择简洁精准的表达

### 绘画风格

腾讯混元通过文本描述控制风格。应用已集成10种图片类型：
- 写实照片、日系动漫、3D渲染、水彩画、油画
- 素描、赛博朋克、蒸汽朋克、像素风、中国风

系统会自动在描述中添加相应的风格关键词。

## API费用

腾讯混元文生图采用按量计费：

- **文生图轻量版**：按生成次数计费
- 具体价格请参考[腾讯云官方定价](https://cloud.tencent.com/document/product/1729/97731)

**注意**：
- 每次测试API都会实际生成一张图片并消耗费用
- 建议先进行少量测试，确认效果后再大量使用
- 请定期检查账户余额，避免欠费

## 技术架构

### 客户端实现

腾讯混元客户端位于 `src/clients/hunyuan_image_client.py`，主要功能：

1. **腾讯云API 3.0签名认证**：
   - 实现TC3-HMAC-SHA256签名算法
   - 自动处理时间戳和请求头

2. **图片生成**：
   ```python
   client = HunyuanImageClient(secret_id="xxx", secret_key="xxx")
   result = client.generate(
       prompt="雨中，竹林，小路",
       resolution="1024x1024",
       rsp_img_type="base64"
   )
   ```

3. **返回格式**：
   - 支持base64编码
   - 支持URL（有效期1小时）

### GUI集成

在 `src/gui_app.py` 中集成：

1. **API预设**：添加腾讯混元预设配置
2. **配置保存**：支持SecretId和SecretKey的保存
3. **智能切换**：根据provider自动选择对应的API客户端
4. **中文支持**：使用腾讯混元时跳过英文翻译步骤

## 常见问题

### Q: 提示"请先配置腾讯混元的SecretId和SecretKey"

A: 请确保在配置页面填写了SecretId和SecretKey，并点击保存配置。

### Q: 生成失败，提示鉴权错误

A: 请检查：
1. SecretId和SecretKey是否正确
2. 是否已开通混元服务
3. 账户余额是否充足
4. 网络连接是否正常

### Q: 可以使用已有的OpenAI API Key吗？

A: 不可以。腾讯混元使用腾讯云自己的认证体系，需要单独申请SecretId和SecretKey。

### Q: 为什么测试API会消耗费用？

A: 测试API时会实际调用混元服务生成一张测试图片，因此会产生费用。建议配置完成后只测试一次。

### Q: 提示"TextLengthExceed - 输入文本过长"怎么办？

A: 腾讯混元限制提示词最多256个UTF-8字符。解决方法：
1. 系统会自动截断过长描述，通常无需手动处理
2. 生成描述时选择"简洁"的表达方式
3. 手动编辑描述，保持在200字以内
4. 使用更精准的关键词而非冗长叙述

### Q: 为什么有些分辨率生成的图片尺寸不同？

A: 系统会自动将某些分辨率映射到腾讯混元支持的尺寸：
- 1024x1792 → 1080:1920（竖版）
- 1792x1024 → 1920:1080（横版）
- 512x512 → 768:768（方形）
