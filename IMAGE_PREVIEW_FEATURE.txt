图片预览功能 - 完成总结
========================

新增功能：分镜图片预览页面
--------------------------

位置：
  导演页面 -> 【图片预览】标签页

功能特性：
---------

1. 分镜选择器
   - 下拉框选择具体分镜或查看全部
   - 自动显示选项："全部分镜" / "分镜1 - Wide Shot" / "分镜2 - Close-up" ...
   - 实时显示图片数量统计

2. 图片网格展示
   - 每行2张图片的网格布局
   - 显示图片信息：
     * 文件名
     * 分辨率 (宽×高)
     * 文件大小 (KB)
   - 可滚动浏览大量图片

3. 图片操作
   - 点击图片放大查看 (全屏模式)
   - 每张图片独立的删除按钮
   - 删除确认对话框防止误操作
   - 删除后自动刷新显示

4. 自动更新
   - 生成新图片后自动刷新下拉框
   - 加载项目时自动加载分镜列表
   - 手动刷新按钮可随时更新

使用方法：
---------

步骤1：生成图片
  1. 在导演页面【步骤3】选择分镜
  2. 点击"生成图片"
  3. 等待生成完成

步骤2：查看图片
  1. 切换到【图片预览】标签页
  2. 从下拉框选择要查看的分镜
  3. 浏览生成的图片

步骤3：管理图片
  - 点击图片查看大图
  - 点击"删除"按钮移除不满意的图片
  - 点击"刷新"更新显示

技术实现：
---------

新增文件：
  - src/gui/mixins/director_modules/image_preview_methods.py
    包含所有图片预览相关方法

核心方法：
  - _refresh_preview_shot_combo()     # 刷新分镜下拉框
  - _on_preview_shot_selected()       # 分镜选择事件
  - _refresh_preview_images()         # 刷新图片显示
  - _display_images_grid()            # 网格布局显示
  - _show_image_fullscreen()          # 全屏查看
  - _delete_preview_image()           # 删除图片
  - _on_preview_mousewheel()          # 鼠标滚轮

UI组件：
  - preview_shot_combo    # 分镜选择下拉框
  - preview_info_label    # 信息标签
  - director_images_canvas         # 可滚动画布
  - director_images_scrollable     # 图片容器

集成方式：
  使用装饰器 @add_image_preview_methods 将方法添加到 DirectorMixin

优势：
-----
✅ 清晰的视觉呈现
✅ 按分镜组织图片
✅ 快速浏览和筛选
✅ 方便的删除管理
✅ 全屏查看细节
✅ 自动同步更新

-----------
1. 运行应用：python run_modern_app.py
2. 进入导演页面
3. 生成分镜图片
4. 在【图片预览】标签页查看
5. 选择不同分镜查看对应图片
6. 点击图片放大查看
7. 删除不满意的图片
